# CodeWay | مسار علم البيانات

منصة تعليمية عربية لتعلم علم البيانات من الصفر حتى المستوى المتقدم، مبنية على الهوية البصرية لـ CodeWay: خلفية داكنة، و Glassmorphism، وتدرجات سماوي/وردي/ذهبي، واتجاه RTL.

## ما الموجود الآن

| المكوّن | المحتوى |
|---|---|
| **بوابة المسار** `index.html` | ما هو علم البيانات، وماذا ستتعلم وتبني، والمتطلبات، ومسار التعلم التفاعلي، والمراحل من مبتدئ إلى محترف، ودورة حياة المشروع، والمستويات والتقنيات والمشاريع |
| **المنهج الكامل** `roadmap.html` | 11 مستوى، و 29 كورساً، و 306 دروس بوحداتها |
| **Python لعلم البيانات** | الكورس كاملاً: 3 وحدات، و 28 درساً، واختباران للوحدتين، واختبار نهائي |
| **NumPy** | الكورس كاملاً: وحدتان، و 11 درساً، واختباران |
| **Pandas** | الوحدة الأولى: 9 دروس واختبار |
| **المشروع 1: تحليل مبيعات متجر** | 9 مراحل من دورة حياة المشروع مع حل نموذجي لكل مرحلة، و 4 نقاط تحقق تُصحّح تلقائياً، ومساحة عمل، ومعايير تقييم |
| **Datasets** | `store_sales.csv` (1,700 طلب) مع قاموس بيانات في `datasets/README.md` |

كل درس فيه: شرح، ولماذا، ومتى، وأمثلة قابلة للتشغيل والتعديل، وشرح الكود، والنتيجة المتوقعة، وملاحظات، وأخطاء شائعة مع تصحيحها، وتمرين يُصحّح تلقائياً، وسؤال فهم، وخلاصة.

**المحرر**: Python يعمل داخل المتصفح (Pyodide في Web Worker) مع NumPy و Pandas و Matplotlib، وملفات البيانات، والرسوم البيانية، ومهلة تنفيذ، ورسائل أخطاء عربية، ومدخلات `input()`.

**التقدّم**: ✓ مكتمل، و ▶ الحالي، و 🔒 مقفل، وشريط التقدّم، و"تابع من حيث توقفت"، وحفظ الكود، وتتبع مراحل المشاريع ونقاط التحقق.

## التشغيل

الصفحات تقرأ ملفات JSON وتشغّل Web Worker، لذلك تحتاج خادماً محلياً (فتح الملف مباشرة لا يكفي):

```bash
# من جذر المستودع
python3 -m http.server 8000
# ثم افتح http://localhost:8000/data-science/
```

تشغيل الكود في الدروس يحتاج اتصالاً بالإنترنت أول مرة لتحميل Pyodide (حوالي 10MB، ثم يُخزّن في المتصفح).

## أوامر المحتوى

```bash
node tools/build-pages.mjs          # يولّد صفحات الكورسات والدروس والاختبارات والمشاريع من content/catalog.json
python3 tools/generate_datasets.py  # يعيد توليد ملفات datasets/ (نفس النتيجة دائماً)
python3 tools/check_content.py      # يتحقق من اكتمال المحتوى ويشغّل كل الأمثلة والحلول بـ CPython
PYODIDE_DIR=/path/to/pyodide node tools/check_in_pyodide.mjs   # نفس الفحص داخل Pyodide الحقيقي
```

- `check_content.py` يحتاج Python 3.10+ مع `pip install numpy==2.0.2 pandas==2.2.3 matplotlib==3.8.4` (نفس إصدارات Pyodide 0.27.7).
- `check_in_pyodide.mjs` يحتاج توزيعة Pyodide الكاملة (`pyodide-0.27.7.tar.bz2` من إصدارات Pyodide على GitHub). هذا الفحص مهم لأن Pyodide يعمل بـ 32-bit فقد تختلف بعض المخرجات (مثل نوع الأعداد الصحيحة الافتراضي في NumPy).
