# CodeWay | مسار علم البيانات

منصة تعليمية عربية لتعلم علم البيانات من الصفر حتى المستوى المتقدم، مبنية على الهوية البصرية لـ CodeWay: خلفية داكنة، و Glassmorphism، وتدرجات سماوي/وردي/ذهبي، واتجاه RTL.

## ما الموجود الآن (المرحلة 1)

- **بوابة المسار** `index.html`: ما هو علم البيانات، وماذا ستتعلم وتبني، والمتطلبات، ومسار التعلم التفاعلي (أين أنت الآن)، والمراحل من مبتدئ إلى محترف، ودورة حياة المشروع، والمستويات والتقنيات والمشاريع.
- **المنهج الكامل** `roadmap.html`: 11 مستوى (0 إلى 10)، و 29 كورساً، و 306 دروس بوحداتها.
- **كورس Python لعلم البيانات**: الوحدة الأولى كاملة (16 درساً) واختبارها:
  - كل درس فيه: شرح، ولماذا، ومتى، وأمثلة قابلة للتشغيل والتعديل، وشرح الكود، والنتيجة المتوقعة، وملاحظات، وأخطاء شائعة مع تصحيحها، وتمرين يُصحّح تلقائياً، وسؤال فهم، وخلاصة.
  - اختبار الوحدة: 18 سؤالاً من خمسة أنواع.
- **محرر كود حقيقي**: Python يعمل داخل المتصفح (Pyodide في Web Worker)، مع مهلة تنفيذ، ورسائل أخطاء عربية، ومدخلات `input()`.
- **التقدّم**: ✓ مكتمل، و ▶ الحالي، و 🔒 مقفل، وشريط التقدّم، و"تابع من حيث توقفت"، وحفظ الكود.

## التشغيل

الصفحات تقرأ ملفات JSON وتشغّل Web Worker، لذلك تحتاج خادماً محلياً (فتح الملف مباشرة لا يكفي):

```bash
# من جذر المستودع
python3 -m http.server 8000
# ثم افتح http://localhost:8000/data-science/
```

تشغيل الكود في الدروس يحتاج اتصالاً بالإنترنت أول مرة لتحميل Pyodide (حوالي 10MB، ثم يُخزّن في المتصفح).

## أوامر المحتوى

```bash
node tools/build-pages.mjs       # يولّد صفحات الكورسات والدروس والاختبارات من content/catalog.json
python3 tools/check_content.py   # يتحقق من اكتمال الدروس ويشغّل كل الأمثلة والحلول
```

`check_content.py` يحتاج Python 3.10+ فقط، وأمثلة درس الوحدات التي تستورد NumPy و Pandas تحتاج `pip install numpy pandas`.
