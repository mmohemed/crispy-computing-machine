# ملفات البيانات Datasets

| الملف | الصفوف | المصدر | الترخيص | يُستخدم في |
|---|---|---|---|---|
| `store_sales.csv` | 1,700 | بيانات تعليمية مولّدة بـ `tools/generate_datasets.py` (بذرة ثابتة 2025) | مفتوح للاستخدام التعليمي ضمن CodeWay | مشروع Python الخالص (الوحدة 3)، دروس Pandas، المشروع 1: تحليل مبيعات متجر |
| `products.csv` | 15 | بيانات تعليمية مولّدة (جدول مرجعي للمنتجات) | مفتوح للاستخدام التعليمي ضمن CodeWay | درس الدمج `merge` في Pandas، ودرس دمج المصادر في تنظيف البيانات |
| `employees.csv` | 412 | بيانات تعليمية مولّدة (بذرة 7) **بمشاكل جودة مقصودة** | مفتوح للاستخدام التعليمي ضمن CodeWay | كورس تنظيف البيانات، المشروع 2: تحليل بيانات الموظفين |
| `students.csv` | 600 | بيانات تعليمية مولّدة (بذرة 11) | مفتوح للاستخدام التعليمي ضمن CodeWay | كورس EDA، المشروع 3: تحليل بيانات الطلاب |

> البيانات المولّدة **ليست بيانات شركة حقيقية**. صُمّمت لتحاكي متجراً إلكترونياً سعودياً خلال عام 2025 بأنماط واقعية يكتشفها الطالب بنفسه أثناء التحليل.

## store_sales.csv: قاموس البيانات

كل صف طلب واحد لمنتج واحد.

| العمود | النوع | الوصف | مثال |
|---|---|---|---|
| `order_id` | نص | رقم الطلب الفريد | `ORD-10001` |
| `order_date` | تاريخ (نص `YYYY-MM-DD`) | تاريخ الطلب خلال 2025 | `2025-03-14` |
| `city` | فئة | المدينة: الرياض، جدة، الدمام، مكة، المدينة، أبها | `جدة` |
| `category` | فئة | فئة المنتج: إلكترونيات، ملابس، المنزل، أغذية، كتب | `أغذية` |
| `product` | فئة | اسم المنتج (15 منتجاً) | `تمر فاخر` |
| `unit_price` | عدد صحيح | سعر الوحدة بالريال قبل الخصم | `95` |
| `quantity` | عدد صحيح | الكمية (1 إلى 5) | `2` |
| `discount` | عشري | نسبة الخصم: 0 أو 0.05 أو 0.1 أو 0.2 | `0.1` |
| `payment_method` | فئة | بطاقة، محفظة إلكترونية، الدفع عند الاستلام، تحويل بنكي | `بطاقة` |
| `customer_type` | فئة | جديد أو عائد | `عائد` |
| `rating` | عدد صحيح أو فارغ | تقييم العميل من 1 إلى 5، **فارغ إذا لم يقيّم** (نحو 12%) | `4` |

**العمود المحسوب الأهم:** `revenue = unit_price × quantity × (1 − discount)`، وهو غير موجود في الملف ويحسبه الطالب بنفسه.

## products.csv: قاموس البيانات

جدول مرجعي: صف لكل منتج من منتجات `store_sales.csv` الخمسة عشر. يُربط معه بعمود `product`.

| العمود | النوع | الوصف | مثال |
|---|---|---|---|
| `product` | نص (مفتاح) | اسم المنتج كما في ملف المبيعات | `عسل سدر` |
| `category` | فئة | فئة المنتج | `أغذية` |
| `unit_cost` | عدد صحيح | تكلفة الوحدة على المتجر بالريال | `118` |
| `supplier` | نص | المورّد (مورّد واحد لكل فئة) | `مزارع الواحة` |
| `launch_year` | عدد صحيح | سنة إضافة المنتج للمتجر | `2021` |

**يُستخدم لحساب الربح:** `profit = (unit_price × (1 − discount) − unit_cost) × quantity`.

## employees.csv: قاموس البيانات

بيانات موارد بشرية لشركة خيالية (400 موظف)، **صُممت عمداً لتكون غير نظيفة** مثل ملف يُجمع من عدة أشخاص وأنظمة. الهدف أن يكتشف الطالب المشاكل ويعالجها بقرارات موثقة.

| العمود | النوع بعد التنظيف | الوصف | أمثلة كما في الملف |
|---|---|---|---|
| `emp_id` | نص (مفتاح) | رقم الموظف | `E0104` |
| `name` | نص | الاسم | `سعد الزهراني`، `  نورة الحربي` |
| `gender` | فئة | الجنس | `ذكر`، `أنثى`، `M`، `F` |
| `department` | فئة | القسم (5 أقسام) | `المبيعات`، `Sales`، `مبيعات`، `التقنية `، `IT`، `خدمه العملاء` |
| `city` | فئة | مدينة العمل | `الرياض`، `جدة `، `الدمام` |
| `hire_date` | تاريخ | تاريخ التعيين | `2017-09-12`، `03/05/2021` (يوم/شهر/سنة) |
| `birth_year` | عدد صحيح | سنة الميلاد | `1986` |
| `salary` | عدد صحيح | الراتب الشهري بالريال | `8750`، `14,700`، `6650 SAR`، `غير متوفر`، فارغ |
| `performance` | عدد صحيح 1–5 | تقييم الأداء السنوي | `4` |
| `satisfaction` | عدد 0–10 أو فارغ | الرضا الوظيفي من استبيان | `6`، فارغ |
| `overtime_hours` | عدد صحيح | متوسط ساعات العمل الإضافي شهرياً | `13` |
| `left_company` | منطقي | هل ترك الشركة خلال السنة؟ | `نعم`، `لا`، `Yes`، `No` |

### المشاكل المقصودة (مرجع للمعلم وللتحقق)

| المشكلة | التفاصيل |
|---|---|
| مكررات كاملة | 10 صفوف مكررة حرفياً |
| مكررات بالمفتاح | موظفان مسجلان مرتين بنفس `emp_id` وراتب مختلف (فيصبح `emp_id.duplicated()` = 12) |
| أقسام بأسماء مختلفة | 17 كتابة لخمسة أقسام: إنجليزي، بدون "ال"، مسافات زائدة، "ه" بدل "ة" |
| رواتب كنص | فواصل آلاف `14,700`، ولاحقة `SAR`، و `غير متوفر`، وخلايا فارغة |
| تواريخ بصيغتين | ISO `YYYY-MM-DD` و `DD/MM/YYYY` |
| ترميز مختلط | الجنس `M/F` بجانب العربي، و `Yes/No` بجانب نعم/لا |
| مسافات زائدة | في بعض المدن والأسماء |
| قيم مستحيلة | راتب 98,000,000 وراتب 120، سنة ميلاد 1890، أداء 9 وأداء 0، عمل إضافي −4، تاريخ تعيين 2031 |
| مفقود | الرضا الوظيفي فارغ لنحو 7% من الموظفين |

الأنماط الحقيقية داخل البيانات (يكتشفها الطالب بعد التنظيف): فروق واضحة في الرواتب بين الأقسام، والراتب يرتفع مع سنوات الخبرة، ونسبة ترك العمل أعلى عند الرضا المنخفض والعمل الإضافي الكثير والموظفين الجدد.

## students.csv: قاموس البيانات

بيانات 600 طالب في المرحلة الثانوية لمدارس خيالية. كل صف طالب واحد.

| العمود | النوع | الوصف | مثال |
|---|---|---|---|
| `student_id` | نص (مفتاح) | رقم الطالب | `S0001` |
| `gender` | فئة | ذكر أو أنثى | `أنثى` |
| `school_type` | فئة | حكومية أو أهلية | `حكومية` |
| `city` | فئة | الرياض، جدة، الدمام، أبها | `الدمام` |
| `parent_education` | فئة مرتبة | أعلى تعليم لولي الأمر: ابتدائي، ثانوي، جامعي، دراسات عليا | `جامعي` |
| `study_hours` | عشري أو فارغ | ساعات المذاكرة الأسبوعية خارج المدرسة (فارغ لنحو 4%) | `8.8` |
| `attendance` | عشري | نسبة الحضور % | `90.0` |
| `sleep_hours` | عشري أو فارغ | متوسط ساعات النوم ليلاً (فارغ لنحو 3%) | `6.4` |
| `activities` | نعم/لا | يشارك في نشاط لاصفي | `نعم` |
| `internet` | نعم/لا | لديه إنترنت في المنزل | `نعم` |
| `math`، `science`، `arabic`، `english` | عدد صحيح 0–100 | درجة المادة النهائية | `63` |

الأنماط الحقيقية: ساعات المذاكرة أقوى العوامل ارتباطاً بالمعدل، ثم الحضور ثم النوم، مع أثر لتعليم ولي الأمر وتوفر الإنترنت، بينما الأنشطة اللاصفية لا ترتبط بالدرجات تقريباً. **هذه ارتباطات في بيانات رصدية** ولا تثبت السببية، وهي نقطة يناقشها المشروع 3.

## قواعد إضافة Dataset جديد

1. البيانات المولّدة: أضف دالة في `tools/generate_datasets.py` ببذرة ثابتة، ووثّق الأنماط المقصودة.
2. البيانات الحقيقية: تأكد أن الترخيص يسمح بإعادة التوزيع. إذا لم يسمح (مثل MovieLens) فضع رابط التحميل الرسمي وتعليماته فقط، ولا ترفع الملف.
3. أضف صفاً في الجدول أعلاه وقاموس أعمدة كاملاً.
