# النظام المحاسبي المتكامل

واجهة نظام محاسبي بالعربية (RTL) تعتمد على شاشة رئيسية تعرض الوحدات الرئيسية كأيقونات،
وتبقى القوائم الفرعية **مخفية** ولا تظهر إلا عند الضغط على الأيقونة الرئيسية.

| الوحدة | عدد العناصر الفرعية |
|---|---|
| ⚙️ الإعدادات والإدارة | 9 |

| 🏦 الصندوق والبنوك | 7 |

| 📑 المشاريع والعقود | 5 |
| 📊 التقارير والتحليلات | 6 |

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## البنية

- `index.html` — هيكل الصفحة (الشريط العلوي، مسار التنقل، الشبكة الرئيسية، شاشة المحتوى)
- `js/modules.js` — تعريف الوحدات والقوائم الفرعية (بيانات فقط، سهلة التعديل)
- `js/app.js` — منطق الفتح/الإغلاق والتنقل
- `css/styles.css` — التنسيقات

## السلوك

- الضغط على أيقونة رئيسية يُظهر قائمتها الفرعية، والضغط مرة أخرى يخفيها.
- تُفتح بطاقة واحدة فقط في كل مرة (فتح بطاقة يُغلق البطاقة المفتوحة).
- الضغط على عنصر فرعي يفتح شاشته (حالياً شاشة جاهزة للربط بالوظائف الفعلية).
- زر 🏠 أو «رجوع» يعيدك للشاشة الرئيسية.
