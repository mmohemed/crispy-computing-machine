مناهج المسارات القادمة

هذه المحاور معلنة مسبقاً حتى تعرف إلى أين يقودك المسار قبل أن يُنشر محتواه.

CSS قريباً

تحويل الهيكل الخام إلى واجهة مصمّمة: المحدّدات والوراثة والأولوية، نموذج الصندوق، Flexbox و Grid، التصميم المتجاوب، المتغيّرات، والحركات.

محاور المنهج المخطّطة:

  1. المحدّدات والتتالي والأولوية
  2. نموذج الصندوق والمسافات
  3. الوحدات والألوان والخلفيات
  4. الطباعة والخطوط
  5. Display و Position
  6. Flexbox
  7. CSS Grid
  8. التصميم المتجاوب
  9. المتغيّرات والوضع الليلي
  10. الحركات والانتقالات
المتطلّب السابق: إتمام مسار HTML أو معرفة أساسية بعناصره.

JavaScript قريباً

من المتغيّرات والدوال إلى DOM والأحداث والبرمجة غير المتزامنة والوحدات: كل ما تحتاجه لتحويل صفحة ساكنة إلى تطبيق حي.

محاور المنهج المخطّطة:

  1. المتغيّرات وأنواع البيانات
  2. المعاملات والجمل الشرطية
  3. الحلقات والمصفوفات
  4. الدوال ونطاق المتغيّرات
  5. الكائنات والأصناف
  6. التعامل مع DOM
  7. الأحداث ومعالجاتها
  8. البرمجة غير المتزامنة و fetch
  9. الوحدات (Modules)
  10. مشروع تطبيقي متكامل
المتطلّب السابق: إتمام مساري HTML و CSS.

React قريباً

أشهر مكتبة لبناء الواجهات في العالم: تقسّم الواجهة إلى مكوّنات صغيرة قابلة لإعادة الاستخدام، وتديرها بالحالة والـ Hooks بدل التلاعب المباشر بالـ DOM.

محاور المنهج المخطّطة:

  1. المكوّنات و props
  2. الحالة useState والأحداث
  3. العرض الشرطي والقوائم
  4. النماذج المتحكَّم بها
  5. useEffect وجلب البيانات
  6. useContext ورفع الحالة
  7. useReducer و Hooks مخصّصة
  8. التوجيه ومشروع متكامل
المتطلّب السابق: JavaScript الحديث (ES6+): الدوال السهمية، التفكيك، والمصفوفات.

Vue.js قريباً

يجمع بين بساطة القوالب وقوة نظام التفاعلية. تكتب HTML شبه عادي وتضيف إليه توجيهات، فيتكفّل Vue بتحديث الواجهة عند تغيّر البيانات.

محاور المنهج المخطّطة:

  1. القوالب والتوجيهات
  2. نظام التفاعلية: ref و reactive
  3. المكوّنات و props والأحداث
  4. Composition API و script setup
  5. المراقبون والخصائص المحسوبة
  6. Vue Router
  7. Pinia لإدارة الحالة
  8. مشروع تطبيقي
المتطلّب السابق: HTML و CSS و JavaScript الأساسية.

TypeScript قريباً

إضافة الأنواع الساكنة إلى JavaScript لاكتشاف الأخطاء قبل التشغيل، مع دعم أفضل من المحرّر وأمان أعلى في المشاريع الكبيرة.

محاور المنهج المخطّطة:

  1. لماذا TypeScript؟ والإعداد و tsconfig
  2. الأنواع الأساسية والمصفوفات و Tuples
  3. الواجهات وأنواع الكائنات
  4. الاتحادات والتقاطعات وتضييق النوع
  5. الدوال والمعاملات الاختيارية
  6. Generics والأنواع المشتقة
  7. الأصناف والمعدِّلات
  8. دمجه مع React
المتطلّب السابق: إتقان JavaScript الحديث.

Node.js قريباً

بيئة تشغيل تتيح لك استخدام JavaScript خارج المتصفح: بناء خوادم وواجهات برمجية، التعامل مع الملفات وقواعد البيانات والمصادقة.

محاور المنهج المخطّطة:

  1. ما هو Node.js و npm
  2. الوحدات ونظام الملفات
  3. خادم HTTP و Express
  4. التوجيه والوسطاء
  5. بناء REST API
  6. التحقّق ومعالجة الأخطاء
  7. المصادقة بـ JWT
  8. الاتصال بقاعدة بيانات والنشر
المتطلّب السابق: JavaScript الحديث والبرمجة غير المتزامنة.

Python قريباً

من أسهل اللغات قراءةً وأوسعها استخداماً. في الويب تُستخدم مع Django و Flask لبناء تطبيقات كاملة وواجهات برمجية.

محاور المنهج المخطّطة:

  1. الأساسيات وأنواع البيانات
  2. التحكّم في المسار والحلقات
  3. الدوال والوحدات
  4. الهياكل: القوائم والقواميس
  5. البرمجة الكائنية
  6. التعامل مع الملفات والاستثناءات
  7. مقدمة Flask
  8. مقدمة Django و ORM
المتطلّب السابق: لا يحتاج خبرة برمجية سابقة.

PHP قريباً

تشغّل جزءاً كبيراً من الويب اليوم بما فيه ووردبريس. PHP 8 لغة حديثة بأنواع ومزايا قوية، ومع Laravel تصبح من أسرع أدوات بناء التطبيقات.

محاور المنهج المخطّطة:

  1. الأساسيات وأنواع البيانات
  2. النماذج و superglobals
  3. الدوال والمصفوفات
  4. البرمجة الكائنية في PHP 8
  5. الاتصال بقاعدة البيانات بـ PDO
  6. الجلسات والمصادقة
  7. Composer والحزم
  8. مدخل إلى Laravel
المتطلّب السابق: HTML أساسية.

Java قريباً

لغة كائنية قوية الأنواع تُبنى بها أنظمة البنوك والمؤسسات. مع Spring Boot تصبح بناء الواجهات البرمجية فيها مباشراً وسريعاً.

محاور المنهج المخطّطة:

  1. الأساسيات وأنواع البيانات
  2. التحكّم والمصفوفات
  3. البرمجة الكائنية
  4. الوراثة والواجهات
  5. المجموعات (Collections)
  6. الاستثناءات
  7. مقدمة Spring Boot
  8. بناء REST API
المتطلّب السابق: لا يحتاج خبرة سابقة، لكن الصبر مطلوب.

C# قريباً

لغة كائنية أنيقة وقوية مع منصة .NET. مع ASP.NET Core تبني واجهات برمجية وتطبيقات ويب عالية الأداء ومتعدّدة المنصّات.

محاور المنهج المخطّطة:

  1. الأساسيات والأنواع
  2. التحكّم والمصفوفات
  3. البرمجة الكائنية
  4. LINQ
  5. التعامل غير المتزامن
  6. مقدمة ASP.NET Core
  7. بناء Web API
  8. Entity Framework Core
المتطلّب السابق: أساسيات البرمجة تفيد لكنها ليست شرطاً.

Go قريباً

لغة من جوجل تجمع بساطة الصياغة مع أداء اللغات المترجمة، وتتفوّق في بناء الخدمات المتزامنة والأدوات السحابية.

محاور المنهج المخطّطة:

  1. الأساسيات والأنواع
  2. الدوال والحزم
  3. المصفوفات والخرائط والبنى
  4. الواجهات
  5. التزامن: goroutines و channels
  6. معالجة الأخطاء
  7. خادم HTTP
  8. بناء REST API
المتطلّب السابق: إلمام بأساسيات البرمجة في أي لغة.
