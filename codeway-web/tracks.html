مناهج المسارات القادمة

هذه المحاور معلنة مسبقاً حتى تعرف إلى أين يقودك المسار قبل أن يُنشر محتواه.

TypeScript قريباً

إضافة الأنواع الساكنة إلى JavaScript لاكتشاف الأخطاء قبل التشغيل، مع دعم أفضل من المحرّر وأمان أعلى في المشاريع الكبيرة.

محاور المنهج المخطّطة:

  1. لماذا TypeScript؟ وإعداد المشروع و tsconfig
  2. الأنواع الأساسية والمصفوفات والـ Tuples
  3. الواجهات (interfaces) وأنواع الكائنات
  4. الاتحادات والتقاطعات وتضييق النوع (Narrowing)
  5. الدوال، المعاملات الاختيارية، والحمل الزائد
  6. Generics والأنواع المشتقة (Utility Types)
  7. الأصناف والمعدِّلات والوراثة
  8. الوحدات، ملفات التعريف d.ts، ودمجه مع React
المتطلّب السابق: إتقان JavaScript الحديث.

React قريباً

بناء واجهات معقّدة من مكوّنات صغيرة قابلة لإعادة الاستخدام، مع إدارة الحالة والتأثيرات الجانبية والتوجيه.

محاور المنهج المخطّطة:

  1. مقدمة React و JSX وإعداد المشروع بـ Vite
  2. المكوّنات و props وتمرير البيانات
  3. الحالة useState ودورة حياة المكوّن
  4. التعامل مع الأحداث والنماذج المتحكَّم بها
  5. القوائم والمفاتيح والعرض الشرطي
  6. useEffect وجلب البيانات
  7. useContext و useReducer لإدارة الحالة
  8. Hooks مخصّصة و useMemo و useCallback
  9. React Router والتوجيه بين الصفحات
  10. مشروع تطبيقي متكامل
المتطلّب السابق: JavaScript الحديث (ES6+) بشكل جيد.

Vue.js قريباً

إطار عمل للواجهات يجمع بين بساطة القوالب وقوة نظام التفاعلية، مناسب للمشاريع الصغيرة والكبيرة.

محاور المنهج المخطّطة:

  1. مقدمة Vue وإعداد المشروع
  2. القوالب والتوجيهات (v-bind, v-if, v-for)
  3. نظام التفاعلية: ref و reactive و computed
  4. المكوّنات، props، والأحداث المخصّصة
  5. Composition API و <script setup>
  6. المراقبون watch و watchEffect
  7. Vue Router و Pinia لإدارة الحالة
  8. مشروع تطبيقي متكامل
المتطلّب السابق: JavaScript الحديث.

Tailwind CSS قريباً

بناء تصاميم مخصّصة بسرعة من خلال أصناف مساعدة صغيرة بدلاً من كتابة CSS من الصفر.

محاور المنهج المخطّطة:

  1. فلسفة Utility-First والتثبيت
  2. المسافات والألوان والخطوط
  3. Flexbox و Grid في Tailwind
  4. التجاوب والحالات (hover, focus, dark)
  5. تخصيص الثيم في tailwind.config
  6. المكوّنات وإعادة الاستخدام و @apply
  7. التحسين للإنتاج
المتطلّب السابق: أساسيات CSS جيدة.

Node.js قريباً

بناء خوادم وواجهات برمجية (APIs) باستخدام JavaScript، والتعامل مع الملفات والطلبات والمصادقة وقواعد البيانات.

محاور المنهج المخطّطة:

  1. ما هو Node.js وكيف يعمل؟ npm والحزم
  2. الوحدات ونظام الملفات والمسارات
  3. خادم HTTP من الصفر ثم Express
  4. التوجيه والوسطاء (Middleware)
  5. بناء REST API كامل (CRUD)
  6. التحقق من المدخلات ومعالجة الأخطاء
  7. المصادقة بـ JWT وتشفير كلمات المرور
  8. الاتصال بقاعدة بيانات ونشر التطبيق
المتطلّب السابق: JavaScript الحديث والبرمجة غير المتزامنة.

SQL قريباً

تصميم قواعد بيانات علائقية سليمة وكتابة استعلامات فعّالة لاسترجاع البيانات وتحديثها.

محاور المنهج المخطّطة:

  1. مفاهيم قواعد البيانات العلائقية
  2. إنشاء الجداول وأنواع البيانات والقيود
  3. SELECT و WHERE و ORDER BY و LIMIT
  4. الدوال التجميعية و GROUP BY و HAVING
  5. العلاقات وأنواع JOIN
  6. الاستعلامات الفرعية والـ Views
  7. الفهارس وتحسين الأداء
  8. المعاملات (Transactions) وسلامة البيانات
المتطلّب السابق: لا يحتاج خبرة سابقة.

Git & GitHub قريباً

تتبّع تغييرات مشروعك، العودة لأي نقطة في الماضي، والعمل مع فريق دون أن يفقد أحد عمله.

محاور المنهج المخطّطة:

  1. لماذا Git؟ التثبيت والإعداد الأولي
  2. دورة العمل: add و commit و status و log
  3. الفروع والدمج وحل التعارضات
  4. العمل مع مستودع بعيد: push و pull و fetch
  5. GitHub: المستودعات وطلبات السحب والمراجعة
  6. التراجع عن الأخطاء: revert و reset و stash
  7. أفضل ممارسات رسائل الـ commit وسير العمل
المتطلّب السابق: لا يحتاج خبرة سابقة.

أدوات البناء والنشر قريباً

أدوات التجميع والتحسين، وأدوات المطوّر في المتصفح، وقياس الأداء، ثم نشر المشروع على الإنترنت.

محاور المنهج المخطّطة:

  1. npm و package.json وإدارة الاعتماديات
  2. Vite: خادم التطوير وبناء الإنتاج
  3. أدوات المطوّر في المتصفح (DevTools)
  4. قياس الأداء و Lighthouse
  5. تحسين الصور والخطوط والتحميل
  6. النشر على GitHub Pages و Netlify و Vercel
  7. أساسيات SEO التقنية
المتطلّب السابق: أساسيات HTML/CSS/JS.
