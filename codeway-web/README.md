# CodeWay Web — منصّة تعليمية عربية لتطوير الويب

منصّة تعليمية متكاملة لتعلّم تطوير الويب باللغة العربية، مبنيّة بمولّد مواقع
ثابتة مكتوب من الصفر بلغة JavaScript — **بلا أي اعتمادية خارجية**.

## المسارات المنشورة

| المسار | الدروس | المستوى |
|---|---|---|
| HTML5 | 20 | مبتدئ ← متقدم |
| Angular | 10 | متوسط ← احترافي |
| Sass | 10 | متوسط ← متقدم |
| Tailwind CSS | 10 | مبتدئ ← متقدم |
| Ruby | 10 | مبتدئ ← احترافي |
| Laravel | 10 | مبتدئ ← احترافي |
| SQL | 10 | مبتدئ ← متقدم |

**المجموع: 80 درساً · 70 ساعة · 80 تمريناً عملياً**

## ما يميّز المحتوى

- شرح عربي كامل بمصطلحات دقيقة ومتّسقة عبر كل المسارات
- أمثلة عملية قابلة للتشغيل في كل درس
- مقارنات **✗ سيّئ / ✓ جيّد** تشرح *لماذا* لا *ماذا* فقط
- عروض حيّة داخل `iframe` معزول (لا سكربتات خارجية)
- تمرين شامل بحلّ كامل في نهاية كل درس
- اختبار ذاتي بـ 5–7 أسئلة مع شرح لكل إجابة
- مرجع سريع وأهداف تعلّم واضحة في كل درس

## التشغيل

```bash
node tools/build.js       # يولّد كل صفحات الموقع
```

ثم افتح `index.html` مباشرة في المتصفّح — الموقع يعمل بلا خادم.

## كتابة درس جديد

كل درس ملف JavaScript واحد يُصدّر كائناً:

```js
'use strict';

module.exports = {
  slug: '01-introduction',
  title: 'عنوان الدرس',
  summary: 'وصف مختصر يظهر في بطاقة الدرس.',
  duration: 45,                    // بالدقائق
  level: 'مبتدئ',                  // مبتدئ | متوسط | متقدم | احترافي
  tags: ['وسم', 'وسم آخر'],
  objectives: ['ما سيتقنه المتعلّم بعد الدرس.'],
  quickRef: [{ code: 'syntax', desc: 'الشرح' }],
  blocks: [ /* … */ ]
};
```

ثم أضِف `require('./01-introduction.js')` إلى `content/<track>/index.js`.

### أنواع البلوكات

| النوع | الاستخدام |
|---|---|
| `h2` `h3` | عناوين — تُبنى منها فهرسة الدرس تلقائياً |
| `p` | فقرة — تدعم `` `code` `` و `**عريض**` و `[نصّ](رابط)` |
| `ul` `ol` `steps` | قوائم عادية ومرقّمة وخطوات |
| `code` | كتلة شيفرة ملوّنة — `{ lang, code }` |
| `demo` | عرض حيّ داخل iframe — `{ title, html, css, js, height }` |
| `table` | جدول — `{ head: [], rows: [[]] }` |
| `compare` | مقارنة سيّئ/جيّد — `{ lang, bad: {code, why}, good: {…} }` |
| `note` `tip` `warn` `danger` | صناديق تنبيه بأربعة مستويات |
| `features` | بطاقات مزايا بأيقونات |
| `quiz` | أسئلة — `{ q, options, answer, explain }` |
| `exercise` | تمرين — `{ title, brief, requirements, hints, solution }` |

## التقنيات

مكتوب بـ **Node.js خالص بلا أي حزمة npm**. الاعتمادية الخارجية الوحيدة
في الصفحات المُولَّدة هي خطّا Google Fonts (Cairo و JetBrains Mono)،
ولكلٍّ منهما بديل نظامي كامل إن تعذّر تحميلهما.

- تلوين الصياغة: محرّك خاص يدعم HTML و CSS/Sass و JS/TS و JSON و Bash و SQL و Ruby و PHP/Blade
- الأيقونات: 49 أيقونة SVG مضمّنة في الصفحة — لا Font Awesome ولا طلبات شبكة
- السمة: فاتحة وداكنة عبر `[data-theme]` مع احترام `prefers-color-scheme`
- الاتجاه: RTL أصيل بخصائص CSS المنطقية (`padding-inline`, `inset-inline`)
- الوصولية: روابط تخطّي، `focus-visible`، ARIA، واحترام `prefers-reduced-motion`
- التقدّم: يُحفظ في `localStorage` لكل درس

## نسخة الملف الواحد (للمشاركة والمعاينة)

```bash
node tools/bundle.js          # ينتج preview.html
```

يجمع المُجمِّع كل الصفحات الـ 91 والأنماط والسكربتات في ملف HTML واحد
(~6.4 ميغابايت) بموجّه داخلي يعمل بعناوين `#/`، فتتصفّح الموقع كاملاً
من ملف واحد بلا خادم وبلا مجلّدات — مفيد للمشاركة أو الرفع السريع.
