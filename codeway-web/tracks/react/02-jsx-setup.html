إعداد المشروع و JSX

إنشاء مشروع React بـ Vite، وفهم JSX: قواعده وفروقه عن HTML وكيف يتحوّل إلى جافاسكربت.

45 دقيقة مسار React 5 أسئلة 1 تمرين

ماذا ستتعلّم في هذا الدرس؟

  • تنشئ مشروع React جاهزاً بأمر واحد.
  • تفهم بنية ملفات المشروع ودور كل ملف.
  • تكتب JSX بقواعده الصحيحة.
  • تدمج تعابير جافاسكربت داخل الواجهة.
  • تتجنّب أشهر أخطاء JSX.

إنشاء المشروع

أسرع طريقة اليوم هي Vite: أداة بناء سريعة جداً تجهّز لك كل شيء (المترجم، خادم التطوير، إعادة التحميل الفوري) في ثوانٍ.

الأوامرbash
# 1) إنشاء المشروع
npm create vite@latest my-app -- --template react

# 2) الدخول وتثبيت الاعتماديات
cd my-app
npm install

# 3) تشغيل خادم التطوير
npm run dev
# افتح http://localhost:5173

# 4) بناء نسخة الإنتاج لاحقاً
npm run build
معلومة

تحتاج Node.js مثبّتاً على جهازك (نسخة 18 فأحدث). تحقّق بـ node -v. أمر npm create vite يسألك عن الإطار واللغة إن لم تمرّرهما في الأمر.

كل تطبيقك يعيش داخل <div id="root"> واحد. هذا ما يُسمّى تطبيق صفحة واحدة (SPA): صفحة HTML واحدة، وReact ترسم كل شيء داخلها.

نصيحة

StrictMode أداة تطوير تكشف مشاكل محتملة. تشغّل بعض الدوال مرتين عمداً في وضع التطوير لتكشف الآثار الجانبية — لا تقلق، هذا لا يحدث في الإنتاج.

ما هو JSX؟

JSX صياغة تسمح بكتابة ما يشبه HTML داخل جافاسكربت. ليست HTML ولا نصاً — بل صياغة تُترجَم إلى استدعاءات دوال.

ما تكتبهjsx
const el = <h1 className="title">مرحباً</h1>;
ما يُترجَم إليه فعلاًjs
const el = React.createElement(
  'h1',
  { className: 'title' },
  'مرحباً'
);

لهذا السبب توجد فروق عن HTML: أنت تكتب كائنات جافاسكربت في النهاية، لا نصاً يفسّره المتصفح.

قواعد JSX الست

1. عنصر جذر واحد

✗ خطأ
jsx
function App() {
  return (
    <h1>عنوان</h1>
    <p>فقرة</p>
  );
}
الدالة لا تستطيع إرجاع قيمتين. خطأ ترجمة مباشر.
✓ صواب
jsx
function App() {
  return (
    <>
      <h1>عنوان</h1>
      <p>فقرة</p>
    </>
  );
}
الجزء <>…</> يجمعهما دون إضافة عنصر إلى DOM.
معلومة

يمكن استخدام <div> بدل <>، لكن الجزء (Fragment) أفضل لأنه لا يلوّث بنية HTML بعناصر لا داعي لها.

2. إغلاق كل الوسوم

jsx
<img src="a.png" alt="صورة" />   {/* لاحظ / في النهاية */}
<br />
<input type="text" />
<hr />

4. الأقواس المعقوفة للتعابير

jsx
function Greeting() {
  const name = 'سارة';
  const hour = new Date().getHours();
  const user = { age: 25, city: 'الرياض' };

  return (
    <div>
      <h1>مرحباً {name}</h1>
      <p>الساعة الآن {hour}</p>
      <p>العمر بعد عام: {user.age + 1}</p>
      <p>{hour < 12 ? 'صباح الخير' : 'مساء الخير'}</p>
      <img src={user.avatar} alt={`صورة ${name}`} />
    </div>
  );
}
تعابير لا جُمل

داخل {} يمكن وضع تعبير يُنتج قيمة فقط. لا يمكن وضع if أو for أو switch. استخدم المعامل الثلاثي ? : أو أخرج المنطق قبل return.

5. الأنماط ككائن

jsx
{/* قوسان: الأول للتعبير والثاني للكائن */}
<div style={{ color: 'red', fontSize: '20px', marginTop: 12 }}>
  نص منسّق
</div>

{/* الأفضل: أصناف CSS */}
<div className="alert alert-error">نص منسّق</div>
  • أسماء الخصائص camelCase: backgroundColor لا background-color.
  • القيم نصوص، والأرقام المجرّدة تُفسَّر كبكسل: marginTop: 12 تعني 12px.
  • استخدم الأنماط المضمّنة للقيم الديناميكية فقط، وأصناف CSS لكل ما عداها.

أول مكوّن حقيقي

src/App.jsxjsx
import './App.css';

function App() {
  const user = { name: 'سارة', lessons: 12, total: 20 };
  const progress = Math.round((user.lessons / user.total) * 100);

  return (
    <main className="app">
      <h1>أهلاً {user.name} 👋</h1>

      <p>
        أكملت {user.lessons} من {user.total} درساً
        ({progress}%)
      </p>

      <progress value={user.lessons} max={user.total} />

      <p>{progress >= 50 ? 'أنت في منتصف الطريق!' : 'البداية دائماً أصعب خطوة.'}</p>
    </main>
  );
}

export default App;
النتيجة

أخطاء JSX الشائعة

الخطأرسالة المتصفح غالباًالحل
عنصران جذرانAdjacent JSX elements must be wrappedلفّهما في <>…</>
class بدل classNameتحذير في وحدة التحكّماستخدم className
نسيان / في العنصر الفارغUnterminated JSX contentsأغلق: <img />
if داخل {}Unexpected tokenاستخدم ? : أو أخرج المنطق
قوس واحد للأنماطstyle غير صالحstyle={{ … }} بقوسين
استدعاء الدالة بدل تمريرهاتُنفَّذ فوراً وتُعيد الرسم بلا نهايةonClick={handle} لا onClick={handle()}
خطأ الاستدعاء المبكر

onClick={handleClick()} تستدعي الدالة فور الرسم وتمرّر نتيجتها. الصواب onClick={handleClick} أو onClick={() => handleClick(id)} إن احتجت تمرير معامل.

قيم لا تُعرض

React تتجاهل عند العرض: null و undefined و false و true. هذا مفيد للعرض الشرطي:

jsx
{isLoggedIn && <button>تسجيل الخروج</button>}
{error && <p className="error">{error}</p>}
فخّ الصفر

الرقم 0 يُعرض. فكتابة {items.length && <List />} تطبع «0» على الشاشة حين تكون القائمة فارغة. الحل: {items.length > 0 && <List />}.

تمرين: بطاقة تعريف بمكوّن

أنشئ مشروع React جديداً واستبدل محتوى App.jsx ببطاقة تعريف بك.

المطلوب:

  • أنشئ المشروع بـ Vite وشغّله.
  • عرّف كائن profile فيه: الاسم، المهنة، المدينة، سنوات الخبرة، ومصفوفة skills.
  • اعرض الاسم في <h1> والمهنة في <p>.
  • احسب واعرض «سنة الميلاد التقريبية» من تعبير جافاسكربت.
  • اعرض رسالة مختلفة حسب سنوات الخبرة (أقل من 3 = «في بداية الطريق»).
  • استخدم <>…</> مرة واحدة على الأقل.
  • أضف عنصراً بنمط مضمّن يعتمد على قيمة من الكائن (لون يتغيّر مثلاً).
  • أضف تعليقاً بصيغة JSX الصحيحة.

تلميحات:

  • 💡 لعرض المصفوفة مؤقتاً استخدم {profile.skills.join(" · ")}.
  • 💡 الأنماط المضمّنة بقوسين: style={{ color: someVar }}.
  • 💡 لا تستخدم class — استخدم className.
عرض الحل المقترح
الحلjsx
import './App.css';

function App() {
  const profile = {
    name: 'سارة عبدالله',
    job: 'مطوّرة واجهات أمامية',
    city: 'الرياض',
    years: 3,
    skills: ['HTML', 'CSS', 'JavaScript', 'React']
  };

  const currentYear = new Date().getFullYear();
  const startYear = currentYear - profile.years;
  const isJunior = profile.years < 3;

  return (
    <main className="card">
      {/* الترويسة */}
      <h1>{profile.name}</h1>
      <p className="job">{profile.job} — {profile.city}</p>

      <>
        <p>بدأت العمل تقريباً عام {startYear}.</p>
        <p style={{ color: isJunior ? '#f59e0b' : '#10b981', fontWeight: 700 }}>
          {isJunior ? 'في بداية الطريق' : 'خبرة راسخة'}
        </p>
      </>

      <p><strong>المهارات:</strong> {profile.skills.join(' · ')}</p>

      {profile.skills.length > 0 && (
        <p>عدد المهارات: {profile.skills.length}</p>
      )}
    </main>
  );
}

export default App;
لاحظ profile.skills.length > 0 لا profile.skills.length وحدها — تفادياً لفخّ الصفر.

اختبر فهمك

1. لماذا نكتب className بدل class في JSX؟

الشرح: JSX يُترجَم إلى جافاسكربت، فلا يمكن استخدام كلماتها المحجوزة كأسماء خصائص.

2. ما الخطأ في <div style={color: "red"}>؟

الشرح: القوس الأول لفتح تعبير JSX، والثاني لكائن الأنماط.

3. ماذا يحدث في onClick={handleClick()}؟

الشرح: الأقواس تعني الاستدعاء الفوري؛ الصواب تمرير المرجع أو لفّه في دالة سهمية.

4. لماذا نستخدم <>…</>؟

الشرح: الدالة تُرجع قيمة واحدة؛ الجزء يجمّع العناصر دون تلويث بنية HTML.

5. ما نتيجة {items.length && <List />} حين تكون القائمة فارغة؟

الشرح: الصفر قيمة تُعرض في React؛ استخدم items.length > 0 && بدلاً منها.
