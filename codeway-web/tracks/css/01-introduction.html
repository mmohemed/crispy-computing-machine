مقدمة في CSS وطرق ربطها

ما هي CSS ولماذا فُصلت عن HTML، وكيف تكتب أول قاعدة، وثلاث طرق لربط الأنماط بصفحتك.

40 دقيقة مسار CSS 5 أسئلة 1 تمرين

ماذا ستتعلّم في هذا الدرس؟

  • تشرح دور CSS وعلاقتها بـ HTML.
  • تكتب قاعدة CSS وتعرف أجزاءها بالاسم.
  • تربط الأنماط بثلاث طرق وتعرف أيها الصحيح.
  • تفهم معنى «التتالي» في اسم اللغة.
  • تستخدم أدوات المطوّر لفحص الأنماط.

ما هي CSS؟

اختصار Cascading Style Sheets أي «صفحات الأنماط المتتالية». هي اللغة التي تصف بها كيف تبدو عناصر HTML: الألوان، الأحجام، المسافات، التخطيط، الحركة، والتجاوب مع أحجام الشاشات المختلفة.

HTML تقول: «هذا عنوان وهذه فقرة». CSS تقول: «العناوين بلون بنفسجي وحجم 32 بكسل، والفقرات بمسافة سطر 1.8 ولون رمادي داكن».

نفس HTML بلا CSS ومعها

لماذا فُصلت عن HTML؟

في التسعينيات كان التنسيق يُكتب داخل HTML نفسها بوسوم مثل <font color="red">. تخيّل موقعاً من 500 صفحة أردت تغيير لونه الأساسي: كنت ستعدّل 500 ملف. الفصل حلّ هذا:

تعديل واحد يطال الكل

ملف CSS واحد يخدم آلاف الصفحات — سطر واحد يغيّر الموقع كله.

أداء أفضل

الملف يُحمَّل مرة ويُخزَّن مؤقتاً، فتصبح الصفحات التالية أسرع.

عمل جماعي

المصمّم يعمل على CSS والمطوّر على البنية دون تعارض.

تصاميم متعدّدة

نفس HTML بتصميم مختلف للشاشة والطباعة والجوال.

تشريح قاعدة CSS

أجزاء القاعدةcss
h1 {
  color: #6366f1;
  font-size: 32px;
}

/*
  h1 ............... المحدّد (Selector) — على من نطبّق؟
  { … } ............ كتلة الإعلانات (Declaration block)
  color ............ الخاصية (Property) — ماذا نغيّر؟
  #6366f1 .......... القيمة (Value) — إلى ماذا؟
  color: #6366f1; .. إعلان واحد (Declaration)
  ; ................ يفصل بين الإعلانات — لا تنسه
*/
انتبه

الفاصلة المنقوطة ; بعد كل إعلان إلزامية عملياً. نسيانها في إعلان يبطله هو والذي يليه، وهذا سبب شائع جداً لأخطاء «التنسيق لا يعمل».

يمكن تجميع محدّدات متعدّدة بفاصلة، وتطبيق عدة إعلانات دفعة واحدة:

css
h1, h2, h3 {
  font-family: 'Cairo', sans-serif;
  line-height: 1.4;
}

ثلاث طرق للربط

1. ملف خارجي — الطريقة الصحيحة

index.htmlhtml
<head>
  <link rel="stylesheet" href="assets/css/style.css">
</head>
assets/css/style.csscss
body {
  font-family: 'Cairo', sans-serif;
  background: #f6f7fb;
  color: #0f172a;
}

ملف مستقل يخدم كل الصفحات، يُخزَّن في ذاكرة المتصفح المؤقتة، وسهل الصيانة. هذه هي الطريقة التي ستستخدمها في 99٪ من الحالات.

2. أنماط داخلية

html
<head>
  <style>
    body { background: #f6f7fb; }
  </style>
</head>

تصلح لصفحة واحدة مستقلة، أو لأنماط حرجة صغيرة تريد ظهورها فوراً قبل تحميل الملف الخارجي (تُسمّى Critical CSS). لا تصلح لمشروع متعدّد الصفحات.

3. أنماط مضمّنة — تجنّبها

html
<p style="color: red; font-size: 20px;">نص</p>
لماذا نتجنّبها؟

تخلط المظهر بالبنية، ولا يمكن إعادة استخدامها، وتحمل أولوية عالية جداً يصعب تجاوزها فتدفعك إلى !important، ولا تستفيد من التخزين المؤقت. استثناؤها الوحيد: قيمة ديناميكية تحسبها جافاسكربت لحظياً.

الطريقةإعادة الاستخدامالأولويةمتى
ملف خارجيممتازةعاديةدائماً تقريباً
<style> داخليضمن الصفحة فقطعاديةصفحة مفردة أو أنماط حرجة
style= مضمّنمعدومةعالية جداًقيم ديناميكية من جافاسكربت فقط

ماذا يعني «المتتالية»؟

الاسم يصف آلية جوهرية: عندما تتنافس عدة قواعد على نفس العنصر، هناك نظام ترتيب يقرّر الفائزة. مبدئياً:

  1. أهمية أعلى — قاعدة عليها !important تسبق غيرها.
  2. خصوصية أعلى — المحدّد الأكثر تحديداً يفوز.
  3. الأخيرة تفوز — عند تساوي كل شيء، تفوز القاعدة المكتوبة لاحقاً.
css
p { color: blue; }
p { color: red; }   /* هذه تفوز — كُتبت أخيراً */
من يفوز؟
معلومة

سنخصّص درساً كاملاً (الدرس الثالث) لهذا الموضوع لأنه سبب معظم لحظات الحيرة عند المبتدئين: «لماذا لا يعمل هذا النمط؟».

الوراثة

بعض الخصائص تنتقل من الأب إلى أبنائه تلقائياً — أغلبها خصائص النصوص:

css
body {
  font-family: 'Cairo', sans-serif;
  color: #0f172a;
  line-height: 1.8;
}
/* كل عناصر الصفحة سترث هذه الخصائص */
تُورَثلا تُورَث
color, font-*, line-heightmargin, padding, border
text-align, directionwidth, height, display
visibility, cursorbackground, position, overflow
نصيحة

اضبط خصائص النصوص على body مرة واحدة ودع الوراثة تعمل، بدل تكرارها في كل عنصر.

التعليقات

css
/* تعليق من سطر واحد */

/*
  تعليق متعدّد الأسطر
  يُستخدم لفصل الأقسام
*/

/* ===== الترويسة ===== */
.header { … }
انتبه

CSS لا تعرف // للتعليق. كتابتها تكسر السطر الذي يليها. الصيغة الوحيدة هي / … /.

أدوات المطوّر: صديقك الدائم

اضغط F12 (أو انقر بالزر الأيمن ← فحص). في تبويب Elements ترى شجرة HTML، وبجوارها لوحة Styles التي تعرض:

  • كل القواعد المطبّقة على العنصر مرتّبة حسب الأولوية.
  • القواعد المشطوبة — تلك التي خسرت المنافسة.
  • مخطّط نموذج الصندوق بأبعاده الفعلية.
  • إمكانية تعديل القيم مباشرة ورؤية النتيجة فوراً.
نصيحة

عادة المحترفين: جرّب في أدوات المطوّر أولاً حتى تصل للنتيجة، ثم انقل القيم النهائية إلى ملفك. أسرع بكثير من دورة «عدّل ← احفظ ← حدّث».

تمرين: تنسيق أول صفحة

خذ صفحة about-me.html التي أنشأتها في مسار HTML، وأضف لها ملف CSS خارجياً.

المطلوب:

  • أنشئ assets/css/style.css واربطه بالصفحة.
  • اضبط على body: خط، لون نص، لون خلفية، وارتفاع سطر — ولاحظ الوراثة.
  • لوّن <h1> بلون مختلف وكبّر حجمه.
  • اجعل الفقرات بلون رمادي أفتح.
  • أضف تعليقاً يفصل بين أقسام الملف.
  • جرّب إضافة style="color: green" مضمّنة على فقرة، ولاحظ أنها تتغلّب على الملف — ثم احذفها.

تلميحات:

  • 💡 الخصائص الأساسية: font-family, color, background, line-height, font-size.
  • 💡 استخدم أدوات المطوّر لفحص أي نمط يُطبَّق فعلاً.
  • 💡 إن لم يعمل الملف، تحقّق من مسار href في تبويب Network.
عرض الحل المقترح
assets/css/style.csscss
/* ===== الأساسيات ===== */
body {
  font-family: 'Cairo', 'Segoe UI', sans-serif;
  background: #f6f7fb;
  color: #334155;
  line-height: 1.8;
  max-width: 720px;
  margin: 40px auto;
  padding: 0 20px;
}

/* ===== العناوين ===== */
h1 {
  color: #6366f1;
  font-size: 40px;
  margin-bottom: 16px;
}

/* ===== النصوص ===== */
p {
  color: #64748b;
  margin-bottom: 16px;
}
لاحظ أن الفقرات ورثت الخط وارتفاع السطر من body ولم نكرّرهما.

اختبر فهمك

1. ما الطريقة الموصى بها لربط CSS؟

الشرح: الملف الخارجي قابل لإعادة الاستخدام والتخزين المؤقت وسهل الصيانة.

2. أي خاصية تُورَث تلقائياً من الأب؟

الشرح: خصائص النصوص كـ color و font-family و line-height تُورَث؛ خصائص الصندوق لا تُورَث.

3. ما الخطأ في p { color: red } بلا فاصلة منقوطة قبل إعلان آخر؟

الشرح: المحلّل لا يعرف أين انتهى الإعلان فيتجاهل ما بعده حتى الفاصلة التالية.

4. ماذا تعني كلمة Cascading في اسم اللغة؟

الشرح: التتالي هو خوارزمية الأهمية والخصوصية وترتيب المصدر التي تحسم التعارضات.

5. كيف تكتب تعليقاً في CSS؟

الشرح: الصيغة الوحيدة المدعومة في CSS هي / … /.
