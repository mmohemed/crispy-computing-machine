المحدّدات (Selectors)

كيف تستهدف بالضبط العنصر الذي تريده: محدّدات العناصر والأصناف والسمات والعلاقات والزائفة.

50 دقيقة مسار CSS 5 أسئلة 1 تمرين

ماذا ستتعلّم في هذا الدرس؟

  • تستخدم محدّدات العنصر والصنف والمعرّف بشكل صحيح.
  • تجمع المحدّدات وتربطها بعلاقات الأب والأخ.
  • تستهدف العناصر بسماتها.
  • تستخدم الأصناف الزائفة للحالات التفاعلية.
  • تكتب محدّدات بسيطة قابلة للصيانة.

المحدّد هو السؤال

كل قاعدة CSS تبدأ بسؤال: على من نطبّق؟ المحدّد هو صياغة هذا السؤال. إتقان المحدّدات يعني أن تصل إلى أي عنصر في صفحتك بدقّة ودون آثار جانبية.

المحدّدات الأساسية

css
/* 1) محدّد العنصر — كل الفقرات */
p { color: #334155; }

/* 2) محدّد الصنف — كل ما يحمل class="card" */
.card { border-radius: 12px; }

/* 3) محدّد المعرّف — العنصر ذو id="hero" */
#hero { min-height: 400px; }

/* 4) المحدّد الشامل — كل عنصر */
* { box-sizing: border-box; }
المحدّديستهدفالخصوصيةالاستخدام
pكل عناصر pمنخفضة (0,0,1)أنماط أساسية عامة
.cardكل ما يحمل الصنفمتوسطة (0,1,0)الأساس في كل مشروع
#heroعنصر واحد فقطعالية (1,0,0)نادراً — تجنّبه في التنسيق
*كل شيءصفر (0,0,0)إعادة الضبط فقط
لماذا نتجنّب `#id` في التنسيق؟

خصوصيته عالية جداً: قاعدة #hero { color: red } لا يمكن تجاوزها بأي عدد من الأصناف. هذا يدفعك لاحقاً إلى !important وتبدأ سلسلة من الفوضى. احتفظ بـ id للروابط الداخلية وربط label وجافاسكربت.

الجمع والتقاطع

css
/* جمع: تطبيق على عدة محدّدات (أو) */
h1, h2, h3 { font-weight: 800; }

/* تقاطع: عنصر يحقّق كل الشروط (و) — بلا مسافات */
a.btn { padding: 12px 24px; }        /* رابط + صنف btn */
.card.featured { border-color: gold; } /* صنفان معاً */
input[type="email"].large { … }
الفرق بين المسافة وعدمها
فرق حاسم

.a.b تعني «عنصر يحمل الصنفين معاً». أما .a .b (بمسافة) فتعني «عنصر بصنف b داخل عنصر بصنف a». المسافة تغيّر المعنى كلياً.

محدّدات العلاقات

css
/* السليل: أي p داخل .card مهما عمق التداخل */
.card p { margin-bottom: 12px; }

/* الابن المباشر: p ابن مباشر لـ .card فقط */
.card > p { font-size: 18px; }

/* الأخ التالي المباشر: أول p بعد h2 مباشرة */
h2 + p { margin-top: 0; }

/* كل الأشقاء التاليين: كل p بعد h2 ضمن نفس الأب */
h2 ~ p { color: #64748b; }
العلاقات بصرياً
الرمزالاسمالمعنى
A BسليلB داخل A على أي عمق
A > Bابن مباشرB ابن مباشر لـ A فقط
A + Bأخ تالٍ مباشرB يلي A مباشرة في نفس الأب
A ~ Bأخ تالٍ عامكل B بعد A في نفس الأب

محدّدات السمات

css
/* وجود السمة */
[disabled] { opacity: .5; }

/* قيمة مطابقة تماماً */
[type="email"] { direction: ltr; }

/* يبدأ بـ */
[href^="https://"] { color: #10b981; }

/* ينتهي بـ */
[href$=".pdf"]::after { content: " (PDF)"; }

/* يحتوي */
[class*="col-"] { float: right; }

/* كلمة ضمن قائمة مفصولة بمسافات */
[data-tags~="css"] { … }

/* غير حسّاس لحالة الأحرف */
[type="EMAIL" i] { … }
تمييز الروابط بأنواعها
نصيحة

محدّدات السمات قوية جداً مع data-*: [data-state="open"] تتيح لك تغيير مظهر مكوّن كامل بتبديل سمة واحدة من جافاسكربت.

الأصناف الزائفة (Pseudo-classes)

تستهدف العنصر في حالة معيّنة لا يمكن التعبير عنها بالترميز وحده.

الحالات التفاعلية

css
a:hover        { text-decoration: underline; }
a:focus-visible { outline: 3px solid #6366f1; }
a:active       { transform: scale(.97); }
a:visited      { color: #7c3aed; }

button:disabled { opacity: .5; cursor: not-allowed; }
input:checked   { … }
input:required  { … }
input:user-invalid { border-color: #ef4444; }
مرّر المؤشّر واضغط

المحدّدات البنيوية

css
li:first-child  { … }   /* أول ابن */
li:last-child   { … }   /* آخر ابن */
li:only-child   { … }   /* الابن الوحيد */
li:nth-child(3) { … }   /* الثالث */
li:nth-child(odd)  { … }  /* الفردي */
li:nth-child(even) { … }  /* الزوجي */
li:nth-child(3n)   { … }  /* كل ثالث */
li:nth-child(n+4)  { … }  /* من الرابع فصاعداً */
li:nth-last-child(2) { … } /* الثاني من النهاية */

p:first-of-type { … }   /* أول p بين أشقائه */
:not(.active)   { … }   /* كل ما ليس active */
:empty          { … }   /* عنصر بلا محتوى */
تلوين الصفوف بالتناوب
كيف تقرأ `nth-child(an+b)`؟

عوّض n بـ 0 ثم 1 ثم 2 وهكذا. مثال 3n+1 يعطي 1, 4, 7, 10… ومثال -n+3 يعطي 3, 2, 1 أي «أول ثلاثة فقط».

العناصر الزائفة (Pseudo-elements)

تُكتب بنقطتين :: وتنشئ جزءاً وهمياً من العنصر لم يوجد في HTML.

css
.quote::before { content: "«"; color: #6366f1; }
.quote::after  { content: "»"; color: #6366f1; }

p::first-line   { font-weight: 700; }
p::first-letter { font-size: 3em; float: right; }
::selection     { background: #6366f1; color: #fff; }
input::placeholder { color: #94a3b8; }
حرف استهلالي واقتباس
انتبه

خاصية content إلزامية لعمل ::before و ::after — بدونها لا يظهر شيء إطلاقاً. استخدم content: "" إن أردت شكلاً بلا نص.

نصيحة

المحتوى المولَّد بـ content لا يُنسخ عند تحديد النص، وقارئات الشاشة تتعامل معه بشكل غير متّسق. استخدمه للزخرفة فقط لا للمعلومات المهمة.

قواعد كتابة محدّدات جيدة

  1. اعتمد على الأصناف كخيار أول — مرنة وخصوصيتها متّسقة.
  2. اجعلها قصيرة: .card-title أفضل من .page .content .card .header h3.
  3. تجنّب التداخل العميق — كل مستوى يزيد الهشاشة والارتباط بالبنية.
  4. تجنّب !important إلا في حالات نادرة جداً.
  5. سمِّ بالمعنى لا بالشكل: .alert-danger أفضل من .red-box.
✗ خطأ
css
#main .content div.wrapper ul li a.link span {
  color: red;
}
طويل، هشّ، خصوصيته عالية جداً، وأي تغيير في البنية يكسره.
✓ صواب
css
.nav-link__label {
  color: red;
}
قصير، واضح، خصوصية متّسقة، ولا يعتمد على بنية HTML.

تمرين: تنسيق قائمة منتجات بالمحدّدات

باستخدام HTML التالي، اكتب CSS يحقّق المطلوب — دون تعديل HTML إطلاقاً.

المطلوب:

  • كل .product بحدود وحواف دائرية ومسافة داخلية.
  • المنتج الذي يحمل الصنفين product و featured معاً يحصل على حد ذهبي.
  • المنتج الذي data-status="sold-out" يظهر بشفافية 0.5.
  • الروابط التي تبدأ بـ https:// تظهر قبلها أيقونة 🔗.
  • الروابط التي تنتهي بـ .pdf يظهر بعدها نص « (PDF)».
  • أول .product بلا هامش علوي، وآخرها بلا هامش سفلي.
  • العنصر الزوجي بخلفية رمادية فاتحة.
  • السعر داخل المنتج المميّز فقط يكون عريضاً وبلون مختلف.
الترميز المعطىhtml
<ul class="products">
  <li class="product" data-status="available">
    <h3>سماعة لاسلكية</h3>
    <p class="price">299 ريالاً</p>
    <a href="p1.html">التفاصيل</a>
  </li>
  <li class="product featured" data-status="available">
    <h3>لوحة مفاتيح</h3>
    <p class="price">450 ريالاً</p>
    <a href="https://store.example.com/p2">التفاصيل</a>
  </li>
  <li class="product" data-status="sold-out">
    <h3>ماوس لاسلكي</h3>
    <p class="price">120 ريالاً</p>
    <a href="specs.pdf">المواصفات</a>
  </li>
</ul>

تلميحات:

  • 💡 «الصنفان معاً» تعني .product.featured بلا مسافة.
  • 💡 استخدم [data-status="sold-out"] لاستهداف السمة.
  • 💡 ::before و ::after تحتاجان content دائماً.
عرض الحل المقترح
الحلcss
.products {
  list-style: none;
  padding: 0;
  margin: 0;
}

.product {
  border: 1px solid #e2e8f0;
  border-radius: 12px;
  padding: 16px 20px;
  margin: 12px 0;
}

/* الصنفان معاً — بلا مسافة */
.product.featured {
  border-color: #f59e0b;
  border-width: 2px;
}

/* محدّد السمة */
.product[data-status="sold-out"] {
  opacity: .5;
}

/* السعر داخل المميّز فقط — علاقة سليل */
.product.featured .price {
  font-weight: 800;
  color: #b45309;
}

/* محدّدات بنيوية */
.product:first-child { margin-top: 0; }
.product:last-child  { margin-bottom: 0; }
.product:nth-child(even) { background: #f8fafc; }

/* محدّدات السمات مع عناصر زائفة */
.product a[href^="https://"]::before {
  content: "🔗 ";
}

.product a[href$=".pdf"]::after {
  content: " (PDF)";
  color: #dc2626;
  font-size: .85em;
}

اختبر فهمك

1. ما الفرق بين .a.b و .a .b؟

الشرح: المسافة هي محدّد السليل؛ غيابها يعني تقاطع الشروط على نفس العنصر.

2. أي محدّد يستهدف الابن المباشر فقط؟

الشرح: > يقصر الاستهداف على الأبناء المباشرين دون الأحفاد.

3. لماذا يُنصح بتجنّب #id في التنسيق؟

الشرح: المعرّف يتفوّق على أي عدد من الأصناف، فيكسر نظام الطبقات في مشروعك.

4. ما الخاصية الإلزامية لعمل ::before؟

الشرح: بدون content لا يُنشأ العنصر الزائف أصلاً.

5. ماذا يستهدف li:nth-child(3n)؟

الشرح: بتعويض n بـ 1، 2، 3 نحصل على 3، 6، 9 وهكذا.

أنهيت قراءة الدرس؟ علّمه كمكتمل ليُحتسب في تقدّمك.
