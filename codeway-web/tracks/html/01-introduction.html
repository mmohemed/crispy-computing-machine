مقدمة في HTML وكيف يعمل الويب

ما هي HTML ولماذا وُجدت، وماذا يحدث فعلياً بين لحظة كتابتك للرابط ولحظة ظهور الصفحة أمامك.

40 دقيقة مسار HTML 5 أسئلة 1 تمرين

ماذا ستتعلّم في هذا الدرس؟

  • تشرح ما هي HTML وما الفرق بينها وبين لغات البرمجة.
  • تصف رحلة الطلب من المتصفح إلى الخادم والعودة.
  • تميّز بين دور HTML و CSS و JavaScript في الصفحة الواحدة.
  • تكتب أول ملف HTML وتفتحه في المتصفح.
  • تعرف مصطلحات: الوسم، العنصر، السمة، والمحتوى.

ما هي HTML؟

اختصار لـ HyperText Markup Language أي «لغة ترميز النص التشعّبي». وهي اللغة التي نصف بها للمتصفح بنية الصفحة ومعنى كل جزء فيها: هذا عنوان، وهذا فقرة، وهذه صورة، وهذا رابط ينقلك إلى مكان آخر.

الكلمة المفتاحية هنا هي ترميز (Markup) وليست برمجة. أنت لا تكتب أوامر تُنفَّذ خطوة بخطوة، ولا شروطاً ولا حلقات تكرار؛ أنت تضع «علامات» حول النص تصف ماهيته. لهذا السبب HTML ليست لغة برمجة، وهذا ليس نقصاً فيها — هذه بالضبط وظيفتها.

تشبيه يثبّت الفكرة

تخيّل مقالاً في جريدة: العنوان الرئيسي بخط كبير، وعناوين فرعية، وفقرات، وصورة لها تعليق. HTML هي التي تقول «هذا عنوان رئيسي وهذه فقرة»، وCSS هي التي تقرّر «العنوان أحمر بحجم 32 بكسل»، وJavaScript هي التي تجعل شيئاً يحدث عند الضغط على زر.

الثلاثي الذي تُبنى به كل صفحة

HTML — الهيكل

العظام. تحدّد ما الموجود في الصفحة وما معناه. بدونها لا شيء.

CSS — المظهر

الجلد والملابس. الألوان والمسافات والتخطيط والتجاوب مع أحجام الشاشات.

JavaScript — السلوك

العضلات والأعصاب. التفاعل، التحقق من النماذج، جلب البيانات، وتحديث الصفحة دون إعادة تحميل.

يمكن لصفحة أن تعيش بـ HTML وحدها (ستكون بسيطة المظهر لكنها تعمل)، لكن لا يمكن لـ CSS أو JavaScript أن تعملا بلا HTML. لهذا نبدأ من هنا دائماً.

ماذا يحدث عندما تفتح موقعاً؟

فهم هذه الرحلة يوفّر عليك ساعات من الحيرة لاحقاً، خصوصاً عندما تتعامل مع المسارات والصور والخطوط.

  1. تكتب example.com في شريط العنوان وتضغط Enter.
  2. يسأل المتصفح خادم DNS: «ما عنوان IP الخاص بهذا الاسم؟» فيحصل على رقم مثل 93.184.216.34.
  3. يفتح المتصفح اتصالاً بذلك الخادم ويرسل طلب HTTP يقول: «أعطني الصفحة الرئيسية».
  4. يردّ الخادم بملف نصي — هو ملف HTML — مع رمز حالة مثل 200 OK.
  5. يبدأ المتصفح بقراءة الملف من أعلى لأسفل ويبني منه شجرة تُسمّى DOM.
  6. كلّما وجد رابطاً لملف CSS أو صورة أو سكربت، أرسل طلباً جديداً لجلبه.
  7. يرسم المتصفح النتيجة النهائية على الشاشة، وتشاهد أنت الصفحة.
نصيحة

لهذا السبب تكون الصفحة الخفيفة أسرع: كل ملف إضافي = طلب إضافي = وقت انتظار إضافي. سنعود لهذه النقطة في درس الأداء.

تشريح عنصر HTML

كل ما ستكتبه في HTML يتكوّن من هذه القطع الأربع. احفظ أسماءها لأننا سنستخدمها في كل درس قادم.

تشريح عنصرhtml
<p class="intro">مرحباً بالعالم</p>
<!--
  <p ............... وسم الفتح (Opening tag)
  class="intro" .... سمة (Attribute) لها اسم وقيمة
  مرحباً بالعالم ... المحتوى (Content)
  </p> ............. وسم الإغلاق (Closing tag)
  والمجموع كله يُسمّى: عنصر (Element)
-->
ما بين <!-- و --> تعليق لا يظهر للمستخدم ويُستخدم لشرح الكود.

عناصر لها إغلاق وعناصر بلا إغلاق

معظم العناصر تُغلق: <h1>…</h1>. لكن هناك عناصر فارغة (Void elements) لا محتوى لها فلا وسم إغلاق لها، مثل <img> و <br> و <hr> و <input> و <meta> و <link>.

✗ خطأ
html
<img src="cat.png" alt="قطة"></img>
<br></br>
العناصر الفارغة لا تُغلق؛ هذه الكتابة خاطئة وقد تسبب سلوكاً غريباً.
✓ صواب
html
<img src="cat.png" alt="قطة">
<br>
الكتابة الصحيحة. الشرطة المائلة الاختيارية في <br /> مسموحة لكنها غير ضرورية في HTML5.

أول ملف HTML لك

لا تحتاج أي برنامج خاص ولا تثبيت أي شيء. محرّر نصوص + متصفح، وانتهى الأمر.

  1. افتح محرّر نصوص (يُنصح بـ VS Code لأنه مجاني ويكمل الكود تلقائياً).
  2. أنشئ ملفاً جديداً واحفظه باسم index.html — الامتداد .html ضروري.
  3. اكتب الكود التالي بالكامل (لا تنسخه في المرة الأولى، اكتبه بيدك؛ هذا يثبّت الشكل في ذاكرتك).
  4. احفظ الملف ثم افتحه بالنقر المزدوج، أو اسحبه إلى نافذة المتصفح.
index.htmlhtml
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>صفحتي الأولى</title>
</head>
<body>
  <h1>مرحباً بالعالم</h1>
  <p>هذه أول صفحة أكتبها بنفسي في رحلة تعلّم تطوير الويب.</p>
</body>
</html>
النتيجة في المتصفح

لماذا اسم index.html تحديداً؟

لأن الخوادم تبحث افتراضياً عن ملف بهذا الاسم عندما يطلب أحدهم مجلداً. فإذا زار شخص example.com/blog/ فسيعرض له الخادم blog/index.html تلقائياً. اسم متعارف عليه، احترمه.

لماذا lang و dir مهمّان في العربية؟

السمة lang="ar" تخبر المتصفح وقارئات الشاشة ومحركات البحث أن محتوى الصفحة بالعربية، فتُنطق بشكل صحيح وتُفهرس بشكل صحيح. والسمة dir="rtl" تجعل اتجاه الكتابة من اليمين إلى اليسار، فتبدأ الفقرات والقوائم والجداول من الجهة الصحيحة تلقائياً.

الفرق بين ltr و rtl
لاحظ موضع نقاط القائمة ومحاذاة النص — كل ذلك بسبب سمة واحدة.
خطأ يكلّف الكثير

نسيان <meta charset="UTF-8"> يجعل الحروف العربية تظهر كرموز غريبة. اجعلها أول سطر داخل <head> دائماً.

المتصفح متسامح… وهذه مشكلة

إذا نسيت وسم إغلاق أو أخطأت في الترتيب، لن يعرض لك المتصفح رسالة خطأ غالباً، بل سيحاول «تخمين» ما تقصده ويعرض شيئاً ما. هذا التسامح مريح في البداية ومؤلم لاحقاً، لأن الصفحة قد تبدو سليمة على متصفح وتنهار على آخر.

نصيحة

العلاج: اكتب كوداً منظّماً بمسافات بادئة (Indentation) متّسقة، وتحقّق من صحّته عبر مدقّق W3C. سنخصّص لهذا درساً كاملاً لاحقاً.

تمرين: بطاقة تعريف بنفسك

أنشئ ملف about-me.html يعرّف بك في بضعة أسطر. لا تستخدم أي شيء لم يُذكر في هذا الدرس.

المطلوب:

  • الهيكل الكامل: <!DOCTYPE html> و <html> و <head> و <body>.
  • اللغة عربية والاتجاه من اليمين لليسار.
  • عنوان في تبويب المتصفح يحمل اسمك.
  • عنوان رئيسي <h1> باسمك، وفقرتان <p>: واحدة عن سبب تعلّمك البرمجة، وأخرى عن هدفك بعد ستة أشهر.
  • تعليق HTML في أعلى الملف يحمل تاريخ اليوم.

تلميحات:

  • 💡 لا تنسَ <meta charset="UTF-8"> وإلا ظهرت العربية كرموز.
  • 💡 التعليق يُكتب هكذا: <!-- نص التعليق -->.
  • 💡 <title> يوضع داخل <head> لا داخل <body>.

اختبر فهمك

1. HTML هي…

الشرح: HTML لغة ترميز (Markup) لا برمجة؛ لا تحتوي شروطاً ولا حلقات، بل تصف معنى المحتوى.

2. أي عنصر من التالي عنصر فارغ لا يُغلق؟

الشرح: <img> عنصر فارغ لا محتوى له، فلا وسم إغلاق له. مثله <br> و <input> و <meta>.

3. ما وظيفة <meta charset="UTF-8">؟

الشرح: الترميز يحدّد كيف تُفسَّر البايتات إلى حروف. بدون UTF-8 تظهر العربية كرموز مشوّهة.

4. لماذا يُسمّى الملف الرئيسي index.html عادةً؟

الشرح: اصطلاح متعارف عليه: طلب المجلد يعرض ملف index.html بداخله تلقائياً.

5. ما الترتيب الصحيح لدور كل تقنية؟

الشرح: HTML = بنية ومعنى، CSS = شكل وتخطيط، JavaScript = تفاعل ومنطق.
