عناصر HTML الحديثة

عناصر تغنيك عن مكتبات كاملة: dialog و details و template و progress و canvas و SVG المضمّن.

45 دقيقة مسار HTML 5 أسئلة 1 تمرين

ماذا ستتعلّم في هذا الدرس؟

  • تبني نافذة منبثقة أصلية بـ <dialog>.
  • تنشئ عناصر طيّ وأكورديون بلا جافاسكربت.
  • تستخدم <template> لقوالب قابلة للاستنساخ.
  • تعرض التقدّم والقياسات بـ <progress> و <meter>.
  • تعرف متى تستخدم Canvas ومتى SVG.

HTML لم تتوقّف عند 2014

كثير من المطوّرين يستدعون مكتبة كاملة لعمل نافذة منبثقة أو أكورديون، بينما المتصفح يوفّرهما أصليين — بإمكانية وصول كاملة ودعم لوحة مفاتيح جاهز وحجم صفر كيلوبايت.

<details> و <summary>

html
<details>
  <summary>ما هي مدة الدورة؟</summary>
  <p>عشرون درساً بمجموع اثنتي عشرة ساعة.</p>
</details>

<!-- مفتوح افتراضياً -->
<details open>
  <summary>هل أحتاج خبرة سابقة؟</summary>
  <p>لا، المسار يبدأ من الصفر.</p>
</details>

<!-- أكورديون: واحد فقط مفتوح في كل مرة -->
<details name="faq"><summary>السؤال الأول</summary><p>…</p></details>
<details name="faq"><summary>السؤال الثاني</summary><p>…</p></details>
أكورديون بلا سطر جافاسكربت
معلومة

السمة name المشتركة تجعلها مجموعة أكورديون: فتح أحدها يغلق البقية تلقائياً. ميزة حديثة أغنت عن عشرات أسطر جافاسكربت.

نصيحة

محتوى <details> المطوي يظل في شجرة DOM، فمحركات البحث تفهرسه ووظيفة البحث في الصفحة (Ctrl+F) تجده في المتصفحات الحديثة.

<dialog> — النافذة المنبثقة الأصلية

html
<button type="button" id="openBtn">تأكيد الحذف</button>

<dialog id="confirmDialog">
  <form method="dialog">
    <h2>تأكيد الحذف</h2>
    <p>سيُحذف الملف نهائياً ولا يمكن التراجع.</p>
    <button value="cancel">إلغاء</button>
    <button value="confirm">حذف</button>
  </form>
</dialog>
js
const dlg = document.getElementById('confirmDialog');

document.getElementById('openBtn')
  .addEventListener('click', () => dlg.showModal());

dlg.addEventListener('close', () => {
  console.log('اختار المستخدم:', dlg.returnValue);
});

ما تحصل عليه مجاناً عند استخدام showModal():

  • حبس التركيز داخل النافذة — لا يستطيع Tab الخروج منها.
  • الإغلاق بمفتاح Esc.
  • طبقة تعتيم خلفية عبر الزائفة ::backdrop.
  • تعطيل التفاعل مع بقية الصفحة تلقائياً.
  • إعادة التركيز إلى الزر الذي فتح النافذة عند الإغلاق.
  • دور dialog معلن لقارئ الشاشة.
css
dialog {
  border: 0;
  border-radius: 16px;
  padding: 24px;
  max-width: 420px;
  box-shadow: 0 20px 60px rgba(0,0,0,.25);
}
dialog::backdrop {
  background: rgba(15, 23, 42, .55);
  backdrop-filter: blur(3px);
}
انتبه

الفرق مهم: show() تفتح نافذة غير حاجزة بلا تعتيم ولا حبس تركيز، وshowModal() تفتح النافذة الحاجزة الكاملة. للتأكيدات استخدم showModal() دائماً. و<form method="dialog"> يغلق النافذة عند الإرسال ويحفظ قيمة الزر في returnValue.

<template> — قالب مخفي

محتوى <template> لا يُعرض ولا يُنفَّذ ولا تُحمَّل صوره — لكنه موجود في DOM جاهزاً للاستنساخ. هذا هو الأساس الذي تُبنى عليه القوائم الديناميكية.

html
<template id="rowTemplate">
  <li class="item">
    <span class="name"></span>
    <span class="price"></span>
    <button type="button" class="remove">حذف</button>
  </li>
</template>

<ul id="list"></ul>
js
const tpl = document.getElementById('rowTemplate');
const list = document.getElementById('list');

function addItem(name, price) {
  const node = tpl.content.cloneNode(true);
  node.querySelector('.name').textContent = name;
  node.querySelector('.price').textContent = price + ' ريالاً';
  list.appendChild(node);
}

addItem('سماعة', 299);
نصيحة

أفضل من بناء HTML بسلاسل نصية: القالب يُتحقّق من صحّته مرة واحدة، ولا تخاطر بثغرة XSS عند استخدام textContent بدل innerHTML.

<progress> و <meter>

html
<!-- تقدّم مهمة نحو الاكتمال -->
<label for="up">رفع الملف</label>
<progress id="up" value="72" max="100">72٪</progress>

<!-- تقدّم غير معروف المدة -->
<progress></progress>

<!-- قياس ضمن نطاق معروف -->
<label for="disk">المساحة المستخدمة</label>
<meter id="disk" value="0.82" low="0.4" high="0.75" optimum="0.2">82٪</meter>

معلومة

النص المكتوب بين الوسمين احتياطي للمتصفحات القديمة. وأضف aria-label أو <label> مرتبطة كي يُعلن المعنى لقارئ الشاشة.

<output> — نتيجة عملية

html
<form oninput="total.value = Number(price.value) * Number(qty.value)">
  <label for="price">السعر</label>
  <input type="number" id="price" name="price" value="50">

  <label for="qty">الكمية</label>
  <input type="number" id="qty" name="qty" value="2">

  <p>الإجمالي: <output name="total" for="price qty">100</output> ريالاً</p>
</form>
حاسبة فورية

<output> منطقة حيّة ضمنياً (aria-live="polite")، فيعلن قارئ الشاشة تغيّر قيمتها تلقائياً دون أي إعداد.

تمرين: لوحة إعدادات حديثة

ابنِ صفحة إعدادات تستخدم العناصر الحديثة بدل المكتبات الخارجية.

المطلوب:

  • ثلاثة أقسام قابلة للطي بـ <details name="settings"> تعمل كأكورديون.
  • زر «حذف الحساب» يفتح <dialog> تأكيد بـ showModal() مع تنسيق ::backdrop.
  • <progress> يعرض نسبة اكتمال الملف الشخصي.
  • <meter> يعرض المساحة المستخدمة مع عتبات low و high و optimum.
  • حاسبة صغيرة تستخدم <output> لعرض الناتج فورياً.
  • <template> لقالب صف إشعار، مع سطر جافاسكربت يستنسخه.
  • كل عنصر له تسمية مناسبة لقارئ الشاشة.

تلميحات:

  • 💡 method="dialog" على النموذج داخل الحوار يغلقه ويحفظ returnValue.
  • 💡 <meter> يحتاج optimum ليعرف أي اتجاه هو «الجيد».
  • 💡 محتوى <template> يُستنسخ بـ tpl.content.cloneNode(true).

اختبر فهمك

1. ما الفرق بين dialog.show() و dialog.showModal()؟

الشرح: النافذة الحاجزة تمنع التفاعل مع الخلفية وتحبس التركيز وتدعم Esc و::backdrop.

2. ما الذي يميّز محتوى <template>؟

الشرح: محتواه خامل تماماً: لا عرض ولا تنفيذ ولا تحميل صور، لكنه جاهز للنسخ.

3. متى تستخدم <meter> بدل <progress>؟

الشرح: progress لمهمة تتقدّم نحو الاكتمال، وmeter لقياس ثابت النطاق يتغيّر في الاتجاهين.

4. أيهما أنسب لرسم بياني تفاعلي بعشرة أعمدة قابلة للنقر؟

الشرح: كل شكل في SVG عنصر DOM يقبل الأحداث والتنسيق، ويبقى حاداً عند التكبير ومتاحاً لقارئ الشاشة.

5. ما فائدة <bdi> في الواجهات العربية؟

الشرح: أسماء المستخدمين اللاتينية داخل جملة عربية قد تقلب ترتيب العرض؛ bdi تعزلها.

أنهيت قراءة الدرس؟ علّمه كمكتمل ليُحتسب في تقدّمك.
