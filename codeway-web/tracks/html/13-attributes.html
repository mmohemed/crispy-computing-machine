السمات العامة و data-*

السمات التي تعمل على أي عنصر: id و class و title و tabindex و hidden، وكيف تخزّن بياناتك الخاصة بأمان.

40 دقيقة مسار HTML 5 أسئلة 1 تمرين

ماذا ستتعلّم في هذا الدرس؟

  • تستخدم id و class بالفرق الصحيح بينهما.
  • تتحكّم بترتيب التنقّل عبر tabindex دون إفساده.
  • تخفي عناصر بشكل صحيح بـ hidden.
  • تخزّن بيانات مخصّصة بسمات data-* وتقرؤها بجافاسكربت.
  • تعرف السمات المنطقية وكيف تُكتب.

ما السمات العامة؟

معظم السمات مخصّصة لعنصر بعينه (src للصور، href للروابط). لكن هناك مجموعة تعمل على أي عنصر — هذه هي السمات العامة (Global attributes)، وهي التي ستستخدمها يومياً في CSS وJavaScript.

id مقابل class

الوجهidclass
التكرارمرة واحدة فقط في الصفحةيتكرّر بلا حدود
العدد لكل عنصرواحدعدة أصناف مفصولة بمسافات
في CSS#header.card
في JavaScriptgetElementByIdquerySelectorAll
في الروابطhref="#id" يقفز إليهلا يُستخدم
في النماذج<label for="id">لا يُستخدم
html
<div id="main-header" class="header sticky dark">…</div>

<article class="card featured">…</article>
<article class="card">…</article>

قاعدة عملية: استخدم class للتنسيق دائماً، واحتفظ بـ id للحالات التي تتطلّب معرّفاً فريداً: أهداف الروابط الداخلية، ربط <label>، وربط ARIA.

قواعد تسمية id

لا يبدأ برقم، ولا يحتوي مسافات، وحسّاس لحالة الأحرف. id="main" و id="Main" معرّفان مختلفان تماماً.

نصيحة

التنسيق بـ id في CSS يعطي أولوية عالية جداً يصعب تجاوزها لاحقاً. ابقَ على الأصناف وستوفّر على نفسك معارك !important.

title — التلميح

html
<abbr title="Cascading Style Sheets">CSS</abbr>
<button title="حفظ المستند (Ctrl+S)">حفظ</button>
انتبه

لا تعتمد على title لمعلومة مهمة: لا يظهر على شاشات اللمس إطلاقاً، ولا يمكن تكبيره، ولا يصل إليه مستخدم لوحة المفاتيح دائماً. اجعله معلومة إضافية لا أساسية.

hidden وإخفاء العناصر

html
<p hidden>لن يظهر هذا النص إطلاقاً.</p>

السمة hidden تخفي العنصر عن الجميع: العين وقارئ الشاشة والتنقّل بلوحة المفاتيح. لكن انتبه — هذه ليست الطريقة الوحيدة للإخفاء، ولكل طريقة أثر مختلف:

الطريقةيراه المبصريقرؤه قارئ الشاشةيشغل مساحة
hidden أو display: noneلالالا
visibility: hiddenلالانعم
opacity: 0لانعمنعم
صنف .sr-onlyلانعملا
aria-hidden="true"نعملانعم
صنف الإخفاء البصري القياسيcss
.sr-only {
  position: absolute;
  width: 1px; height: 1px;
  padding: 0; margin: -1px;
  overflow: hidden;
  clip: rect(0 0 0 0);
  white-space: nowrap;
  border: 0;
}
نصيحة

استخدم .sr-only لنص يشرح لقارئ الشاشة ما تعبّر عنه أيقونة بصرياً، مثل زر فيه أيقونة سلة فقط.

tabindex — ترتيب التنقّل

الروابط والأزرار وحقول النماذج قابلة للتركيز افتراضياً. tabindex يغيّر هذا السلوك بثلاث قيم لها معانٍ مختلفة تماماً:

القيمةالمعنىالاستخدام
tabindex="0"أدخِل العنصر في الترتيب الطبيعيعنصر مخصّص تفاعلي، أو منطقة تمرير
tabindex="-1"قابل للتركيز برمجياً فقط لا بمفتاح Tabنقل التركيز إلى نافذة منبثقة أو رسالة خطأ
tabindex="1" فأكثريقفز إلى مقدّمة الترتيبتجنّبه دائماً
لماذا تُمنع القيم الموجبة؟

أي عنصر بـ tabindex="1" يسبق كل العناصر الطبيعية في الصفحة، فيصبح ترتيب التنقّل غير متوقّع ويستحيل صيانته مع نمو الصفحة. الحل الصحيح: رتّب عناصرك في HTML بالترتيب المنطقي أصلاً.

✗ خطأ
html
<div onclick="save()">حفظ</div>
div غير قابل للتركيز ولا يستجيب لمفتاح Enter — مستخدم لوحة المفاتيح لا يستطيع استخدامه إطلاقاً.
✓ صواب
html
<button type="button" onclick="save()">حفظ</button>
الزر يأتي بكل السلوك مجاناً: تركيز، Enter، Space، ودور دلالي صحيح.

سمات data-* — بياناتك الخاصة

أحياناً تحتاج ربط معلومة بعنصر: معرّف منتج، حالة، قيمة. لا تخترع سمات عشوائية (productid="5") — فهي ترميز غير صالح. استخدم البادئة data- المخصّصة لهذا الغرض.

html
<button
  class="add-to-cart"
  data-product-id="1042"
  data-price="299"
  data-currency="SAR">
  أضف إلى السلة
</button>
قراءتها في جافاسكربتjs
const btn = document.querySelector('.add-to-cart');

console.log(btn.dataset.productId); // "1042"  ← لاحظ camelCase
console.log(btn.dataset.price);     // "299"

// التعديل
btn.dataset.price = '249';

// القيم دائماً نصوص — حوّلها عند الحاجة
const price = Number(btn.dataset.price);
قاعدة التحويل

السمة data-product-id تُقرأ في جافاسكربت باسم dataset.productId: تُحذف البادئة data-، وتتحوّل الشرطات إلى camelCase.

استخدامها في CSS أيضاًcss
[data-state="loading"] { opacity: .5; pointer-events: none; }
[data-level="pro"]::after { content: " (احترافي)"; }
تنسيق بحسب data
انتبه

لا تخزّن في data-* أي شيء حسّاس — كلها مرئية لأي مستخدم يفتح أدوات المطوّر. وتجنّب تخزين محتوى نصي طويل فيها؛ المحتوى مكانه داخل العنصر.

السمات المنطقية

بعض السمات وجودها وحده يعني true: required, disabled, checked, hidden, readonly, multiple, autofocus, defer, async, loop, muted, controls, open, inert.

html
<input required="false">
<input disabled="no">
أي قيمة — حتى "false" — تُفعّل السمة. الحقلان أعلاه إلزامي ومعطّل فعلاً!
✓ صواب
html
<input required>
<input>

<!-- لإلغائها: احذفها كلياً -->
الطريقة الوحيدة لإلغاء سمة منطقية هي حذفها من العنصر.

تمرين: بطاقات منتجات ببيانات مخصّصة

ابنِ ثلاث بطاقات منتجات تحمل بياناتها في سمات data-*.

المطلوب:

  • كل بطاقة <article> بصنف card وسمات: data-id و data-price و data-category و data-stock.
  • كل بطاقة تحوي عنواناً ووصفاً وزر «أضف إلى السلة» يحمل data-product-id مطابقاً.
  • زر واحد معطّل بسمة منطقية لأن المنتج غير متوفّر (data-stock="0").
  • أيقونة زخرفية واحدة مخفية عن قارئ الشاشة بـ aria-hidden="true".
  • نص مخفي بصرياً بصنف .sr-only يوضّح ما يفعله زر يحوي أيقونة فقط.
  • استخدم id مرة واحدة فقط في الصفحة كهدف لرابط داخلي.

تلميحات:

  • 💡 السمات المنطقية تُكتب بلا قيمة: disabled لا disabled="true".
  • 💡 data-product-id تُقرأ في جافاسكربت بـ dataset.productId.
  • 💡 لا تستخدم id مكرّراً على البطاقات — استخدم data-id.
عرض الحل المقترح
الحلhtml
<main id="products">
  <h1>منتجاتنا</h1>

  <article class="card" data-id="1042" data-price="299"
           data-category="audio" data-stock="12">
    <h2>سماعة لاسلكية</h2>
    <p>عزل ضوضاء نشط وبطارية 30 ساعة.</p>
    <button type="button" class="add" data-product-id="1042">
      أضف إلى السلة
    </button>
  </article>

  <article class="card" data-id="1043" data-price="149"
           data-category="accessories" data-stock="0">
    <h2>حامل هاتف</h2>
    <p>معدن مطلي قابل للطي.</p>
    <button type="button" class="add" data-product-id="1043" disabled>
      غير متوفّر حالياً
    </button>
  </article>

  <article class="card" data-id="1044" data-price="89"
           data-category="cables" data-stock="43">
    <h2>كابل USB-C</h2>
    <p>طول مترين ودعم الشحن السريع.</p>
    <button type="button" class="add" data-product-id="1044">
      <span aria-hidden="true">🛒</span>
      <span class="sr-only">أضف كابل USB-C إلى السلة</span>
    </button>
  </article>
</main>
في جافاسكربت: document.querySelectorAll(".card") ثم card.dataset.price للوصول إلى كل قيمة.

اختبر فهمك

1. ما الفرق الأساسي بين id و class؟

الشرح: المعرّف يجب أن يكون فريداً في الصفحة؛ الصنف مصمَّم للتكرار على عناصر متشابهة.

2. كيف تُقرأ data-user-name في جافاسكربت؟

الشرح: تُحذف البادئة data- وتتحوّل الشرطات إلى camelCase.

3. لماذا يُنصح بتجنّب tabindex="1" فأكثر؟

الشرح: القيم الموجبة تخلق ترتيباً موازياً يسبق الترتيب الطبيعي، ويصبح غير متوقّع مع كل إضافة.

4. أي طريقة تخفي العنصر بصرياً لكن يبقى مقروءاً لقارئ الشاشة؟

الشرح: .sr-only يخرج العنصر من العرض المرئي مع بقائه في شجرة إمكانية الوصول.

5. ماذا تعني <input required="false">؟

الشرح: السمات المنطقية تُفعَّل بمجرّد وجودها مهما كانت قيمتها؛ لإلغائها تُحذف تماماً.
