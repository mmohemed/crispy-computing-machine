القوائم بأنواعها

القوائم غير المرتبة والمرتبة وقوائم الوصف، والتداخل، واستخدام القوائم في بناء قوائم التنقّل.

40 دقيقة مسار HTML 5 أسئلة 1 تمرين

ماذا ستتعلّم في هذا الدرس؟

  • تختار بين ul و ol و dl بحسب المعنى.
  • تتحكّم بترقيم القوائم المرتبة عبر type و start و reversed.
  • تبني قوائم متداخلة بإغلاق صحيح.
  • تستخدم القائمة لبناء شريط تنقّل دلالي.
  • تعرف الفرق بين <dl> وجدول ثنائي الأعمدة.

ثلاثة أنواع، ثلاثة معانٍ

الاختيار بينها ليس مسألة شكل. اسأل: هل يتغيّر المعنى إذا بدّلت ترتيب العناصر؟ إن كان الجواب لا فهي ul، وإن كان نعم فهي ol. أما إن كنت تعرض أزواجاً من «اسم ← وصف» فهي dl.

1. القائمة غير المرتبة <ul>

html
<ul>
  <li>تفاح</li>
  <li>موز</li>
  <li>برتقال</li>
</ul>
النتيجة

قائمة مشتريات، مميزات منتج، روابط تنقّل — كلها لا يهم ترتيبها. النقاط التي تراها ليست جزءاً من HTML بل تنسيق افتراضي يمكن تغييره كلياً بـ CSS عبر list-style.

2. القائمة المرتبة <ol>

html
<ol>
  <li>افتح محرّر النصوص</li>
  <li>اكتب كود HTML</li>
  <li>احفظ الملف بامتداد .html</li>
  <li>افتح الملف في المتصفح</li>
</ol>
خطوات مرتّبة

التحكّم في الترقيم

السمةالمعنىمثال
type="1"أرقام (الافتراضي)1. 2. 3.
type="A"حروف لاتينية كبيرةA. B. C.
type="a"حروف لاتينية صغيرةa. b. c.
type="I"أرقام رومانية كبيرةI. II. III.
type="i"أرقام رومانية صغيرةi. ii. iii.
start="5"يبدأ العد من رقم معيّن5. 6. 7.
reversedيعدّ تنازلياً3. 2. 1.
value="9" على <li>يفرض رقماً لعنصر بعينه ويكمل منه9. 10. 11.
html
<ol type="A" start="3">
  <li>يبدأ من C</li>
  <li>ثم D</li>
</ol>

<ol reversed>
  <li>المركز الثالث</li>
  <li>المركز الثاني</li>
  <li>المركز الأول</li>
</ol>
أنماط الترقيم
معلومة

لتغيير شكل الترقيم فقط، فالأفضل استخدام CSS: list-style-type: upper-alpha. أما start و reversed فهما معلومتان دلاليتان تبقى في HTML.

3. قائمة الوصف <dl>

تُسمّى Description List. تربط بين مصطلح <dt> ووصفه <dd>. ليست للقواميس فقط: تصلح لبطاقة مواصفات منتج، أو بيانات وصفية، أو أسئلة وأجوبة.

html
<dl>
  <dt>المعالج</dt>
  <dd>ثماني الأنوية بتردد 3.2 جيجاهرتز</dd>

  <dt>الذاكرة</dt>
  <dd>16 جيجابايت</dd>

  <dt>المنافذ</dt>
  <dd>USB-C</dd>
  <dd>HDMI 2.1</dd>
</dl>
بطاقة مواصفات
  • يمكن لمصطلح واحد أن يتبعه عدة أوصاف (كما في المنافذ أعلاه).
  • ويمكن لعدة مصطلحات أن تشترك في وصف واحد.
  • يُسمح بلفّ كل زوج داخل <div> لتسهيل التنسيق — وهذه الحالة الوحيدة المسموح فيها بعنصر آخر داخل <dl>.

القوائم المتداخلة

القائمة الفرعية توضع داخل عنصر <li> وليس بين عنصرين. هذا أكثر خطأ شيوعاً في القوائم.

✗ خطأ
html
<ul>
  <li>الفصل الأول</li>
  <ul>
    <li>الدرس 1</li>
  </ul>
</ul>
<ul> الفرعية أصبحت ابناً مباشراً لـ <ul> — ترميز غير صالح، والعلاقة الهرمية ضاعت.
✓ صواب
html
<ul>
  <li>الفصل الأول
    <ul>
      <li>الدرس 1</li>
    </ul>
  </li>
</ul>
القائمة الفرعية داخل <li> الذي تتبعه — علاقة أب وابن واضحة.
فهرس كتاب متداخل
نصيحة

يمكن خلط الأنواع: قائمة مرتبة داخل غير مرتبة أو العكس، بحسب معنى كل مستوى.

القوائم في التنقّل

شريط التنقّل في أي موقع هو في جوهره قائمة روابط. كتابته كقائمة يخبر قارئ الشاشة بعدد العناصر ويتيح التنقّل بينها بسهولة.

html
<nav aria-label="التنقّل الرئيسي">
  <ul>
    <li><a href="index.html">الرئيسية</a></li>
    <li><a href="services.html">خدماتنا</a></li>
    <li><a href="contact.html" aria-current="page">اتصل بنا</a></li>
  </ul>
</nav>
شريط تنقّل من قائمة
معلومة

خاصية CSS ‏list-style: none تزيل النقاط، وdisplay: flex تجعلها أفقية. المعنى الدلالي يبقى محفوظاً في HTML رغم تغيّر الشكل تماماً.

متى لا تستخدم قائمة؟

  • حين تكون البيانات ثنائية البعد (صفوف وأعمدة) — استخدم <table>.
  • حين يكون النص فقرة متصلة — لا تقطّع الجُمل إلى عناصر قائمة.
  • لمجرد إنشاء مسافات بادئة — استخدم CSS.

تمرين: صفحة وصفة طبخ

اكتب صفحة وصفة تستخدم الأنواع الثلاثة من القوائم، كلٌّ في موضعه الصحيح.

المطلوب:

  • <ul> للمكوّنات (الترتيب لا يهم).
  • <ol> لخطوات التحضير (الترتيب مهم)، وإحدى الخطوات تحتوي قائمة فرعية بخطوات تفصيلية.
  • <dl> لبطاقة معلومات الوصفة: مدة التحضير، عدد الأشخاص، مستوى الصعوبة.
  • شريط تنقّل مبني على <ul> بثلاثة روابط.
  • استخدم start أو reversed مرة واحدة في مكان له معنى.

تلميحات:

  • 💡 القائمة الفرعية تُوضع داخل <li> الأب قبل إغلاقه.
  • 💡 في <dl> كل <dt> يتبعه <dd> واحد أو أكثر.
  • 💡 اسأل نفسك عن كل قائمة: هل يتغيّر المعنى لو بدّلت الترتيب؟

<dl>
  <dt>مدة التحضير</dt>
  <dd>ساعة و15 دقيقة</dd>
  <dt>تكفي</dt>
  <dd>6 أشخاص</dd>
  <dt>مستوى الصعوبة</dt>
  <dd>متوسط</dd>
</dl>

<h2>المكوّنات</h2>
<ul>
  <li>دجاجة كاملة مقطّعة</li>
  <li>ثلاثة أكواب أرز بسمتي</li>
  <li>بصلتان مفرومتان</li>
  <li>بهارات كبسة</li>
</ul>

<h2>طريقة التحضير</h2>
<ol>
  <li>سخّن الزيت وأضف البصل حتى يذبل.</li>
  <li>أضف الدجاج والبهارات وقلّبه.</li>
  <li>حضّر الأرز:
    <ol type="a">
      <li>اغسل الأرز ثلاث مرات.</li>
      <li>انقعه عشرين دقيقة.</li>
      <li>صفّه جيداً.</li>
    </ol>
  </li>
  <li>أضف الأرز إلى المرق واتركه على نار هادئة.</li>
</ol>

<h2>ملاحظات الشيف (الأهم أولاً)</h2>
<ol reversed>
  <li>يمكن استبدال الدجاج باللحم.</li>
  <li>لا تفتح الغطاء أثناء نضج الأرز.</li>
  <li>جودة البهارات تصنع الفرق كله.</li>
</ol>

اختبر فهمك

1. متى تستخدم <ol> بدل <ul>؟

الشرح: الشكل يمكن تغييره بـ CSS؛ الاختيار يقوم على المعنى: هل يتغيّر المقصود لو بدّلت الترتيب؟

2. أين توضع القائمة الفرعية في قائمة متداخلة؟

الشرح: الأبناء المباشرون لـ <ul> يجب أن يكونوا <li> فقط؛ القائمة الفرعية تُوضع داخل الـ <li> المعني.

3. ما وظيفة <dt> و <dd>؟

الشرح: dt = Description Term و dd = Description Details، وهما زوج المصطلح ووصفه.

4. كيف تجعل قائمة مرتبة تبدأ من الرقم 5؟

الشرح: السمة start على <ol>؛ أما value فتوضع على <li> لفرض رقم عنصر بعينه.

5. لماذا يُبنى شريط التنقّل عادةً على <ul>؟

الشرح: القائمة تعطي بنية دلالية: «قائمة من 5 عناصر»، فيسهل على المستخدم تصوّرها والتنقّل فيها.
