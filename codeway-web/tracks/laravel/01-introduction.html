مقدمة في Laravel وتهيئة البيئة

ما هو Laravel ولماذا يتصدّر عالم PHP، تثبيته بـ Composer، بنية المشروع، وأدوات Artisan.

ماذا ستتعلّم في هذا الدرس؟

  • تعرف ما يقدّمه Laravel ومتى تختاره.
  • تثبّت PHP و Composer وتنشئ مشروعاً جديداً.
  • تفهم بنية مجلّدات المشروع ودور كلٍّ منها.
  • تستخدم Artisan لتوليد الملفات وتشغيل المهام.

ما هو Laravel؟

إطار عمل PHP كامل أنشأه Taylor Otwell عام 2011، وهو اليوم الأكثر استخداماً في عالم PHP بفارق كبير. فلسفته قريبة من Rails: صياغة أنيقة واتفاقات ذكية وأدوات جاهزة لكل شيء.

php
<?php
// مثال يوضّح فلسفة Laravel — كل ما يلزم لواجهة برمجية كاملة

Route::get('/posts', function () {
    return Post::published()
        ->with('author')
        ->latest()
        ->paginate(15);
});

ثلاثة أسطر تُنتج: استعلاماً محسّناً، وتحميلاً مسبقاً للعلاقة، وترتيباً، وترقيم صفحات، وتحويلاً تلقائياً إلى JSON مع روابط الصفحات.

ما الذي يأتي جاهزاً؟

Eloquent ORM

تتعامل مع الجداول ككائنات PHP، والعلاقات بسطر واحد.

قوالب Blade

محرّك قوالب سريع مع وراثة ومكوّنات وهروب تلقائي.

مصادقة وصلاحيات

تسجيل ودخول وإعادة تعيين كلمة المرور وسياسات صلاحيات.

Artisan

سطر أوامر يولّد الملفات ويشغّل الهجرات والمهام.

الطوابير والجدولة

مهام خلفية ومهام مجدولة بلا إعداد معقّد.

اختبارات مدمجة

PHPUnit و Pest مع مساعدات اختبار HTTP وقاعدة البيانات.

جذر الويب هو `public/` لا مجلّد المشروع

عند النشر، وجّه الخادم إلى public/ فقط. توجيهه لمجلّد المشروع يجعل .env وكل شيفرتك متاحة للتحميل عبر المتصفّح — ثغرة أمنية كاملة.

php

// قراءة الإعدادات

config('app.debug');

env('APP_NAME');               // ⚠️ يعمل في ملفات config فقط
لا تستخدم `env()` خارج ملفات `config/`

عند تخزين الإعدادات مؤقّتاً في الإنتاج بـ config:cache، تُرجع env() قيمة null في كل مكان آخر. اقرأ دائماً عبر config()، وضع أيّ قيمة تحتاجها في ملف إعداد أولاً.

`.env` لا يُرفع لـ Git أبداً

يحتوي كلمات مرور قاعدة البيانات ومفاتيح الواجهات البرمجية. الملف مُدرَج في .gitignore افتراضياً — لا تُخرجه منه. شارك البنية عبر .env.example بقيم فارغة.

Artisan

bash
php artisan list                    # كل الأوامر
php artisan help make:model

# التوليد
php artisan make:model Post -mfsc   # نموذج + هجرة + مصنع + بذرة + متحكّم
php artisan make:controller PostController --resource
php artisan make:migration create_posts_table
php artisan make:request StorePostRequest
php artisan make:middleware EnsureUserIsAdmin
php artisan make:policy PostPolicy --model=Post
php artisan make:seeder PostSeeder
php artisan make:test PostTest

# قاعدة البيانات
php artisan migrate
php artisan migrate:rollback
php artisan migrate:fresh --seed     # يمسح كل شيء ويعيد البناء
php artisan db:seed

# التشخيص
php artisan route:list
php artisan tinker                   # صدفة تفاعلية
php artisan about                    # معلومات المشروع

# الذاكرة المؤقّتة
php artisan optimize:clear           # يمسح الكل
php artisan config:cache             # للإنتاج فقط

تهيئة مشروع وصفحة تعريف

أنشئ مشروع Laravel جديداً واضبطه وابنِ صفحة تعريف ديناميكية.

المطلوب:

  • أنشئ مشروعاً باسم codeway وشغّله على http://localhost:8000.
  • اضبط .env: اسم التطبيق بالعربية، والمنطقة الزمنية Asia/Riyadh في config/app.php.
  • أنشئ مسار / يعرض صفحة رئيسية، و /about يعرض صفحة تعريف.
  • أنشئ مسار /greet/{name} يمرّر الاسم للعرض، ويستخدم "زائر" إن لم يُمرَّر.
  • أنشئ قالباً أساسياً layouts/app.blade.php بـ RTL وخطّ عربي، وورّث منه الصفحتين.
  • اعرض في صفحة التعريف: اسم التطبيق من config()، إصدار Laravel، إصدار PHP، والتاريخ الهجري والميلادي.
  • أضف شريط تنقّل مشتركاً يبرز الصفحة الحالية.
  • أنشئ مسار /api/info يُرجع نفس المعلومات بصيغة JSON.
  • أضف صفحة خطأ 404 مخصّصة بالعربية.

تلميحات:

  • 💡 Route::get('/greet/{name?}', ...) مع ? يجعل المعامل اختيارياً.
  • 💡 app()->version() و PHP_VERSION للإصدارات.
  • 💡 request()->routeIs('about') لمعرفة المسار الحالي.
  • 💡 صفحة 404 المخصّصة: resources/views/errors/404.blade.php.
عرض الحل المقترح
الحلphp
<?php
// ═══════════════════════════════════════════════
// routes/web.php
// ═══════════════════════════════════════════════
use Illuminate\Support\Facades\Route;

Route::get('/', fn () => view('home'))->name('home');

Route::get('/about', function () {
    return view('about', [
        'info' => app_info(),
    ]);
})->name('about');

Route::get('/greet/{name?}', function (?string $name = null) {
    return view('greet', ['name' => $name ?: 'زائر']);
})->name('greet');

Route::get('/api/info', fn () => response()->json(app_info()));

// ═══════════════════════════════════════════════
// app/helpers.php  (سجّله في composer.json → autoload.files)
// ═══════════════════════════════════════════════
if (! function_exists('app_info')) {
    function app_info(): array
    {
        return [
            'app'          => config('app.name'),
            'environment'  => config('app.environment', app()->environment()),
            'laravel'      => app()->version(),
            'php'          => PHP_VERSION,
            'timezone'     => config('app.timezone'),
            'date'         => now()->format('Y-m-d'),
            'time'         => now()->format('H:i'),
            'day'          => now()->translatedFormat('l'),
        ];
    }
}
?>

اختبر نفسك

اختبر فهمك

1. لماذا يجب توجيه خادم الويب إلى public/ لا لمجلّد المشروع؟

الشرح: ثغرة أمنية كاملة: كلمات مرور قاعدة البيانات ومفاتيح الواجهات كلها تصبح متاحة للتحميل.

2. لماذا لا نستخدم env() خارج ملفات config/؟

الشرح: اقرأ دائماً عبر config()، وضع القيمة في ملف إعداد أولاً.

3. ما فائدة php artisan tinker؟

الشرح: أسرع من كتابة مسار مؤقّت لتجربة استعلام أو دالة.

4. ماذا يولّد php artisan make:model Post -mfsc؟

الشرح: m هجرة، f مصنع، s بذرة، c متحكّم — اختصار مفيد جداً.

5. ما دور bootstrap/app.php في Laravel 11؟

الشرح: حلّ في Laravel 11 محلّ ملفات Kernel المتعدّدة في الإصدارات السابقة.

6. كيف تشارك بنية .env مع فريقك؟

الشرح: .env نفسه في .gitignore دائماً لأنه يحمل أسراراً حقيقية.

أنهيت قراءة الدرس؟ علّمه كمكتمل ليُحتسب في تقدّمك.
