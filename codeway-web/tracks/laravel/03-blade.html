قوالب Blade

صياغة Blade والتعليمات الشرطية والحلقات، وراثة القوالب والأجزاء والمكوّنات، والنماذج والرسائل.

55 دقيقة مسار Laravel 7 أسئلة 1 تمرين

ماذا ستتعلّم في هذا الدرس؟

  • تكتب قوالب Blade وتفهم الهروب التلقائي.
  • تستخدم التعليمات الشرطية والحلقات ومتغيّر $loop.
  • تبني تخطيطاً أساسياً وترث منه بـ @extends و @section.
  • تنشئ مكوّنات قابلة لإعادة الاستخدام مع خصائص وفتحات.
  • تعرض رسائل النجاح والأخطاء بشكل موحّد.
  • تحمي قوالبك من ثغرات XSS.

<?php
// app/View/Components/Alert.php
namespace App\View\Components;

use Illuminate\View\Component;
use Illuminate\View\View;

class Alert extends Component
{
    public function __construct(
        public string $type = 'info',
        public ?string $title = null,
        public bool $dismissible = false,
    ) {
    }

    public function classes(): string
    {
        return match ($this->type) {
            'success' => 'bg-green-50 text-green-800 border-green-200',
            'error'   => 'bg-red-50 text-red-800 border-red-200',
            'warning' => 'bg-amber-50 text-amber-800 border-amber-200',
            default   => 'bg-blue-50 text-blue-800 border-blue-200',
        };
    }

    public function icon(): string
    {
        return match ($this->type) {
            'success' => '✓', 'error' => '✕', 'warning' => '⚠', default => 'ℹ',
        };
    }

    public function render(): View
    {
        return view('components.alert');
    }
}

نصيحة

استخدم @props للمكوّنات البسيطة — لا تحتاج صنف PHP. أنشئ صنفاً فقط حين تحتاج منطقاً حقيقياً أو حقن اعتماديات.

`@csrf` ليس اختيارياً

بدونه يرفض Laravel الطلب بخطأ 419. الرمز يمنع تزوير الطلبات عبر المواقع: موقع خبيث يجعل متصفّح المستخدم يرسل طلباً لموقعك وهو مسجّل الدخول.

تمرين

مكتبة مكوّنات لمدوّنة

ابنِ نظام قوالب كاملاً بمكوّنات قابلة لإعادة الاستخدام لواجهة مدوّنة عربية.

المطلوب:

  • تخطيط أساسي layouts.app بـ RTL وخطّ عربي ورأس وتذييل وكومتي أنماط وسكربتات.
  • مكوّن <x-alert> بأربعة أنواع وعنوان اختياري وإمكانية الإغلاق.
  • مكوّن <x-card> بفتحات header و footer مسمّاة.
  • مكوّن <x-badge> بألوان وأحجام، مضمّن بـ @props بلا صنف.
  • مكوّن <x-post-card> يعرض مقالاً كاملاً: صورة، عنوان، مقتطف، كاتب، وسوم، زمن قراءة.
  • مكوّن <x-form.input> و <x-form.textarea> يعرضان الأخطاء و old() تلقائياً.
  • مكوّن <x-pagination> لترقيم الصفحات بالعربية.
  • جزء partials.flash يعرض كل رسائل الجلسة والأخطاء بشكل موحّد.
  • صفحة posts.index تستخدم @forelse مع حالة فارغة أنيقة.
  • صفحة posts.show مع تعليقات ونموذج إضافة تعليق كامل بـ @csrf و old().
  • لا تستخدم {!! !!} مع أي محتوى من المستخدم.

تلميحات:

  • 💡 $attributes->merge([...]) يدمج الأصناف الممرّرة مع أصناف المكوّن.
  • 💡 @props(['color' => 'gray']) يعرّف الخصائص في المكوّنات المضمّنة.
  • 💡 $errors->has($name) لمعرفة إن كان الحقل به خطأ.
  • 💡 $attributes->whereStartsWith('wire:') لتمرير سمات محدّدة.

اختبر نفسك

اختبر فهمك

1. ما الفرق بين {{ $x }} و {!! $x !!}؟

الشرح: لا تستخدم {!! !!} مع أي محتوى من المستخدم إلا بعد تنظيفه بمكتبة متخصّصة.

2. ما فائدة @forelse؟

الشرح: تختصر @if (count) @foreach … @else … @endif في تعليمة واحدة.

3. ما الفرق بين @yield و @stack؟

الشرح: @stack مثالي للأنماط والسكربتات: كل قالب يدفع ما يحتاجه بلا تعارض.

4. لماذا تُفضَّل المكوّنات على @include؟

الشرح: الجزء يرث كل شيء فيخفي التبعيات، والمكوّن له واجهة واضحة عبر @props.

5. ماذا يحدث لو نسيت @csrf في نموذج POST؟

الشرح: الرمز يمنع تزوير الطلبات عبر المواقع (CSRF) وهو حماية أساسية.

6. ما وظيفة old('title', $post->title)؟

الشرح: نسيانها في حقل واحد يعني ضياع ما كتبه المستخدم فيه عند كل خطأ تحقّق.

7. ما وظيفة $attributes->merge(['class' => ...]) في المكوّن؟

الشرح: يسمح بكتابة <x-alert class="mt-6"> دون فقدان أنماط المكوّن.

أنهيت قراءة الدرس؟ علّمه كمكتمل ليُحتسب في تقدّمك.
