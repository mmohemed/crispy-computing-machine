الـ Mixins وإعادة الاستخدام

كتل أنماط قابلة لإعادة الاستخدام تقبل معاملات ومحتوى، وأشهر الـ mixins التي ستكتبها في كل مشروع.

45 دقيقة مسار Sass 5 أسئلة 1 تمرين

ماذا ستتعلّم في هذا الدرس؟

  • تعرّف mixin وتستدعيه.
  • تمرّر معاملات وتعطيها قيماً افتراضية.
  • تستخدم @content لتمرير كتلة أنماط.
  • تبني mixins للتجاوب والحالات الشائعة.
  • تعرف متى تستخدم mixin ومتى @extend ومتى دالة.

ما هو الـ mixin؟

كتلة من الإعلانات تُعرَّف مرة وتُستدعى في أي مكان. مثل الدالة في البرمجة، لكنها تُنتج أنماطاً لا قيماً.

scss
// التعريف
@mixin flex-center {
  display: flex;
  align-items: center;
  justify-content: center;
}

// الاستدعاء
.hero {
  @include flex-center;
  min-height: 400px;
}

.modal {
  @include flex-center;
  position: fixed;
  inset: 0;
}
الناتجcss
.hero {
  display: flex;
  align-items: center;
  justify-content: center;
  min-height: 400px;
}
.modal {
  display: flex;
  align-items: center;
  justify-content: center;
  position: fixed;
  inset: 0;
}
معلومة

لاحظ أن الأنماط تُنسَخ في كل موضع استدعاء. هذا يعني تكراراً في الناتج — لكن ضغط gzip يتعامل مع التكرار بكفاءة عالية، فلا تقلق منه.

المعاملات

scss
@mixin flex($direction: row, $gap: 0, $align: center) {
  display: flex;
  flex-direction: $direction;
  align-items: $align;
  gap: $gap;
}

.nav   { @include flex(row, 16px); }
.stack { @include flex(column, 8px, stretch); }
.plain { @include flex; }                    // كل القيم افتراضية

// التمرير بالاسم — يتيح تخطّي معامل
.sidebar { @include flex($direction: column, $align: flex-start); }
نصيحة

التمرير بالاسم يجعل الاستدعاء موثّقاً ذاتياً: @include flex($gap: 16px) أوضح بكثير من @include flex(row, 16px, center) بعد ستة أشهر.

عدد متغيّر من المعاملات

scss
@mixin shadow($shadows...) {
  box-shadow: $shadows;
}

.card {
  @include shadow(
    0 2px 6px rgba(0,0,0,.06),
    0 12px 32px rgba(0,0,0,.08)
  );
}

@content — تمرير كتلة أنماط

أقوى ميزة في الـ mixins: تستطيع تمرير كتلة كاملة من الأنماط تُوضَع في موضع @content. هذا ما يجعل mixin التجاوب ممكناً.

scss
@mixin respond-to($breakpoint) {
  @media (min-width: $breakpoint) {
    @content;
  }
}

.card {
  padding: 16px;

  @include respond-to(768px) {
    padding: 24px;
    display: grid;
    grid-template-columns: 1fr 1fr;
  }
}
الناتجcss
.card { padding: 16px; }

@media (min-width: 768px) {
  .card {
    padding: 24px;
    display: grid;
    grid-template-columns: 1fr 1fr;
  }
}

mixins ستكتبها في كل مشروع

1. نقاط التوقف

scss
@use 'sass:map';

$breakpoints: (
  'sm': 576px,
  'md': 768px,
  'lg': 992px,
  'xl': 1200px
);

@mixin respond-to($name) {
  $value: map.get($breakpoints, $name);

  @if $value {
    @media (min-width: $value) { @content; }
  } @else {
    @error "نقطة التوقف '#{$name}' غير معرّفة. المتاح: #{map.keys($breakpoints)}";
  }
}

// الاستخدام
.hero {
  font-size: 1.5rem;

  @include respond-to('md') { font-size: 2rem; }
  @include respond-to('lg') { font-size: 3rem; }
}
انتبه

التوجيه @error يوقف الترجمة برسالة واضحة. بدونه، خطأ مطبعي في اسم نقطة التوقف يمرّ صامتاً ولا يُطبَّق النمط — وتقضي ساعة تبحث عن السبب.

@use 'sass:color';

@mixin button($bg, $fg: #fff, $padding: 12px 24px) {
  display: inline-flex;

mixin أم @extend أم دالة؟

الأداةتُرجعاستخدمها حين
mixinكتلة إعلاناتتحتاج معاملات، أو تولّد استعلام وسائط، أو كتلة @content
@extendيدمج المحدّداتأنماط متطابقة تماماً بلا معاملات (بحذر — انظر الدرس 8)
دالةقيمة واحدةتحسب لوناً أو حجماً أو نصاً لتضعه في خاصية
scss
// mixin: ينتج أنماطاً
@mixin card-base { border-radius: 12px; padding: 16px; }

// دالة: تنتج قيمة
@function rem($px, $base: 16px) {
  @return math.div($px, $base) * 1rem;
}

.card {
  @include card-base;          // أنماط
  font-size: rem(18px);        // قيمة
}

أخطاء شائعة

✗ خطأ
scss
@mixin brand-color {
  color: #6366f1;
}

.title { @include brand-color; }
mixin بقيمة ثابتة واحدة بلا معاملات — متغيّر بسيط أوضح وأخف.
✓ صواب
scss
$color-brand: #6366f1;

.title { color: $color-brand; }
لا تستخدم mixin لما يكفيه متغيّر.
  • mixin ضخم يفعل كل شيء: قسّمه إلى وحدات صغيرة قابلة للتركيب.
  • mixin بلا معاملات ولا @content: غالباً يكفيه متغيّر أو @extend.
  • استدعاؤه في مئات المواضع: راجع — قد يكون صنفاً مساعداً أنسب.
  • تسمية غامضة: @mixin style1 لا تخبر شيئاً. سمّه بما يفعل.

تمرين: مكتبة mixins للمشروع

ابنِ ملف _mixins.scss بمجموعة أدوات جاهزة واستخدمها في مكوّنات فعلية.

المطلوب:

  • خريطة $breakpoints بأربع نقاط توقف، وmixin respond-to يستخدمها مع @error للاسم الخاطئ.
  • mixin flex($dir, $gap, $align, $justify) بقيم افتراضية معقولة.
  • mixin truncate و line-clamp($lines).
  • mixin button($bg, $fg) يولّد زراً كاملاً بحالاته الأربع.
  • mixin card($padding, $radius) يولّد بطاقة مع ظل و hover.
  • mixin dark للوضع الليلي بـ @content.
  • mixin auto-grid($min, $gap).
  • استخدم كل mixin مرة واحدة على الأقل في ملف _components.scss.
  • أنشئ ثلاثة أنواع أزرار من mixin واحد.

تلميحات:

  • 💡 @content يجب أن تكون داخل كتلة الوسائط لا خارجها.
  • 💡 استخدم color.adjust لتوليد لون الـ hover تلقائياً من اللون الأساسي.
  • 💡 اختبر رسالة @error بتمرير اسم نقطة توقف غير موجودة.

اختبر فهمك

1. ما وظيفة @content داخل mixin؟

الشرح: يتيح تمرير كتلة أنماط كاملة، وهو أساس mixins التجاوب.

2. ما الفرق بين mixin ودالة في Sass؟

الشرح: استخدم mixin للإعلانات، ودالة لحساب قيمة تضعها في خاصية.

3. متى لا يجب استخدام mixin؟

الشرح: mixin بلا معاملات ولا محتوى وبقيمة واحدة تعقيد بلا فائدة.

4. ما فائدة @error في mixin؟

الشرح: يمنع الأخطاء الصامتة التي تضيّع وقتاً طويلاً في التشخيص.

5. لماذا لا يقلقنا تكرار الأنماط في ناتج mixin؟

الشرح: النصوص المتكرّرة تُضغط بشدّة، فالفرق في الحجم المنقول ضئيل.
