الوراثة @extend والعناصر النائبة

مشاركة الأنماط بدمج المحدّدات، والفرق الحاسم بينها وبين mixin، ولماذا تُستخدم بحذر.

35 دقيقة مسار Sass 5 أسئلة 1 تمرين

ماذا ستتعلّم في هذا الدرس؟

  • تستخدم @extend لمشاركة الأنماط.
  • تعرّف عناصر نائبة بـ %.
  • تفرّق بين @extend و mixin في الناتج.
  • تدرك المشكلات التي يسبّبها @extend.
  • تختار الأداة المناسبة لكل حالة.

الفكرة

بدل نسخ الأنماط كما يفعل mixin، يدمج @extend المحدّدات في قاعدة واحدة مشتركة. الناتج أقلّ تكراراً.

scss
.message {
  padding: 16px;
  border-radius: 10px;
  border: 1px solid;
}

.message-success {
  @extend .message;
  background: #ecfdf5;
  border-color: #10b981;
}

.message-error {
  @extend .message;
  background: #fef2f2;
  border-color: #ef4444;
}
الناتجcss
.message,
.message-success,
.message-error {
  padding: 16px;
  border-radius: 10px;
  border: 1px solid;
}

.message-success {
  background: #ecfdf5;
  border-color: #10b981;
}

.message-error {
  background: #fef2f2;
  border-color: #ef4444;
}

لاحظ: الأنماط المشتركة كُتبت مرة واحدة وأُضيفت المحدّدات إليها. هذا هو الفرق الجوهري عن mixin.

العناصر النائبة %

مشكلة المثال السابق: صنف .message يظهر في الناتج حتى لو لم تستخدمه في HTML إطلاقاً. العنصر النائب يحلّ ذلك: يُعرَّف بـ % ولا يُطبَع أبداً إلا حين يرثه أحد.

scss
%message-base {
  padding: 16px;
  border-radius: 10px;
  border: 1px solid;
  font-weight: 600;
}

.message-success {
  @extend %message-base;
  background: #ecfdf5;
  border-color: #10b981;
}

.message-error {
  @extend %message-base;
  background: #fef2f2;
  border-color: #ef4444;
}
الناتج — لا أثر لـ %message-basecss
.message-success,
.message-error {
  padding: 16px;
  border-radius: 10px;
  border: 1px solid;
  font-weight: 600;
}

.message-success { background: #ecfdf5; border-color: #10b981; }
.message-error   { background: #fef2f2; border-color: #ef4444; }
رسائل ترث قاعدة واحدة
نصيحة

إن استخدمت @extend أصلاً، فاستخدمه مع العناصر النائبة دائماً — لا مع الأصناف العادية. هذا يمنع تسرّب أصناف لا تستخدمها إلى ملفك النهائي.

@mixin message-base {
  padding: 16px;
  border-radius: 10px;

.msg-a { @include message-base; background: #eee; }
.msg-b { @include message-base; background: #ddd; }

%message-base {

مشكلات @extend

1. لا يعمل عبر استعلامات الوسائط

scss
%base { padding: 16px; }

@media (min-width: 768px) {
  .card {
    @extend %base;   // ❌ خطأ ترجمة
  }
}
خطأ شائع

رسالة الخطأ: You may not @extend selectors across media queries. السبب أن الدمج يحدث على مستوى المحدّدات، والمحدّد داخل استعلام وسائط في سياق مختلف. الحل الوحيد: استخدم mixin.

2. انفجار المحدّدات

scss
.a .b .c { color: red; }
.x .y .z { @extend .c; }

// الناتج: كل التوافيق الممكنة
// .a .b .c, .a .b .x .y .z, .x .y .a .b .z, …
انتبه

مع محدّدات متداخلة، قد يولّد @extend عشرات المحدّدات المركّبة التي لا تحتاجها — فينتفخ الملف بدل أن يصغر، وهو عكس الهدف.

3. تغيّر ترتيب المصدر

scss
.btn { color: blue; }

.card {
  color: green;
}

.special {
  @extend .btn;   // ينتقل مع .btn إلى موضعها في الملف
}

المحدّد ينتقل إلى موضع القاعدة الموروثة في الملف، لا حيث كتبته. هذا يغيّر ترتيب التتالي وقد يجعل قاعدة كنت تتوقّع فوزها تخسر.

4. !optional

scss
.card {
  @extend %maybe-missing !optional;   // لا يفشل إن لم يوجد
}

بدونها تفشل الترجمة إن كان المحدّد المورَّث غير موجود. مفيدة في المكتبات التي قد لا تُحمَّل كل أجزائها.

متى تستخدم كلاً منهما؟

استخدم %placeholder

أنماط متطابقة تماماً بلا معاملات، بين عناصر متقاربة دلالياً، في نفس السياق.

استخدم mixin

تحتاج معاملات، أو تعمل داخل استعلام وسائط، أو تريد نتيجة متوقّعة تماماً.

لا تستخدم @extend

مع أصناف عادية، أو عبر ملفات متباعدة، أو داخل محدّدات متداخلة عميقة.

رأي شائع في المجتمع

كثير من الفرق تمنع @extend كلياً وتكتفي بالـ mixins. السبب: مع ضغط gzip يكاد الفرق في الحجم يختفي، بينما مشكلات التنبّؤ تبقى. إن كنت متردّداً، اختر mixin — لن تندم.

حالة استخدام جيدة

عناصر متقاربة في نفس الملفscss
%input-base {
  width: 100%;
  padding: 10px 14px;
  border: 1px solid #cbd5e1;
  border-radius: 8px;
  font-family: inherit;
  font-size: 1rem;
  background: #fff;

  &:focus-visible {
    outline: 3px solid #a5b4fc;
    border-color: #6366f1;
  }

  &:disabled {
    background: #f1f5f9;
    cursor: not-allowed;
  }
}

.input    { @extend %input-base; }
.textarea { @extend %input-base; min-height: 120px; resize: vertical; }
.select   { @extend %input-base; appearance: none; }
حقول ترث قاعدة واحدة

هذه حالة مثالية: ثلاثة عناصر متقاربة دلالياً، في نفس الملف، بأنماط متطابقة بلا معاملات، خارج أي استعلام وسائط.

تمرين: نظام تنبيهات وحقول

ابنِ نظام تنبيهات بعناصر نائبة، ثم أعد بناءه بـ mixins وقارن الناتجين.

المطلوب:

  • عنصر نائب %alert-base فيه الأنماط المشتركة.
  • أربعة أصناف تنبيه ترثه: نجاح، خطأ، تحذير، معلومة.
  • عنصر نائب %visually-hidden واستخدمه في صنفين.
  • عنصر نائب %input-base وثلاثة عناصر ترثه.
  • اكتب النسخة نفسها بـ mixins في ملف منفصل.
  • ترجم الملفين وقارن حجميهما وعدد القواعد.
  • حاول استخدام @extend داخل استعلام وسائط ووثّق رسالة الخطأ في تعليق.
  • اكتب في تعليق أي النهجين تفضّل ولماذا.

تلميحات:

  • 💡 العنصر النائب لا يظهر في الناتج إلا إن ورثه أحد.
  • 💡 قارن الحجم قبل وبعد الضغط: gzip -c style.css | wc -c.
  • 💡 الخطأ المتوقّع: You may not @extend selectors across media queries.
عرض الحل المقترح
الحلscss
/* ===== النهج الأول: عناصر نائبة ===== */

%alert-base {
  display: flex;
  align-items: center;
  gap: 12px;
  padding: 14px 18px;
  border-radius: 10px;
  border: 1px solid;
  font-weight: 600;
  margin-bottom: 12px;
}

.alert-success { @extend %alert-base; background: #ecfdf5; border-color: #10b981; color: #047857; }
.alert-error   { @extend %alert-base; background: #fef2f2; border-color: #ef4444; color: #b91c1c; }
.alert-warning { @extend %alert-base; background: #fffbeb; border-color: #f59e0b; color: #b45309; }
.alert-info    { @extend %alert-base; background: #f0f9ff; border-color: #0ea5e9; color: #0369a1; }

%visually-hidden {
  position: absolute;
  width: 1px; height: 1px;
  padding: 0; margin: -1px;
  overflow: hidden;
  clip: rect(0 0 0 0);
  white-space: nowrap;
  border: 0;
}

.sr-only    { @extend %visually-hidden; }
.skip-label { @extend %visually-hidden; }

%input-base {
  width: 100%;
  padding: 10px 14px;
  border: 1px solid #cbd5e1;
  border-radius: 8px;
  font-family: inherit;
  font-size: 1rem;

  &:focus-visible {
    outline: 3px solid #a5b4fc;
    border-color: #6366f1;
  }
}

.input    { @extend %input-base; }
.textarea { @extend %input-base; min-height: 120px; resize: vertical; }
.select   { @extend %input-base; appearance: none; }

/*
  محاولة فاشلة عمداً — رسالة الخطأ:
  "You may not @extend selectors across media queries."

  @media (min-width: 768px) {
    .alert-lg { @extend %alert-base; }
  }

  الحل: استخدم mixin بدلاً منه.
*/

/* ===== النهج الثاني: mixins ===== */

@mixin alert-base {
  display: flex;
  align-items: center;
  gap: 12px;
  padding: 14px 18px;
  border-radius: 10px;
  border: 1px solid;
  font-weight: 600;
  margin-bottom: 12px;
}

@mixin alert($bg, $border, $text) {
  @include alert-base;
  background: $bg;
  border-color: $border;
  color: $text;
}

.m-alert-success { @include alert(#ecfdf5, #10b981, #047857); }
.m-alert-error   { @include alert(#fef2f2, #ef4444, #b91c1c); }

// هذه تعمل بلا مشكلة داخل استعلام وسائط
@media (min-width: 768px) {
  .m-alert-lg { @include alert-base; padding: 20px 28px; }
}

/*
  الخلاصة:
  النهج الأول أصغر في الناتج الخام، لكن النهج الثاني
  أكثر مرونة (يقبل معاملات) ويعمل داخل استعلامات الوسائط،
  والفرق في الحجم بعد gzip ضئيل جداً.
  التفضيل: mixins للمرونة والتنبّؤ، مع %placeholder
  في الحالات المتطابقة تماماً داخل الملف الواحد.
*/

اختبر فهمك

1. ما الفرق الجوهري بين @extend و mixin في الناتج؟

الشرح: الدمج يعطي قاعدة واحدة بعدة محدّدات؛ النسخ يكرّر الإعلانات.

2. لماذا نستخدم %placeholder بدل صنف عادي مع @extend؟

الشرح: الصنف العادي يُطبَع حتى لو لم تستخدمه في HTML.

3. ماذا يحدث عند @extend داخل استعلام وسائط؟

الشرح: القيد بنيوي في آلية دمج المحدّدات؛ البديل mixin.

4. ما خطر @extend مع المحدّدات المتداخلة؟

الشرح: انفجار التوافيق قد ينتفخ بالملف بدل تصغيره.

5. متى تكون mixin الخيار الأصوب؟

الشرح: المرونة وقابلية التنبّؤ تجعلانها الخيار الافتراضي الآمن.
