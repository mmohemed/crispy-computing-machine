التقسيم والوحدات: @use و @forward

تقسيم أنماطك إلى ملفات صغيرة، ونظام الوحدات الحديث الذي حلّ محلّ @import المهمل.

40 دقيقة مسار Sass 5 أسئلة 1 تمرين

ماذا ستتعلّم في هذا الدرس؟

  • تقسّم مشروعك إلى ملفات جزئية.
  • تستورد الملفات بـ @use مع أسماء مستعارة.
  • تعيد تصدير الوحدات بـ @forward.
  • تخصّص متغيّرات وحدة بـ with.
  • تعرف لماذا هُجر @import.

لماذا نقسّم؟

ملف CSS من 3000 سطر كابوس: تبحث عن قاعدة فتضيع، وتخشى التعديل خشية كسر شيء بعيد، ويستحيل على فريق العمل عليه معاً بلا تعارضات.

الحل: ملفات صغيرة كل منها مسؤول عن شيء واحد، تُدمَج عند الترجمة في ملف CSS واحد — فتحصل على تنظيم التطوير وأداء الإنتاج معاً.

الملفات الجزئية

الملف الذي يبدأ اسمه بشرطة سفلية _ يُسمّى جزئياً: لا يُترجَم إلى ملف CSS مستقل، بل يُستورد داخل غيره.

text
scss/
├── abstracts/
│   ├── _variables.scss
│   ├── _mixins.scss
│   └── _functions.scss
├── base/
│   ├── _reset.scss
│   └── _typography.scss
├── components/
│   ├── _button.scss
│   └── _card.scss
└── main.scss           ← الوحيد بلا شرطة، وهو ما يُترجَم
bash
# يُترجَم main.scss فقط، والجزئيات تُدمَج بداخله
npx sass scss/main.scss dist/style.css

@use — الاستيراد الحديث

_variables.scssscss
$color-brand: #6366f1;
$color-text: #0f172a;
$space-4: 16px;
$radius: 12px;
_button.scssscss
@use 'variables';

.btn {
  background: variables.$color-brand;
  padding: variables.$space-4;
  border-radius: variables.$radius;
}
البادئة إلزامية

مع @use لا يكفي كتابة $color-brand — يجب variables.$color-brand. البادئة هي اسم الملف بلا الشرطة والامتداد. هذا يمنع تعارض الأسماء بين الملفات ويوضّح مصدر كل قيمة.

الأسماء المستعارة

scss
// بادئة أقصر
@use 'abstracts/variables' as v;

.btn {
  background: v.$color-brand;
  padding: v.$space-4;
}

// بلا بادئة إطلاقاً
@use 'abstracts/variables' as *;

.btn {
  background: $color-brand;   // تعمل مباشرة
}
حذار من `as *`

تلغي الحماية الأساسية التي جاء @use من أجلها: إن عرّف ملفان متغيّراً بالاسم نفسه ستحصل على تعارض غامض. استخدمها فقط لملف متغيّرات واحد مركزي تعرفه جيداً.

نصيحة

الاصطلاح الشائع: as v للمتغيّرات و as m للـ mixins و as f للدوال. قصير وواضح.

التخصيص بـ with

_theme.scssscss
$brand: #6366f1 !default;
$radius: 12px !default;
$font-size: 16px !default;

.btn {
  background: $brand;
  border-radius: $radius;
  font-size: $font-size;
}
main.scssscss
@use 'theme' with (
  $brand: #dd0031,
  $radius: 4px
);
// $font-size بقي 16px
  • المتغيّرات القابلة للتخصيص يجب أن تحمل !default في الوحدة.
  • with تُستخدم مرة واحدة فقط لكل وحدة في المشروع كله.
  • إن استوردت الوحدة نفسها في ملفين، فالتخصيص يكون في أول استيراد.

الأعضاء الخاصة

scss
// المتغيّر أو الـ mixin الذي يبدأ بـ - أو _ خاص بالوحدة
$-internal-cache: ();
@mixin _helper() { … }

// عام
$color-brand: #6366f1;
@mixin button() { … }

الأعضاء الخاصة لا تظهر للملفات المستوردة. مفيدة لتفاصيل التنفيذ التي لا تريد أن يعتمد عليها أحد.

@forward — إعادة التصدير

تخيّل عشرة ملفات في abstracts/. هل يستورد كل مكوّن العشرة؟ الحل: ملف فهرس واحد يعيد تصديرها كلها.

abstracts/_index.scssscss
@forward 'variables';
@forward 'mixins';
@forward 'functions';
components/_card.scssscss
// استيراد واحد يكفي — Sass يجد _index.scss تلقائياً
@use '../abstracts' as a;

.card {
  padding: a.$space-4;
  border-radius: a.$radius;
  @include a.flex-center;
}
ملف الفهرس

إن كان في المجلد ملف اسمه _index.scss فيكفي كتابة اسم المجلد: @use "../abstracts". اصطلاح مريح يقلّل الضجيج.

خيارات @forward

scss
// إعادة تصدير أعضاء محدّدة فقط
@forward 'variables' show $color-brand, $space-4;

// إخفاء أعضاء
@forward 'mixins' hide _internal-helper;

// إضافة بادئة لكل الأعضاء
@forward 'buttons' as btn-*;
// فيصبح $primary باسم $btn-primary

// تمرير التخصيص للأعلى
@forward 'theme' with ($brand: #dd0031 !default);

لماذا هُجر @import؟

المشكلةمع @importمع @use
النطاقكل شيء عالمي — تعارضات صامتةنطاق لكل وحدة ببادئة واضحة
التكراراستيراد الملف مرتين يكرّر أنماطهيُحمَّل مرة واحدة مهما تكرّر
المصدرلا تعرف من أين جاء المتغيّرالبادئة تخبرك فوراً
الترتيبحسّاس جداً وهشّمستقرّ
الأداءأبطأ في المشاريع الكبيرةأسرع
مهمل رسمياً

@import مهمل وسيُحذف من Sass. لا تستخدمه في أي مشروع جديد. ستجده كثيراً في مشاريع قائمة — والانتقال منه إلى @use عملية تدريجية ممكنة.

معلومة

انتبه: @import في CSS الأصلية شيء مختلف تماماً ولا يزال صالحاً. ما هُجر هو @import الخاص بـ Sass.

معمارية 7-1

أشهر تنظيم لمشاريع Sass الكبيرة: سبعة مجلدات وملف واحد رئيسي.

text
scss/
├── abstracts/     أدوات لا تُنتج CSS: متغيّرات، mixins، دوال
├── base/          إعادة الضبط، الطباعة، القواعد العامة
├── components/    الأزرار، البطاقات، النماذج، التنبيهات
├── layout/        الترويسة، الفوتر، الشبكة، الشريط الجانبي
├── pages/         أنماط خاصة بصفحة بعينها
├── themes/        الوضع الليلي، ثيمات بديلة
├── vendors/       أنماط مكتبات خارجية
└── main.scss
main.scssscss
// 1) الأدوات أولاً — لا تنتج CSS
@use 'abstracts' as *;

// 2) الأساس
@use 'base/reset';
@use 'base/typography';

// 3) التخطيط
@use 'layout/header';
@use 'layout/footer';
@use 'layout/grid';

// 4) المكوّنات
@use 'components/button';
@use 'components/card';
@use 'components/form';

// 5) الصفحات
@use 'pages/home';

// 6) الثيمات
@use 'themes/dark';
ترتيب مهم

الترتيب يحدّد ترتيب القواعد في ملف CSS الناتج، وبالتالي أي قاعدة تفوز عند تساوي الخصوصية. ضع العام أولاً والخاص أخيراً: reset ← layout ← components ← pages ← themes.

نصيحة

مشروع صغير؟ لا تحتاج سبعة مجلدات. ابدأ بثلاثة: abstracts و base و components، وأضف الباقي عند الحاجة الفعلية.

تمرين: إعادة هيكلة مشروع

خذ ملف SCSS واحداً كبيراً وقسّمه إلى معمارية منظّمة.

المطلوب:

  • أنشئ البنية: abstracts/، base/، components/، layout/، وmain.scss.
  • في abstracts/: _variables.scss و _mixins.scss و _index.scss يعيد تصديرهما.
  • _variables.scss فيه 5 متغيّرات على الأقل بـ !default.
  • _mixins.scss فيه mixin واحد بسيط (توسيط بـ flexbox مثلاً).
  • في base/: _reset.scss و _typography.scss.
  • في components/: _button.scss و _card.scss يستوردان abstracts باسم مستعار.
  • في layout/: _header.scss.
  • main.scss يستورد كل شيء بالترتيب الصحيح، ويخصّص متغيّراً واحداً بـ with.
  • استخدم sass:math مرة واحدة على الأقل.
  • تأكّد أن الترجمة تنتج ملف CSS واحداً بلا أخطاء.

تلميحات:

  • 💡 ملف _index.scss داخل المجلد يتيح @use "../abstracts" باسم المجلد فقط.
  • 💡 التخصيص بـ with يجب أن يكون في أول استيراد للوحدة.
  • 💡 رتّب: abstracts ← base ← layout ← components.
عرض الحل المقترح
الحلscss
/* ===== abstracts/_variables.scss ===== */
$color-brand:  #6366f1 !default;
$color-text:   #0f172a !default;
$color-border: #e2e8f0 !default;
$space-4: 16px !default;
$radius:  12px !default;
$bp-md:   768px !default;

/* ===== abstracts/_mixins.scss ===== */
@mixin flex-center($gap: 0) {
  display: flex;
  align-items: center;
  justify-content: center;
  gap: $gap;
}

@mixin respond-to($bp) {
  @media (min-width: $bp) { @content; }
}

/* ===== abstracts/_index.scss ===== */
@forward 'variables';
@forward 'mixins';

/* ===== base/_reset.scss ===== */
*, *::before, *::after { box-sizing: border-box; }
* { margin: 0; padding: 0; }

/* ===== base/_typography.scss ===== */
@use '../abstracts' as a;
@use 'sass:math';

body {
  font-family: 'Cairo', sans-serif;
  color: a.$color-text;
  line-height: math.div(29px, 16px);
}

/* ===== components/_button.scss ===== */
@use '../abstracts' as a;

.btn {
  @include a.flex-center(8px);
  padding: math.div(a.$space-4, 2) a.$space-4;
  background: a.$color-brand;
  color: #fff;
  border: 0;
  border-radius: a.$radius;
  cursor: pointer;

  &:hover { filter: brightness(.92); }
}

/* ===== components/_card.scss ===== */
@use '../abstracts' as a;

.card {
  border: 1px solid a.$color-border;
  border-radius: a.$radius;
  padding: a.$space-4;

  @include a.respond-to(a.$bp-md) {
    padding: a.$space-4 * 1.5;
  }
}

/* ===== layout/_header.scss ===== */
@use '../abstracts' as a;

.site-header {
  @include a.flex-center(a.$space-4);
  justify-content: space-between;
  padding: a.$space-4;
  border-bottom: 1px solid a.$color-border;
}

/* ===== main.scss ===== */
@use 'abstracts' with ($color-brand: #dd0031);

@use 'base/reset';
@use 'base/typography';
@use 'layout/header';
@use 'components/button';
@use 'components/card';
التخصيص with في main.scss يؤثّر في كل الملفات لأن الوحدة تُحمَّل مرة واحدة فقط.

اختبر فهمك

1. ما دلالة الشرطة السفلية في اسم الملف؟

الشرح: الجزئيات تمنع توليد ملفات CSS لا حاجة لها.

2. كيف تصل إلى $brand بعد @use "variables"؟

الشرح: البادئة إلزامية مع @use، وهي اسم الملف بلا شرطة ولا امتداد.

3. ما الفرق بين @use و @forward؟

الشرح: @forward لا يتيح لك استخدام الأعضاء، بل يمرّرها لمن يستورد ملفك.

4. لماذا هُجر @import في Sass؟

الشرح: @use يوفّر نطاقاً واضحاً وتحميلاً مرة واحدة وتتبّعاً سهلاً.

5. متى تُستخدم with لتخصيص وحدة؟

الشرح: الوحدة تُحمَّل مرة واحدة؛ التخصيص يكون عند أول استيراد.
