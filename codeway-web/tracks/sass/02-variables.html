المتغيّرات وأنواع البيانات

تخزين القيم المتكرّرة، أنواع البيانات في Sass، النطاق، والعلاقة بمتغيّرات CSS الأصلية.

40 دقيقة مسار Sass 5 أسئلة 1 تمرين

ماذا ستتعلّم في هذا الدرس؟

  • تعرّف متغيّرات وتستخدمها في أنماطك.
  • تعرف أنواع البيانات السبعة في Sass.
  • تفهم نطاق المتغيّر عالمياً ومحلياً.
  • تفرّق بين متغيّرات Sass ومتغيّرات CSS.
  • تنظّم متغيّراتك في نظام تصميم مبدئي.

لماذا المتغيّرات؟

اللون #6366f1 مكرّر في 40 موضعاً. جاء العميل وقال: «اجعله أزرق». الآن أمامك خياران: بحث واستبدال في كل الملفات (مع خطر تغيير قيمة لا تقصدها)، أو سطر واحد.

✗ خطأ
scss
.btn { background: #6366f1; }
.link { color: #6366f1; }
.badge { border-color: #6366f1; }
.title::after { background: #6366f1; }
أي تغيير يعني تعديل كل موضع، وأي خطأ مطبعي يمرّ بلا ملاحظة.
✓ صواب
scss
$color-brand: #6366f1;

.btn { background: $color-brand; }
.link { color: $color-brand; }
.badge { border-color: $color-brand; }
.title::after { background: $color-brand; }
سطر واحد يغيّر كل شيء، والاسم يوثّق النية.

التعريف والاستخدام

scss
// التعريف: علامة الدولار ثم الاسم ثم القيمة
$color-brand: #6366f1;
$spacing-md: 16px;
$font-heading: 'Cairo', sans-serif;
$radius: 12px;

// الاستخدام
.card {
  padding: $spacing-md;
  border-radius: $radius;
  font-family: $font-heading;
  border: 1px solid $color-brand;
}
اصطلاح التسمية

استخدم الشرطات لا الشرطة السفلية: $color-brand لا $color_brand. ورتّب الاسم من العام إلى الخاص: $color-text-muted أوضح من $muted-text-color عند الفرز الأبجدي.

$size: 16px;              // رقم بوحدة
$ratio: 1.5;              // رقم بلا وحدة
$name: 'CodeWay';         // نص
$brand: #6366f1;          // لون
$is-dark: false;          // منطقي

نصيحة

قيمة null مفيدة جداً: border: $border; تُحذف كلياً من الناتج إن كان $border فارغاً — فتستطيع جعل خاصية اختيارية داخل mixin.

العمليات الحسابية

scss
$base: 16px;

.el {
  font-size: $base;              // 16px
  padding: $base * 1.5;          // 24px
  margin-bottom: $base + 8px;    // 24px
  line-height: 24px / 16px;      // تجنّبها — انظر التحذير
}
القسمة تغيّرت

المعامل / أصبح مهملاً في Sass الحديثة لأنه يتعارض مع صياغة CSS المختصرة (font: 16px/1.5). استخدم math.div() من الوحدة الرياضية بدلاً منه.

الطريقة الصحيحة للقسمةscss
@use 'sass:math';

$base: 16px;

.el {
  line-height: math.div(24px, $base);   // 1.5
  width: math.div(100%, 3);             // 33.3333%
}
انتبه

لا يمكن جمع قيم بوحدات متعارضة: 10px + 2em خطأ. لكن 10px + 5 يعطي 15px لأن العدد المجرّد يأخذ وحدة الطرف الآخر.

الإقحام #{}

المتغيّر لا يعمل مباشرة داخل النصوص أو أسماء المحدّدات أو الخصائص. الإقحام يحلّ ذلك.

scss
$side: 'right';
$breakpoint: 768px;
$prefix: 'app';

.box {
  // في اسم الخاصية
  margin-#{$side}: 20px;          // margin-right: 20px

  // في قيمة نصية
  content: 'الاتجاه: #{$side}';

  // في استعلام الوسائط
  @media (min-width: #{$breakpoint}) { … }
}

// في اسم المحدّد
.#{$prefix}-card {
  padding: 16px;
}                                  // .app-card { … }

// في مسار الصورة
.hero {
  background-image: url('/img/#{$name}.jpg');
}
ناتج الإقحام

النطاق (Scope)

scss
$color: blue;          // عالمي

.card {
  $color: red;         // محلي — يظلّل العالمي داخل هذه الكتلة فقط
  border-color: $color; // red
}

.other {
  color: $color;       // blue — العالمي لم يتأثّر
}
التعديل العالميscss
$theme: light;

.dark-mode {
  $theme: dark !global;   // يغيّر المتغيّر العالمي نفسه
}
انتبه

!global مصدر شائع للأخطاء الغامضة: قيمة تتغيّر من مكان بعيد فتتساءل لماذا. تجنّبها إلا لضرورة حقيقية.

!default — القيم القابلة للتخصيص

حين تبني مكتبة أو نظام تصميم، تريد أن تعطي قيماً افتراضية يستطيع المستخدم تجاوزها. علامة !default تعني: «استخدم هذه القيمة إن لم تكن محدّدة مسبقاً».

_theme.scssscss
$color-brand: #6366f1 !default;
$radius: 12px !default;
$font-base: 16px !default;
main.scss — تخصيص المكتبةscss
@use 'theme' with (
  $color-brand: #dd0031,
  $radius: 4px
);
// $font-base بقي 16px لأننا لم نمرّره

هذه الآلية هي ما يجعل مكتبات مثل Bootstrap قابلة للتخصيص الكامل دون تعديل ملفاتها الأصلية.

الجمع بينهما — أفضل الممارساتscss
@use 'sass:color';

// قيم Sass للبناء والحسابات
$brand: #6366f1;
$radius-base: 12px;

// تصديرها كمتغيّرات CSS للثيمات
:root {
  --color-brand: #{$brand};
  --color-brand-dark: #{color.adjust($brand, $lightness: -12%)};
  --radius: #{$radius-base};
}

[data-theme='dark'] {
  --color-brand: #{color.adjust($brand, $lightness: 15%)};
}

// الاستخدام: متغيّر CSS ليتبدّل مع الثيم
.btn {
  background: var(--color-brand);
  border-radius: var(--radius);
}
نصيحة

القاعدة العملية: Sass للحساب والتوليد، وCSS للثيمات. احسب القيم بـ Sass ثم صدّرها إلى :root كمتغيّرات CSS.

معلومة

لاحظ استخدام مقياس لا قيم عشوائية: المسافات مضاعفات 4، وأحجام الخط بنسب متتالية. هذا ما يجعل التصميم يبدو متّسقاً حتى لو لم يعرف الناظر السبب.

تمرين: نظام متغيّرات لمشروعك

ابنِ ملف متغيّرات كاملاً واستخدمه في تنسيق بطاقة.

المطلوب:

  • أنشئ _variables.scss يحوي: 5 ألوان، مقياس مسافات من 5 قيم، 4 أحجام خطوط، 3 أنصاف أقطار، وظلّين.
  • كل المتغيّرات بعلامة !default.
  • في main.scss استوردها بـ @use ... with (...) وغيّر لوناً واحداً.
  • صدّر ثلاثة من المتغيّرات إلى :root كمتغيّرات CSS بالإقحام.
  • نسّق بطاقة .card تستخدم متغيّرات Sass للمسافات ومتغيّر CSS للون.
  • استخدم math.div مرة واحدة لحساب line-height.
  • استخدم الإقحام #{} في اسم خاصية أو في استعلام وسائط.
  • أضف كتلة [data-theme="dark"] تغيّر متغيّرات CSS فقط ولاحظ تبدّل الشكل.

تلميحات:

  • 💡 @use "sass:math"; يجب أن تكون في أعلى الملف.
  • 💡 الإقحام ضروري داخل :root: --x: #{$x};.
  • 💡 تجاوز القيم الافتراضية يتم في @use ... with (...) لا بإعادة التعريف.
عرض الحل المقترح
الحلscss
/* ===== _variables.scss ===== */
$color-brand:  #6366f1 !default;
$color-text:   #0f172a !default;
$color-muted:  #64748b !default;
$color-border: #e2e8f0 !default;
$color-surface:#ffffff !default;

$space-1: 4px  !default;
$space-2: 8px  !default;
$space-3: 12px !default;
$space-4: 16px !default;
$space-5: 24px !default;

$fs-sm: 0.875rem !default;
$fs-md: 1rem     !default;
$fs-lg: 1.25rem  !default;
$fs-xl: 1.5rem   !default;

$radius-sm: 6px  !default;
$radius-md: 12px !default;
$radius-lg: 20px !default;

$shadow-sm: 0 2px 6px rgba(15,23,42,.07)  !default;
$shadow-md: 0 8px 24px rgba(15,23,42,.09) !default;

$bp-md: 768px !default;

/* ===== main.scss ===== */
@use 'sass:math';
@use 'variables' as v with (
  $color-brand: #dd0031
);

:root {
  --color-brand: #{v.$color-brand};
  --color-surface: #{v.$color-surface};
  --radius: #{v.$radius-md};
}

[data-theme='dark'] {
  --color-brand: #f472b6;
  --color-surface: #111a2e;
}

.card {
  background: var(--color-surface);
  border: 1px solid v.$color-border;
  border-radius: var(--radius);
  padding: v.$space-5;
  box-shadow: v.$shadow-md;

  // القسمة الصحيحة
  line-height: math.div(28px, 16px);

  // الإقحام في اسم خاصية
  $side: 'inline-start';
  border-#{$side}: 4px solid var(--color-brand);

  .card__title {
    color: var(--color-brand);
    font-size: v.$fs-lg;
    margin-bottom: v.$space-2;
  }

  .card__text {
    color: v.$color-muted;
    font-size: v.$fs-md;
  }

  // الإقحام في استعلام وسائط
  @media (min-width: #{v.$bp-md}) {
    padding: v.$space-5 * 1.5;
  }
}

اختبر فهمك

1. ما الفرق الجوهري بين $x و --x؟

الشرح: متغيّر Sass يختفي في الناتج؛ متغيّر CSS يبقى ويمكن تغييره بجافاسكربت أو بالثيم.

2. ما البديل الصحيح لمعامل القسمة /؟

الشرح: المعامل / مهمل لتعارضه مع صياغة CSS المختصرة.

3. ماذا تعني !default؟

الشرح: أساس تخصيص المكتبات: المستخدم يمرّر قيمه عبر @use ... with (...).

4. متى تحتاج الإقحام #{}؟

الشرح: المتغيّر لا يُقيَّم تلقائياً في هذه المواضع، فيلزم الإقحام.

5. ما فائدة قيمة null لخاصية؟

الشرح: مفيدة لجعل خاصية اختيارية داخل mixin دون كتابة شرط.
