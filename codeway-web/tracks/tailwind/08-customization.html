التخصيص وبناء نظامك

تخصيص الثيم في CSS، إضافة ألوان وخطوط ومقاييس، والتوجيهات @apply و @utility و @variant.

45 دقيقة مسار Tailwind CSS 5 أسئلة 1 تمرين

ماذا ستتعلّم في هذا الدرس؟

  • تخصّص الثيم بتوجيه @theme.
  • تضيف ألواناً وخطوطاً ومقاييس خاصة بمشروعك.
  • تنشئ أدوات مخصّصة بـ @utility.
  • تنشئ متغيّرات مخصّصة بـ @custom-variant.
  • تعرف متى تستخدم @apply ومتى تتجنّبها.

التخصيص في CSS

في الإصدار الرابع لم يعد التخصيص في ملف جافاسكربت، بل في CSS نفسها عبر توجيه @theme. كل متغيّر تعرّفه يولّد أصنافاً تلقائياً.

style.csscss
@import "tailwindcss";

@theme {
  /* ألوان مخصّصة */
  --color-brand-50:  #eef2ff;
  --color-brand-100: #e0e7ff;
  --color-brand-300: #a5b4fc;
  --color-brand-500: #6366f1;
  --color-brand-700: #4338ca;
  --color-brand-900: #312e81;

  /* خطوط */
  --font-sans: 'Cairo', 'Segoe UI', sans-serif;
  --font-display: 'Tajawal', sans-serif;

  /* مسافات إضافية */
  --spacing-18: 4.5rem;
  --spacing-112: 28rem;

  /* نقاط توقف */
  --breakpoint-3xl: 1920px;

  /* حواف وظلال */
  --radius-4xl: 2rem;
  --shadow-glow: 0 0 40px rgb(99 102 241 / 0.35);
}

<h1 class="font-display">خط العناوين</h1>
<div class="p-18 mt-112">مسافات مخصّصة</div>
<div class="3xl:grid-cols-6">نقطة توقف مخصّصة</div>

الاصطلاح يصنع الأصناف

اسم المتغيّر يحدّد الأصناف المولّدة: --color- تولّد bg- و text- و border-، و--spacing- تولّد p- و m- و gap-، و--font- تولّد font-. لا حاجة لأي إعداد إضافي.

الاستبدال الكامل

css
@theme {
  /* احذف كل ألوان Tailwind الافتراضية */
  --color-*: initial;

  /* ثم عرّف لوحتك أنت فقط */
  --color-ink: #0f172a;
  --color-paper: #fefefe;
  --color-accent: #dd0031;
}
انتبه

الاستبدال الكامل يقلّص حجم الناتج ويفرض الالتزام بنظامك، لكنه يعني أن bg-red-500 لن تعمل. قرار جيد لمشروع بهوية صارمة، وسيّئ لنموذج أوّلي سريع.

نصيحة

صيغة oklch أحدث وأدقّ من hex: تغيير الإضاءة (الرقم الأول) يعطي تدرّجاً بصرياً متساوياً، بخلاف hex التي تعطي قفزات غير متناسقة. Tailwind نفسها تستخدمها في لوحتها.

الثيمات ومتغيّرات وقت التشغيل

css
@import "tailwindcss";

@custom-variant dark (&:where([data-theme="dark"], [data-theme="dark"] *));

@theme {
  --color-surface: #ffffff;
  --color-ink: #0f172a;
}

@layer base {
  [data-theme='dark'] {
    --color-surface: #111a2e;
    --color-ink: #e8edf9;
  }
}

أدوات مخصّصة بـ @utility

css
@import "tailwindcss";

/* أداة بسيطة */
@utility text-shadow {
  text-shadow: 0 2px 8px rgb(0 0 0 / 0.25);
}

/* أداة بقيمة متغيّرة */
@utility scrollbar-* {
  scrollbar-color: --value(--color- *) transparent;
}

/* أداة مركّبة */
@utility card-base {
  border-radius: var(--radius-2xl);
  border: 1px solid var(--color-slate-200);
  background: var(--color-white);
  padding: --spacing(6);
  box-shadow: var(--shadow-md);
}
html
<h1 class="text-shadow">عنوان بظل</h1>

<!-- الأدوات المخصّصة تقبل كل المتغيّرات -->

ميزة @utility على @apply: الأداة المخصّصة تعمل مع كل المتغيّرات (hover: و md: و dark:) تماماً كأدوات Tailwind الأصلية.

متغيّرات مخصّصة

css
/* الوضع الليلي بسمة data */
@custom-variant dark (&:where([data-theme="dark"], [data-theme="dark"] *));

/* حالة الاتجاه */
@custom-variant rtl (&:where([dir="rtl"], [dir="rtl"] *));

/* حالة مخصّصة من سمة */
@custom-variant loading (&[data-loading="true"]);

/* عند التمرير */
@custom-variant scrolled (&:where(.is-scrolled, .is-scrolled *));
html
<div class="dark:bg-slate-900">…</div>
<span class="rtl:rotate-180">←</span>
<button data-loading="true" class="loading:opacity-50 loading:pointer-events-none">
  حفظ
</button>

@apply — استخدمها بحذر

css
@layer components {
  .btn-primary {
    @apply rounded-lg bg-brand-600 px-6 py-3 font-bold text-white
           transition hover:bg-brand-700
           focus-visible:outline-2 focus-visible:outline-offset-2;
  }
}
لماذا الحذر؟

يبدو @apply حلاً مثالياً لكنه يعيدك إلى مشكلة CSS التقليدية: ملف ينمو، أسماء تخترعها، وانتقال بين ملفين. أنشأت Tailwind لتتخلّص من هذا بالضبط.

استخدم @apply حينتجنّبه حين
لا تملك نظام مكوّنات (HTML خام)تستخدم React/Vue/Angular — المكوّن يكفي
تنسّق محتوى من محرّر نصوصتنسّق مكوّناتك الخاصة
تكتب مكتبة أنماط للتوزيعمشروع تطبيق عادي
حالات نادرة جداًكعادة متكرّرة
✗ خطأ
html
<!-- CSS -->
.btn { @apply px-6 py-3 rounded-lg bg-sky-600 text-white; }

<!-- HTML -->
<button class="btn">إرسال</button>
عدت إلى ملفين ومصطلح جديد تخترعه. ما الفائدة من Tailwind إذن؟
✓ صواب
html
// مكوّن React
function Button({ children, ...props }) {
  return (
    <button
      className="px-6 py-3 rounded-lg bg-sky-600 text-white"
      {...props}
    >
      {children}
    </button>
  );
}
إعادة الاستخدام الحقيقية على مستوى المكوّن، لا على مستوى الصنف.
نصيحة

إن كنت في HTML خام بلا إطار مكوّنات، فالبديل الأفضل لـ @apply هو @utility — تعطيك أداة حقيقية تعمل مع كل المتغيّرات.

الطبقات

css
@import "tailwindcss";

/* أنماط أساسية للعناصر */
@layer base {
  html {
    scroll-behavior: smooth;
  }

  body {
    @apply bg-slate-50 text-slate-800 antialiased;
  }

  h1, h2, h3 {
    @apply font-display font-extrabold text-slate-900;
  }

  :focus-visible {
    @apply outline-2 outline-offset-2 outline-brand-500;
  }
}

/* مكوّنات — أولوية أقل من الأدوات */
@layer components {
  .prose-ar {
    @apply max-w-prose leading-loose;
  }
}
معلومة

ترتيب الأولوية: base ← components ← utilities. لهذا تستطيع تجاوز أي مكوّن بأداة: <div class="prose-ar leading-normal"> ستفوز فيها leading-normal.

نتيجة النظام

تمرين: نظام تصميم لعلامتك

خصّص Tailwind بالكامل لمشروع بهوية بصرية خاصة.

المطلوب:

  • لوحة ألوان علامة من 9 درجات باسم مخصّص (لا blue ولا indigo).
  • ألوان أسطح دلالية: surface, canvas, ink, muted, line.
  • خطّان: --font-sans للنص و--font-display للعناوين.
  • ثلاث مسافات إضافية غير موجودة في المقياس الافتراضي.
  • نقطة توقف مخصّصة 3xl.
  • ظل مخصّص --shadow-glow.
  • متغيّر مخصّص dark بسمة data-theme، وثيم داكن يبدّل ألوان الأسطح.
  • أداتان مخصّصتان بـ @utility: واحدة للبطاقة وأخرى لتأثير نصي.
  • أنماط أساسية في @layer base: الجسم، العناوين، مؤشّر التركيز.
  • صفحة تجريبية تستخدم كل ما سبق وتعمل في الوضعين.

تلميحات:

  • 💡 أسماء المتغيّرات تحدّد الأصناف: --color-x-500 تولّد bg-x-500.
  • 💡 ألوان الأسطح تُعرَّف في @theme وتُبدَّل في @layer base.
  • 💡 الأدوات المخصّصة تعمل مع كل المتغيّرات بخلاف @apply.

اختبر فهمك

1. أين يتم التخصيص في Tailwind الإصدار الرابع؟

الشرح: الإصدار الرابع نقل التخصيص إلى CSS، فلا حاجة لملف جافاسكربت.

2. ماذا يولّد --color-brand-500 في @theme؟

الشرح: الاصطلاح في اسم المتغيّر يحدّد عائلة الأصناف المولّدة.

3. ما ميزة @utility على @apply؟

الشرح: @apply تنتج قاعدة عادية لا تقبل بادئات المتغيّرات.

4. متى يكون @apply مبرّراً؟

الشرح: مع أطر المكوّنات، المكوّن نفسه هو وحدة إعادة الاستخدام الصحيحة.

5. ما ترتيب أولوية الطبقات؟

الشرح: الأدوات أخيراً لتتمكّن من تجاوز المكوّنات والأنماط الأساسية.

أنهيت قراءة الدرس؟ علّمه كمكتمل ليُحتسب في تقدّمك.
