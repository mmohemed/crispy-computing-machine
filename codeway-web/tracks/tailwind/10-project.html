مشروع: صفحة هبوط متكاملة

بناء صفحة هبوط احترافية متجاوبة بالوضع الليلي، تطبّق كل ما تعلّمته في المسار.

120 دقيقة مسار Tailwind CSS 5 أسئلة 1 تمرين

ماذا ستتعلّم في هذا الدرس؟

  • تخطّط صفحة هبوط بأقسامها المعتادة.
  • تدمج كل أدوات Tailwind في مشروع واحد.
  • تبني واجهة متجاوبة تماماً وبوضع ليلي.
  • تحقّق معايير إمكانية الوصول والأداء.
  • تنشر المشروع على الإنترنت.

ما ستبنيه

صفحة هبوط لمنتج تقني اسمه نَسَق: منصة إدارة مشاريع عربية. صفحة واحدة كاملة تعرض كل ما يجيده مطوّر واجهات.

قاعدة الورشة

اقرأ المواصفات كاملة، خطّط الأقسام على ورقة، ثم ابنِ قسماً قسماً واختبره على ثلاثة أحجام قبل الانتقال. لا تنظر للحل قبل إنهاء محاولتك.

المتطلّبات التقنية

التصميم

  • لوحة ألوان مخصّصة في @theme (لا blue الافتراضي).
  • خط عربي محمّل بثلاثة أوزان.
  • وضع ليلي كامل يعمل تلقائياً ويدوياً مع حفظ التفضيل.
  • نظام مسافات متّسق — لا قيم عشوائية إلا بمبرّر.

التجاوب

  • يعمل بامتياز من 375 بكسل إلى 1920.
  • لا تمرير أفقي على أي حجم.
  • قائمة جوال تعمل (يمكن بـ details بلا جافاسكربت).
  • أحجام الخطوط متدرّجة عبر نقاط التوقف.

إمكانية الوصول

  • رابط تخطٍّ إلى المحتوى.
  • focus-visible واضح على كل عنصر تفاعلي.
  • تباين ألوان يحقّق المستوى AA.
  • كل الأيقونات الزخرفية بـ aria-hidden.
  • كل الحركات محمية بـ motion-safe/motion-reduce.
  • ترتيب عناوين منطقي: h1 واحد ثم h2 للأقسام.

src/theme.jsjs
(function () {
  const KEY = 'theme';

  // تطبيق التفضيل المحفوظ قبل الرسم
  try {
    const saved = localStorage.getItem(KEY);
    if (saved) document.documentElement.dataset.theme = saved;
  } catch (e) {}

  document.addEventListener('click', function (e) {
    if (!e.target.closest('[data-theme-toggle]')) return;

    const isDark = document.documentElement.dataset.theme === 'dark'
      || (!document.documentElement.dataset.theme
          && matchMedia('(prefers-color-scheme: dark)').matches);

    const next = isDark ? 'light' : 'dark';
    document.documentElement.dataset.theme = next;

    try { localStorage.setItem(KEY, next); } catch (e) {}
  });
})();

نصيحة

حيلة أنيقة: details تعطيك قائمة جوال تعمل بلوحة المفاتيح وقارئات الشاشة بلا سطر جافاسكربت واحد.

قائمة المراجعة النهائية

  1. الصفحة تعمل على 375 و 768 و 1440 و 1920 بلا تمرير أفقي.
  2. الوضع الليلي يعمل تلقائياً ويدوياً ويحفظ التفضيل.
  3. التنقّل بمفتاح Tab يصل لكل عنصر تفاعلي بمؤشّر واضح.
  4. رابط التخطّي يظهر عند أول ضغطة Tab.
  5. كل الحركات تتوقّف مع prefers-reduced-motion.
  6. Lighthouse: 90+ في Performance و Accessibility و SEO.
  7. حجم CSS المضغوط أقل من 20 كيلوبايت.
  8. لا اسم صنف مبني ديناميكياً.
  9. الأصناف مرتّبة بـ Prettier.
  10. الصفحة منشورة على رابط حقيقي.

المشروع الكامل

نفّذ صفحة هبوط «نَسَق» بكل المواصفات أعلاه.

المطلوب:

  • الأقسام العشرة كلها.
  • كل المتطلّبات التقنية (تصميم، تجاوب، وصول).
  • قائمة المراجعة كلها ✓.
  • منشورة على Netlify أو Vercel أو GitHub Pages.

تلميحات:

  • 💡 ابنِ قسماً واحداً كاملاً واختبره على ثلاثة أحجام قبل التالي.
  • 💡 ابدأ بالجوال دائماً ثم أضف البادئات.
  • 💡 استخدم container-page لكل قسم لتوحيد الحاوية.
  • 💡 اختبر الوضع الليلي بعد كل قسم لا في النهاية.
  • 💡 إن تعثّرت في موضوع، عد إلى درسه لا إلى بداية المسار.

ماذا بعد؟

أنهيت مسار Tailwind: الفلسفة والمسافات والألوان والطباعة والتخطيط والحالات والتجاوب والتأثيرات والتخصيص والمكوّنات. أنت الآن قادر على بناء أي واجهة بسرعة واتّساق.

  • shadcn/ui — مكوّنات جاهزة تنسخها إلى مشروعك وتملكها بالكامل.
  • Headless UI — مكوّنات تفاعلية بلا أنماط، تنسّقها بـ Tailwind.
  • Framer Motion — حركات متقدّمة تتكامل مع Tailwind.
  • Tailwind UI — قوالب رسمية مدفوعة عالية الجودة.
  • بناء نظام تصميم كامل لفريقك بالمبادئ التي تعلّمتها.

1. ما ترتيب البناء الصحيح في التصميم المتجاوب؟

الشرح: يتوافق مع منطق Tailwind ويقلّل الأصناف المطلوبة.

2. كيف تبني قائمة جوال بلا جافاسكربت؟

الشرح: details تأتي بدعم لوحة المفاتيح وقارئات الشاشة مجاناً.

الشرح: التطبيق المبكر يمنع ومضة الوضع الفاتح قبل تحميل السكربت.
