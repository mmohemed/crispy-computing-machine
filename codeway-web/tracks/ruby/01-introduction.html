ما هي Ruby؟

لغة برمجة مفسَّرة، ديناميكية، وكائنية بالكامل، أنشأها الياباني يوكيهيرو ماتسوموتو (المعروف بـ Matz) عام 1995. كان هدفه المعلَن غريباً في عالم اللغات: أن تجعل المبرمج سعيداً، لا أن تُرضي المترجِم.

يقول Matz: «أريد أن تكون Ruby طبيعية، لا بسيطة». الفرق دقيق ومهم: الشيفرة تُقرأ كجملة إنجليزية، والأشياء المتوقّعة تعمل كما تتوقّع دون أن تبحث في التوثيق.

ruby
# اقرأ هذا السطر بصوت عالٍ — إنه جملة مفهومة
5.times { puts "مرحباً" }

# وهذا أيضاً
[3, 1, 2].sort.reverse.first   # => 3

# وحتى هذا
puts "متأخر" if Time.now.hour > 22

كل شيء كائن — حرفياً

في معظم اللغات هناك «أنواع بدائية» (أعداد، منطقيات) وكائنات. في Ruby لا يوجد هذا الفصل: الرقم كائن، والنصّ كائن، وحتى nil كائن. كل شيء يستجيب لرسائل (تُستدعى عليه دوال).

ruby
5.class          # => Integer
5.even?          # => false
-7.abs           # => 7
3.14.round       # => 3
"مرحبا".length   # => 5
nil.to_a         # => []
true.class       # => TrueClass
Integer.class    # => Class   ← حتى الصنف نفسه كائن!
معلومة

هذه ليست تفصيلة أكاديمية. لأن كل شيء كائن، تختفي الحالات الخاصة من اللغة: لا تحتاج دالة abs(x) منفصلة، بل x.abs. القاعدة واحدة في كل مكان، فتقلّ الأشياء التي عليك حفظها.

التثبيت

لا تستخدم Ruby المرفقة مع النظام

ماك ولينكس يأتيان بإصدار قديم من Ruby يستخدمه النظام نفسه. تعديله أو التثبيت عليه قد يعطب أدوات النظام. ثبّت دائماً إصداراً خاصاً بك عبر مدير إصدارات.

ماك ولينكس — عبر rbenv

bash
# ماك (يتطلّب Homebrew)
brew install rbenv ruby-build

# أوبنتو / ديبيان
sudo apt update && sudo apt install rbenv

# أضف السطر التالي لملف الصدفة (~/.zshrc أو ~/.bashrc)
eval "$(rbenv init - zsh)"

# ثم أعد فتح الطرفية وثبّت أحدث إصدار
rbenv install 3.3.6
rbenv global 3.3.6
ruby -v          # ruby 3.3.6

ويندوز — عبر RubyInstaller

  1. حمّل RubyInstaller with DevKit من rubyinstaller.org (اختر أحدث إصدار Ruby+Devkit x64).
  2. شغّل المثبّت واترك خيار Add Ruby executables to your PATH مفعّلاً.
  3. في نهاية التثبيت ستُسأل عن تشغيل ridk install — وافق واختر الخيار 3 لتثبيت أدوات البناء.
  4. افتح موجّه الأوامر واكتب ruby -v للتأكّد.
نصيحة

إن أردت التجربة قبل التثبيت، استخدم replit.com أو try.ruby-lang.org — تكتب Ruby في المتصفّح مباشرة.

أول برنامج

أنشئ ملفاً باسم hello.rb:

ruby
# hello.rb — أول برنامج بـ Ruby
name = "زائر"

puts "مرحباً يا #{name}!"
puts "أهلاً بك في عالم Ruby."
puts "اليوم: #{Time.now.strftime('%Y-%m-%d')}"
bash
ruby hello.rb
# مرحباً يا زائر!
# أهلاً بك في عالم Ruby.
# اليوم: 2026-08-27

لاحظ #{...} — تُسمّى الاستيفاء (Interpolation): تُنفَّذ الشيفرة داخل الأقواس وتُدرج نتيجتها في النصّ. تعمل داخل علامات التنصيص المزدوجة فقط.

طرق الطباعة الثلاث

الدالةماذا تفعلمتى تستخدمها
putsتطبع وتضيف سطراً جديداً، وتفكّ المصفوفات سطراً سطراًالمخرجات للمستخدم
printتطبع بلا سطر جديدبناء سطر على مراحل
pتطبع التمثيل البرمجي (inspect) وتُرجع الكائنالتنقيح والاستكشاف
ruby
puts "نصّ"     # نصّ
print "نصّ"    # نصّ  (بلا سطر جديد)
p "نصّ"        # "نصّ"  ← لاحظ علامات التنصيص

puts [1, 2, 3]  # يطبع كل عنصر في سطر
p    [1, 2, 3]  # [1, 2, 3]

puts nil        # سطر فارغ
p    nil        # nil    ← أوضح بكثير عند التنقيح
نصيحة

عند مطاردة خطأ استخدم p لا puts: p يفرّق بين nil والنصّ الفارغ وبين 1 و "1"، وهذا غالباً هو الفرق الذي تبحث عنه.

IRB — مختبرك التفاعلي

اكتب irb في الطرفية لتفتح صدفة تنفّذ Ruby سطراً سطراً وتعرض نتيجة كل تعبير. إنها أسرع طريقة للإجابة على سؤال «ماذا يفعل هذا؟».

bash
$ irb
irb(main):001> 2 + 3
=> 5
irb(main):002> "ruby".upcase
=> "RUBY"
irb(main):003> [1,2,3].sum
=> 6
irb(main):004> "نصّ".methods.size
=> 190
irb(main):005> exit
معلومة

جرّب 5.methods.sort في IRB لترى كل ما يستطيع الرقم فعله. هذه عادة ممتازة: بدل البحث في جوجل، اسأل الكائن نفسه.

الفراغات والنهايات

Ruby لا يحتاج فاصلة منقوطة في نهاية السطر، ولا أقواساً معقوفة للكتل — يستخدم كلمة end. المسافة البادئة بمقدار مسافتين (لا أربع ولا Tab) هي العُرف المتّبع.

✗ خطأ
ruby
def greet(name);
    if name.empty?;
        return "مرحباً يا زائر";
    end;
    return "مرحباً يا " + name;
end;
فواصل منقوطة لا لزوم لها، مسافة بادئة رباعية، وreturn صريحة حيث لا تلزم — كلها ضدّ العُرف.
✓ صواب
ruby
def greet(name)
  return "مرحباً يا زائر" if name.empty?

  "مرحباً يا #{name}"
end
مسافتان، حارس بصيغة اللاحقة، واستيفاء بدل الجمع. آخر تعبير في الدالة هو قيمتها المُرجَعة تلقائياً.

القيمة المُرجَعة الضمنية

كل شيء في Ruby تعبير له قيمة، والدالة تُرجع قيمة آخر تعبير فيها دون حاجة لكلمة return. هذه من أوضح سمات اللغة.

ruby
def double(x)
  x * 2        # لا حاجة لـ return
end

double(5)      # => 10

# حتى الشرط تعبير له قيمة
status = if 85 >= 60 then "ناجح" else "راسب" end
status         # => "ناجح"

# وحتى الإسناد نفسه تعبير
puts (x = 3)   # => 3
نصيحة

استخدم return فقط للخروج المبكّر من الدالة (كالحرّاس في بدايتها). في نهاية الدالة اتركها — وجودها هناك يُعدّ ضجيجاً في عرف Ruby.

محرّر مناسب

  1. ثبّت VS Code من code.visualstudio.com.
  2. ثبّت إضافة Ruby LSP من Shopify — تعطيك إكمالاً تلقائياً وانتقالاً للتعريف وتشخيصاً للأخطاء.
  3. ثبّت إضافة endwise — تكتب end تلقائياً عند كتابة def أو class.

تمرين

بطاقة تعريف تفاعلية

اكتب سكربتاً يسأل المستخدم عن بياناته ثم يعرض بطاقة تعريف منسّقة.

المطلوب:

  • اسأل عن الاسم وسنة الميلاد والمدينة واللغة المفضّلة باستخدام gets.chomp.
  • احسب العمر التقريبي من سنة الميلاد.
  • اعرض بطاقة داخل إطار مرسوم بالرموز، بعرض ثابت.
  • استخدم الاستيفاء #{} في كل السطور، ولا تستخدم + لجمع النصوص.
  • أضف سطراً يعرض تاريخ اليوم بصيغة عربية مقروءة.
  • إن ترك المستخدم الاسم فارغاً، استخدم "زائر" بدلاً منه.

تلميحات:

  • 💡 gets تُرجع النصّ مع سطر جديد في نهايته، وchomp تزيله.
  • 💡 gets.chomp.to_i تحوّل المدخل إلى عدد صحيح.
  • 💡 "─" * 40 تكرّر الرمز أربعين مرة.
  • 💡 str.center(40) توسّط النصّ داخل عرض محدّد.
عرض الحل المقترح
الحلruby
# card.rb — بطاقة تعريف تفاعلية
WIDTH = 44

print "ما اسمك؟ "
name = gets.chomp
name = "زائر" if name.empty?

print "سنة ميلادك؟ "
birth_year = gets.chomp.to_i

print "مدينتك؟ "
city = gets.chomp

print "لغتك البرمجية المفضّلة؟ "
language = gets.chomp

age = Time.now.year - birth_year

line = "─" * WIDTH

puts
puts "┌#{line}┐"
puts "│#{'بطاقة تعريف'.center(WIDTH)}│"
puts "├#{line}┤"
puts "│ الاسم:    #{name.ljust(WIDTH - 11)}│"
puts "│ العمر:    #{"#{age} سنة".ljust(WIDTH - 11)}│"
puts "│ المدينة:  #{city.ljust(WIDTH - 11)}│"
puts "│ اللغة:    #{language.ljust(WIDTH - 11)}│"
puts "├#{line}┤"
puts "│ التاريخ:  #{Time.now.strftime('%Y/%m/%d').ljust(WIDTH - 11)}│"
puts "└#{line}┘"
puts
puts "أهلاً بك يا #{name} في رحلة تعلّم Ruby!"

اختبر نفسك

اختبر فهمك

1. ما الهدف المعلَن الذي بُنيت عليه Ruby؟

الشرح: صرّح Matz بأن هدفه جعل المبرمج سعيداً، وهذا يفسّر كثيراً من قرارات تصميم اللغة.

2. أيّ العبارات صحيحة عن الأنواع في Ruby؟

الشرح: لا يوجد فصل بين البدائي والكائن؛ 5.class يُرجع Integer وInteger.class يُرجع Class.

3. ما الفرق بين puts و p؟

الشرح: p "5" يطبع "5" بينما puts "5" يطبع 5 — الفرق حاسم عند مطاردة خطأ.

4. لماذا لا نستخدم Ruby المرفقة مع نظام التشغيل؟

الشرح: استخدم مدير إصدارات مثل rbenv لتثبيت نسخة مستقلة تحت تحكّمك.

5. ماذا تُرجع دالة لا تحوي return؟

الشرح: القيمة المُرجَعة الضمنية سمة أساسية في Ruby، ووجود return في النهاية يُعدّ ضجيجاً.

6. ما دلالة ? في نهاية اسم دالة مثل empty?؟

الشرح: اصطلاح لا يفرضه المفسّر لكن المجتمع ملتزم به تماماً، ومثله ! للدوال المُعدِّلة أو الخطرة.
