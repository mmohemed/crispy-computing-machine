المتغيّرات وأنواع البيانات

الأعداد والنصوص والرموز والقيم المنطقية و nil، وأنواع المتغيّرات الخمسة ونطاق كلٍّ منها.

50 دقيقة مسار Ruby 7 أسئلة 1 تمرين

ماذا ستتعلّم في هذا الدرس؟

  • تعرّف متغيّراً وتفهم أن Ruby لا يحتاج تصريحاً بالنوع.
  • تميّز بين أنواع المتغيّرات الخمسة ونطاق كلٍّ منها.
  • تتعامل مع الأعداد الصحيحة والعشرية والكسور بدقّة.
  • تتقن النصوص: الاستيفاء والدوال الشائعة والقابلية للتعديل.
  • تفهم متى تستخدم الرمز (Symbol) بدل النصّ.
  • تفرّق بين nil والفراغ، وتتعامل معه بأمان.

المتغيّر ليس صندوقاً — إنه ملصق

في Ruby لا تصرّح بنوع المتغيّر ولا تحجز له مساحة. المتغيّر مجرّد اسم يشير إلى كائن موجود في الذاكرة. هذا الفهم يوفّر عليك أخطاءً كثيرة لاحقاً.

ruby
x = 5           # x يشير إلى الكائن 5
x = "نصّ"       # الآن يشير إلى نصّ — لا مشكلة
x = [1, 2, 3]   # والآن إلى مصفوفة

a = "مرحبا"
b = a           # b و a يشيران لنفس الكائن!
b << " بك"      # نعدّل الكائن نفسه
puts a          # => "مرحبا بك"  ← تفاجأت؟

a.object_id == b.object_id   # => true
الفخّ الأشهر للمبتدئين

الإسناد b = a لا ينسخ الكائن، بل ينسخ المرجع. إن أردت نسخة مستقلة استخدم b = a.dup.

ruby
a = "مرحبا"
b = a.dup       # نسخة مستقلة
b << " بك"
puts a          # => "مرحبا"   ← لم يتأثّر

أنواع المتغيّرات الخمسة

Ruby يميّز نوع المتغيّر من أول حرف في اسمه لا من كلمة مفتاحية. هذا اختصار أنيق يخبرك بنطاق المتغيّر بمجرّد رؤيته.

النوعالصياغةالنطاقالاستخدام
محليnameالكتلة أو الدالة الحالية فقطالأغلبية الساحقة
مثيل@nameالكائن الواحدحالة الكائن — سنستخدمه كثيراً في OOP
صنف@@countالصنف وكل مثيلاته وورّاثهنادر؛ يُفضَّل تجنّبه
عام$debugالبرنامج كلّهتجنّبه إلا لأغراض خاصة
ثابتMAXالصنف/الوحدة، ومقروء من الخارجقيم لا تتغيّر
ruby
class Counter
  MAX = 100          # ثابت
  @@total = 0        # متغيّر صنف — مشترك بين كل المثيلات

  def initialize(name)
    @name  = name    # متغيّر مثيل — خاص بهذا الكائن
    @count = 0
    @@total += 1
  end

  def increment
    step = 1         # متغيّر محلي — يختفي بانتهاء الدالة
    @count += step
    raise "تجاوز الحدّ" if @count > MAX
    @count
  end

  def self.total = @@total
end

a = Counter.new("أول")
b = Counter.new("ثانٍ")
Counter.total        # => 2
Counter::MAX         # => 100
نصيحة

قاعدة عملية: استخدم المتغيّرات المحلية افتراضياً، ومتغيّرات المثيل لحالة الكائن، والثوابت للقيم الثابتة. أما متغيّرات الصنف @@ والعامة $ فتجنّبها — لهما بدائل أفضل دائماً.

فخّ القسمة الصحيحة

✗ خطأ
ruby
total = 7
count = 2
average = total / count    # => 3   ✗ ضاع الكسر!
قسمة عدد صحيح على عدد صحيح تُرجع عدداً صحيحاً في Ruby — يُقتطع الكسر بصمت.
✓ صواب
ruby
total = 7
count = 2
average = total.fdiv(count)   # => 3.5
# أو
average = total / count.to_f  # => 3.5
fdiv تقسم قسمة عشرية دائماً، وهي أوضح من تحويل أحد المعاملين يدوياً.

دقّة العشرية

ruby
0.1 + 0.2               # => 0.30000000000000004  ← ليست مشكلة Ruby
0.1 + 0.2 == 0.3        # => false !

# للمال والحسابات الدقيقة استخدم Rational أو BigDecimal
require 'bigdecimal'
require 'bigdecimal/util'

(0.1.to_d + 0.2.to_d) == 0.3.to_d   # => true

# أو الكسور النسبية — دقيقة تماماً
(1r/3) * 3              # => (1/1)
لا تخزّن المال في Float أبداً

خطأ التقريب يتراكم مع آلاف العمليات فينتج فرق حقيقي في الحسابات. خزّن المبالغ كـ أعداد صحيحة بالهللات/السنتات أو استخدم BigDecimal.

النصوص

النصّ في Ruby كائن غنيّ جداً بالدوال، وهو قابل للتعديل (Mutable) خلافاً لكثير من اللغات.

التنصيص المزدوج مقابل المفرد

ruby
name = "سارة"

"مرحباً #{name}"     # => "مرحباً سارة"   ← استيفاء يعمل
'مرحباً #{name}'     # => "مرحباً #{name}"  ← نصّ حرفي

"سطر\nجديد"          # => يطبع سطرين
'سطر\nجديد'          # => يطبع \n حرفياً
نصيحة

استخدم التنصيص المزدوج افتراضياً — الفرق في الأداء معدوم عملياً، والانتقال للاستيفاء لاحقاً لا يحتاج تعديل النوع.

النصوص متعدّدة الأسطر

ruby
# heredoc — <<~ يزيل المسافة البادئة المشتركة
message = <<~TEXT
  عزيزي العميل،

  تمّ استلام طلبك رقم #{123}.
  شكراً لثقتك.
TEXT

# <<~ (مع ~) هو ما تريده دائماً
# <<- يحافظ على المسافات البادئة

أهم دوال النصّ

ruby
s = "  Ruby رائعة  "

s.strip           # => "Ruby رائعة"    يزيل الفراغات الطرفية
s.length          # => 15
s.upcase          # => "  RUBY رائعة  "
s.downcase        # => "  ruby رائعة  "
s.reverse

s.start_with?("  ")  # => true
s.sub("Ruby", "روبي")    # يستبدل أول تطابق
s.gsub("a", "A")         # يستبدل كل التطابقات
s.split(" ")             # => ["Ruby", "رائعة"]
s.strip.chars            # => ["R","u","b","y"," ",...]
"abc" * 3                # => "abcabcabc"

دوال بعلامة !

ruby
s = "ruby"

s.upcase      # => "RUBY"   لكن s نفسها لم تتغيّر
s             # => "ruby"

s.upcase!     # يعدّل s نفسها
s             # => "RUBY"

# انتبه: دوال ! تُرجع nil إن لم يحدث تغيير
"RUBY".upcase!   # => nil !
خطأ شائع

كتابة name = name.strip! قد تجعل name تساوي nil إن لم يكن هناك فراغ يُزال. لا تسند نتيجة دالة ! لمتغيّر — استخدم النسخة بلا علامة تعجّب.

s = "برمجة"

s[0, 3]     # => "برم"   ابدأ من 0 وخذ 3
s[1..3]     # => "رمج"   مدى
s[1...3]    # => "رم"    مدى حصري
s[/م\S+/]   # => "مجة"   بتعبير نمطي

الرموز (Symbols)

الرمز نصّ خفيف وغير قابل للتعديل يُنشَأ مرة واحدة في الذاكرة مهما تكرّر. يُكتب بنقطتين قبله: :name.

ruby
"name".object_id == "name".object_id   # => false — كائنان مختلفان
:name.object_id  == :name.object_id    # => true  — نفس الكائن دائماً
استخدمه رمزاً حين…استخدمه نصّاً حين…
يكون معرّفاً ثابتاً في الشيفرةيكون بيانات من المستخدم أو الشبكة
مفتاح Hash: { name: "سارة" }قيمة يعرضها المستخدم
اسم دالة: send(:save)نصّ ستعدّله أو تبني عليه
حالة أو خيار: status: :activeمحتوى يُطبع أو يُخزَّن
ruby
# رموز كمفاتيح — الاصطلاح الشائع
user = { name: "سارة", role: :admin, active: true }
user[:name]     # => "سارة"

# النصّ لأن هذه بيانات
comment = "شكراً على المقال!"

# تحويل بين الاثنين
:admin.to_s     # => "admin"
"admin".to_sym  # => :admin

القيم المنطقية و nil

قاعدة Ruby في الصدق بسيطة للغاية وتختلف عن أغلب اللغات: كل شيء صادق إلا false و nil. لا استثناءات.

ruby
if 0        then puts "0 صادق!"      end   # ✅ يُطبع
if ""       then puts "الفراغ صادق!" end   # ✅ يُطبع
if []       then puts "[] صادقة!"    end   # ✅ يُطبع
if nil      then puts "لن يُطبع"     end   # ❌
if false    then puts "لن يُطبع"     end   # ❌
معلومة

في JavaScript و Python يُعتبر 0 و "" كاذبين. في Ruby هما صادقان. إن جئت من لغة أخرى فهذه أول عادة عليك تغييرها.

التعامل الآمن مع nil

ruby
user = nil

user.name              # ✗ NoMethodError
user&.name             # => nil  ← الاستدعاء الآمن
user&.name&.upcase     # => nil  ← يمكن تسلسله

# قيمة افتراضية
name = user&.name || "زائر"

# اختبارات
nil.nil?               # => true
"".empty?              # => true
nil.to_s               # => ""
nil.to_a               # => []
nil.to_i               # => 0

# الفرق بين الفارغ والفراغ
"".nil?                # => false !
"   ".strip.empty?     # => true
✗ خطأ
ruby
if user != nil && user.profile != nil && user.profile.bio != nil
  puts user.profile.bio
end
ثلاثة اختبارات متداخلة — طويل ويصعب قراءته، ويتضاعف مع كل مستوى.
✓ صواب
ruby
bio = user&.profile&.bio
puts bio if bio

# أو بقيمة افتراضية
puts user&.profile&.bio || "لا توجد نبذة"
الاستدعاء الآمن &. يتوقّف عند أول nil ويُرجع nil مباشرة.

التحويل بين الأنواع

ruby
"42".to_i        # => 42
"42abc".to_i     # => 42     ← يتساهل ويأخذ ما يستطيع
"abc".to_i       # => 0      ← خطر! لا يرمي خطأ

Integer("42")    # => 42
Integer("abc")   # ✗ ArgumentError  ← أفضل للمدخلات غير الموثوقة

"3.9".to_f       # => 3.9
3.9.to_i         # => 3      ← يقتطع لا يقرّب
3.9.round        # => 4

[1,2].to_a
{a: 1}.to_a      # => [[:a, 1]]
[[:a, 1]].to_h   # => {a: 1}
نصيحة

استخدم to_i حين تثق بالمدخل، وInteger() حين تريد أن ينفجر الخطأ فوراً بدل أن يتسلّل صفر خاطئ في بياناتك.

التجميد (freeze)

ruby
CONFIG = { host: "localhost", port: 3000 }.freeze
CONFIG[:port] = 4000    # ✗ FrozenError

NAME = "CodeWay".freeze
NAME << "!"             # ✗ FrozenError

CONFIG.frozen?          # => true
:sym.frozen?            # => true  الرموز مجمّدة أصلاً
42.frozen?              # => true  والأعداد كذلك
معلومة

أضف # frozen_string_literal: true كأول سطر في ملفاتك: يجمّد كل النصوص الحرفية تلقائياً فيقلّ استهلاك الذاكرة وتُكتشَف التعديلات غير المقصودة مبكّراً.

محلّل نصّ ومحوّل وحدات

اكتب سكربتاً يحلّل نصّاً يدخله المستخدم ويعرض إحصاءات عنه، ثم يحوّل بين وحدات.

المطلوب:

  • اطلب من المستخدم جملة، واعرض: عدد الحروف (مع الفراغات وبدونها)، عدد الكلمات، عدد الجمل.
  • اعرض أطول كلمة وأقصر كلمة.
  • اعرض الجملة معكوسة، وبأحرف كبيرة، وبصيغة snake_case.
  • اطلب مبلغاً بالريال وحوّله للدولار بسعر 3.75، مع تقريب لخانتين.
  • اطلب درجة حرارة مئوية وحوّلها لفهرنهايت.
  • خزّن أسعار التحويل في ثوابت مجمّدة لا متغيّرات.
  • تعامل بأمان مع المدخل الفارغ — لا تنهر البرنامج.
  • استخدم Integer() أو Float() للتحقّق من المدخلات الرقمية.

تلميحات:

  • 💡 text.split تقسّم على أي فراغ وتتجاهل الفراغات المتعدّدة.
  • 💡 words.max_by(&:length) تُرجع أطول كلمة.
  • 💡 text.count(" ") تعدّ الفراغات، و text.delete(" ").length تعدّ الحروف بدونها.
  • 💡 rescue ArgumentError يمسك خطأ التحويل الفاشل.
عرض الحل المقترح
الحلruby
# frozen_string_literal: true
# analyzer.rb — محلّل نصّ ومحوّل وحدات

SAR_TO_USD = 3.75
SEPARATOR  = ("─" * 46).freeze

def ask_number(prompt)
  print prompt
  Float(gets.chomp)
rescue ArgumentError
  puts "  ⚠️  مدخل غير رقمي — سنستخدم 0"
  0.0
end

# ===== 1) تحليل النصّ =====
print "اكتب جملة: "
text = gets.chomp

if text.strip.empty?
  puts "لم تكتب شيئاً!"
  exit
end

words     = text.split
sentences = text.split(/[.!?؟]/).reject { |s| s.strip.empty? }

puts
puts SEPARATOR
puts "تحليل النصّ".center(44)
puts SEPARATOR
puts "الحروف (مع الفراغ):  #{text.length}"
puts "الحروف (بلا فراغ):   #{text.delete(' ').length}"
puts "الكلمات:             #{words.size}"
puts "الجمل:               #{sentences.size}"
puts "أطول كلمة:           #{words.max_by(&:length)}"
puts "أقصر كلمة:           #{words.min_by(&:length)}"
puts SEPARATOR
puts "معكوسة:   #{text.reverse}"
puts "كبيرة:     #{text.upcase}"
puts "snake_case: #{text.strip.downcase.gsub(/\s+/, '_')}"
puts SEPARATOR

# ===== 2) تحويل العملة =====
puts
amount = ask_number("المبلغ بالريال: ")
usd    = (amount / SAR_TO_USD).round(2)
puts "  #{amount} ريال = #{usd} دولار  (بسعر #{SAR_TO_USD})"

# ===== 3) تحويل الحرارة =====
puts
celsius    = ask_number("الحرارة بالمئوية: ")
fahrenheit = (celsius * 9.0 / 5 + 32).round(1)
puts "  #{celsius}°C = #{fahrenheit}°F"

اختبر نفسك

اختبر فهمك

1. ماذا يحدث بعد b = a ثم b << "x" حين تكون a نصّاً؟

الشرح: الإسناد ينسخ المرجع لا الكائن؛ استخدم dup لنسخة مستقلة.

2. ما نتيجة 7 / 2 في Ruby؟

الشرح: استخدم 7.fdiv(2) أو 7 / 2.0 للحصول على 3.5.

3. أيّ القيم كاذبة في Ruby؟

الشرح: قاعدة Ruby أبسط من أغلب اللغات: كل شيء صادق إلا false و nil.

4. متى تستخدم الرمز :name بدل النصّ "name"؟

الشرح: الرمز يُنشَأ مرة واحدة في الذاكرة، والنصّ للبيانات المتغيّرة القادمة من المستخدم.

5. ماذا تُرجع "RUBY".upcase!؟

الشرح: لهذا لا تسند نتيجة دالة ! لمتغيّر أبداً.

6. ما فائدة user&.profile&.bio؟

الشرح: الاستدعاء الآمن &. يختصر سلاسل الاختبارات المتداخلة.

7. لماذا لا نخزّن المال في Float؟

الشرح: 0.1 + 0.2 != 0.3؛ استخدم أعداداً صحيحة بالهللات أو BigDecimal.
