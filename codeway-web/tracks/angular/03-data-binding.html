ربط البيانات والتحكّم في التدفّق

أنواع الربط الأربعة، والصياغة الحديثة للشروط والحلقات، والتعامل مع الأحداث.

50 دقيقة مسار Angular 5 أسئلة 1 تمرين

ماذا ستتعلّم في هذا الدرس؟

  • تستخدم أنواع الربط الأربعة في مواضعها.
  • تعرض المحتوى شرطياً بـ @if و @switch.
  • تكرّر العناصر بـ @for وتفهم أهمية track.
  • تستمع للأحداث وتمرّر بياناتها.
  • تربط الأصناف والأنماط ديناميكياً.

أنواع الربط الأربعة

الربط هو الجسر بين صنف المكوّن وقالبه. أربعة أنواع تغطّي كل الحالات، والفرق بينها هو اتجاه تدفّق البيانات.

اتجاهات الربط

1. الإقحام {{ }}

html
<h1>{{ title }}</h1>
<p>{{ user.firstName }} {{ user.lastName }}</p>
<p>الإجمالي: {{ price * quantity }}</p>
<p>{{ isAdmin ? 'مدير' : 'مستخدم' }}</p>
<p>{{ description || 'لا يوجد وصف' }}</p>
<p>{{ user?.address?.city }}</p>
معلومة

المعامل ?. (Safe navigation) يمنع الخطأ إن كانت القيمة null أو undefined — مفيد جداً مع بيانات لم تصل بعد من الخادم.

2. ربط الخاصية [ ]

الإقحام يعمل مع النصوص فقط. لتمرير قيمة حقيقية (رقم، منطقي، كائن) تحتاج ربط الخاصية.

✗ خطأ
html
<button disabled="{{ isLoading }}">إرسال</button>
يُمرَّر النص "false" وهو قيمة صادقة، فيبقى الزر معطّلاً دائماً!
✓ صواب
html
<button [disabled]="isLoading">إرسال</button>
تُمرَّر القيمة المنطقية الحقيقية فيعمل الزر كما هو متوقّع.
html
<img [src]="imageUrl" [alt]="imageAlt" [width]="300">
<input [value]="username" [placeholder]="hint">
<a [href]="'/products/' + product.id">التفاصيل</a>

<!-- ربط سمة HTML (لا خاصية DOM) -->
<td [attr.colspan]="span">…</td>
<button [attr.aria-label]="label">✕</button>
خاصية أم سمة؟

معظم الأشياء خصائص DOM وتُربط بـ [prop]. لكن colspan و aria-* و role سمات HTML لا خصائص، فتحتاج البادئة attr. — وإلا ستحصل على خطأ «Can't bind to…».

3. ربط الحدث ( )

html
<button (click)="save()">حفظ</button>
<button (click)="remove(item.id)">حذف</button>

<!-- كائن الحدث -->
<input (input)="onType($event)">
<form (submit)="onSubmit($event)">…</form>

<!-- مُعدِّلات المفاتيح -->
<input (keyup.enter)="search()">
<input (keyup.escape)="clear()">
ts
onType(event: Event): void {
  const value = (event.target as HTMLInputElement).value;
  console.log(value);
}

onSubmit(event: Event): void {
  event.preventDefault();
  // معالجة الإرسال
}

4. الربط الثنائي [( )]

ts
import { FormsModule } from '@angular/forms';

@Component({
  standalone: true,
  imports: [FormsModule],   // ضروري لعمل ngModel
  template: `
    <input [(ngModel)]="searchTerm" placeholder="ابحث…">
    <p>تبحث عن: {{ searchTerm }}</p>
  `
})
export class SearchComponent {
  searchTerm = '';
}
صندوق الموز في العلبة

الصياغة [()] تُسمّى مازحاً «banana in a box». وهي ليست سحراً: مجرّد اختصار لـ [ngModel]="x" و (ngModelChange)="x = $event" معاً.

أثر الربط الثنائي

التحكّم في التدفّق

منذ Angular 17 توجد صياغة مدمجة في القالب أوضح وأسرع من التوجيهات القديمة ngIf و ngFor.

@if و @else

html
@if (user) {
  <p>أهلاً {{ user.name }}</p>
} @else if (isLoading) {
  <p>جارٍ التحميل…</p>
} @else {
  <a href="/login">سجّل الدخول</a>
}
الصياغة القديمة للمقارنةhtml
<p *ngIf="user; else loginTpl">أهلاً {{ user.name }}</p>
<ng-template #loginTpl>
  <a href="/login">سجّل الدخول</a>
</ng-template>
نصيحة

الصياغة الجديدة أوضح ولا تحتاج استيراد CommonModule، وأداؤها أفضل. استخدمها في كل مشروع جديد.

@for والمفتاح track

html
@for (product of products; track product.id) {
  <app-product-card [product]="product" />
} @empty {
  <p>لا توجد منتجات لعرضها.</p>
}
`track` إلزامية وليست اختيارية

بدونها لا يعرف Angular أي عنصر يقابل أيّاً بعد التغيير، فيعيد بناء القائمة كاملة — يفقد المستخدم ما كتبه في الحقول ويهبط الأداء. استخدم معرّفاً فريداً ثابتاً، ولا تستخدم الفهرس $index إلا إن كانت القائمة ثابتة الترتيب.

المتغيّرات المتاحة داخل @forhtml
@for (item of items; track item.id; let i = $index, isFirst = $first) {
  <div [class.first]="isFirst">
    {{ i + 1 }}. {{ item.name }}
  </div>
}

<!-- المتغيّرات: $index, $first, $last, $even, $odd, $count -->
قائمة مرقّمة بتلوين متناوب

@switch

html
@switch (order.status) {
  @case ('pending')   { <span class="badge warn">قيد المراجعة</span> }
  @case ('shipped')   { <span class="badge info">تم الشحن</span> }
  @case ('delivered') { <span class="badge ok">تم التسليم</span> }
  @default            { <span class="badge">غير معروف</span> }
}

ربط الأصناف والأنماط

html
<!-- صنف واحد شرطي -->
<div [class.active]="isActive">…</div>

<!-- عدة أصناف بكائن -->
<div [ngClass]="{
  'active': isActive,
  'disabled': isDisabled,
  'highlighted': score > 90
}">…</div>

<!-- من متغيّر -->
<div [ngClass]="statusClass">…</div>

<!-- نمط واحد -->
<div [style.width.%]="progress">…</div>
<div [style.color]="isError ? 'red' : 'green'">…</div>

<!-- عدة أنماط -->
<div [ngStyle]="{
  'width.px': barWidth,
  'background-color': barColor
}">…</div>
شريط تقدّم مربوط
نصيحة

للحالات البسيطة استخدم [class.x] و [style.y] — أسرع وأوضح من ngClass و ngStyle اللذين يحتاجان CommonModule.

مراجع القالب

html
<input #nameInput type="text">
<button (click)="greet(nameInput.value)">رحّب</button>

<video #player src="clip.mp4"></video>
<button (click)="player.play()">تشغيل</button>

المرجع #name يمنحك وصولاً مباشراً إلى العنصر داخل القالب فقط، بلا حاجة إلى document.querySelector.

تمرين: قائمة مهام تفاعلية

ابنِ مكوّناً لإدارة قائمة مهام يستخدم أنواع الربط الأربعة والتحكّم في التدفّق.

المطلوب:

  • مصفوفة tasks فيها كائنات: id, title, done.
  • حقل إدخال مربوط ثنائياً بـ newTask.
  • زر «إضافة» يضيف المهمة ويفرّغ الحقل، ويكون معطّلاً إن كان الحقل فارغاً.
  • عرض المهام بـ @for مع track task.id و @empty.
  • كل مهمة لها مربّع اختيار يبدّل done، ويُشطب نصّها عند الإكمال.
  • زر حذف لكل مهمة.
  • عدّاد يعرض «تم إنجاز س من ص».
  • رسالة تهنئة بـ @if تظهر حين تكتمل كل المهام.
  • الاستجابة لمفتاح Enter في الحقل لإضافة المهمة.

تلميحات:

  • 💡 لا تنسَ imports: [FormsModule] لعمل ngModel.
  • 💡 (keyup.enter)="addTask()" تلتقط مفتاح Enter مباشرة.
  • 💡 [class.done]="task.done" أبسط من ngClass هنا.
عرض الحل المقترح
الحلts
import { Component } from '@angular/core';
import { FormsModule } from '@angular/forms';

interface Task {
  id: number;
  title: string;
  done: boolean;
}

@Component({
  selector: 'app-tasks',
  standalone: true,
  imports: [FormsModule],
  template: `
    <section class="tasks">
      <h2>قائمة المهام</h2>

      <div class="add">
        <input
          [(ngModel)]="newTask"
          (keyup.enter)="addTask()"
          placeholder="أضف مهمة جديدة…">
        <button (click)="addTask()" [disabled]="!newTask.trim()">
          إضافة
        </button>
      </div>

      <ul>
        @for (task of tasks; track task.id) {
          <li [class.done]="task.done">
            <input
              type="checkbox"
              [checked]="task.done"
              (change)="toggle(task)">
            <span>{{ task.title }}</span>
            <button (click)="remove(task.id)" aria-label="حذف">✕</button>
          </li>
        } @empty {
          <li class="empty">لا توجد مهام بعد.</li>
        }
      </ul>

      <p class="counter">تم إنجاز {{ doneCount }} من {{ tasks.length }}</p>

      @if (tasks.length > 0 && doneCount === tasks.length) {
        <p class="congrats">🎉 أنجزت كل المهام!</p>
      }
    </section>
  `,
  styles: [`
    .add { display: flex; gap: 8px; margin-bottom: 16px; }
    input[type="text"] { flex: 1; padding: 9px 12px; border: 1px solid #cbd5e1; border-radius: 8px; }
    ul { list-style: none; padding: 0; }
    li { display: flex; align-items: center; gap: 10px; padding: 10px; border-bottom: 1px solid #eef2f7; }
    li.done span { text-decoration: line-through; color: #94a3b8; }
    li span { flex: 1; }
    .empty { color: #94a3b8; justify-content: center; }
    .congrats { color: #10b981; font-weight: 700; }
  `]
})
export class TasksComponent {
  newTask = '';
  private nextId = 1;

  tasks: Task[] = [
    { id: 0, title: 'قراءة درس ربط البيانات', done: true }
  ];

  get doneCount(): number {
    return this.tasks.filter(t => t.done).length;
  }

  addTask(): void {
    const title = this.newTask.trim();
    if (!title) return;
    this.tasks.push({ id: this.nextId++, title, done: false });
    this.newTask = '';
  }

  toggle(task: Task): void {
    task.done = !task.done;
  }

  remove(id: number): void {
    this.tasks = this.tasks.filter(t => t.id !== id);
  }
}

اختبر فهمك

1. ما الخطأ في <button disabled="{{ isLoading }}">؟

الشرح: الإقحام يُنتج نصاً؛ النص "false" قيمة صادقة. الصواب [disabled]="isLoading".

2. لماذا track إلزامية في @for؟

الشرح: بدونها يُعاد بناء القائمة كاملة، فتضيع حالة العناصر ويهبط الأداء.

3. ما اختصار [(ngModel)]="x"؟

الشرح: الربط الثنائي مجرّد اختصار لربط خاصية وربط حدث معاً.

4. متى تحتاج البادئة attr. في الربط؟

الشرح: بعض السمات لا يقابلها خاصية DOM، فيلزم [attr.colspan].

5. ما وظيفة @empty في @for؟

الشرح: تغني عن كتابة @if (items.length === 0) منفصلة.

أنهيت قراءة الدرس؟ علّمه كمكتمل ليُحتسب في تقدّمك.
