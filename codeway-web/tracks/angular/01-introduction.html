مقدمة في Angular وإعداد المشروع

ما هو Angular ولماذا يختلف عن المكتبات، وكيف تنشئ مشروعك الأول وتفهم بنية ملفاته.

ما هو Angular؟

إطار عمل شامل من جوجل لبناء تطبيقات الويب الكبيرة، مبني بالكامل على TypeScript. يختلف جوهرياً عن المكتبات: لا يعطيك قطعة واحدة ويتركك تجمع الباقي، بل يأتي بكل شيء جاهزاً ومتوافقاً.

الاحتياجفي React (مكتبة)في Angular (إطار)
بناء الواجهةReact نفسهامدمج
التوجيه بين الصفحاتتختار: React Router أو غيرهمدمج: @angular/router
طلبات HTTPتختار: fetch أو axiosمدمج: HttpClient
النماذج والتحقّقتختار مكتبةمدمج: ReactiveFormsModule
حقن الاعتمادياتغير موجودمدمج في صميم المعمارية
أدوات البناء والاختبارتُعدّها بنفسكجاهزة عبر CLI
الخلاصة

Angular يقرّر عنك كثيراً من الخيارات. هذا يقلّل حرّيتك ويزيد اتّساق المشاريع — ولهذا تفضّله المؤسسات والفرق الكبيرة، حيث يهمّ أن يبدو كل مشروع كالآخر.

ثمن الدخول وفائدته

أنواع صارمة

TypeScript إلزامية عملياً — أخطاء أقل في وقت التشغيل ودعم ممتاز من المحرّر.

معمارية واضحة

المكوّن للعرض، والخدمة للمنطق، والوحدة للتنظيم. لا اجتهاد في التقسيم.

أدوات جاهزة

CLI يولّد الملفات ويشغّل الاختبارات ويبني الإنتاج بأمر واحد.

مناسب للفرق

اصطلاحات موحّدة تجعل انتقال المطوّر بين المشاريع سلساً.

منحنى تعلّم أعلى

مفاهيم كثيرة قبل أن تكتب شيئاً مفيداً — هذا هو الثمن.

حجم أكبر

الحزمة الأولية أكبر من المكتبات الخفيفة، لكنها تشمل كل شيء.

التثبيت وإنشاء المشروع

bash
# 1) تأكّد من وجود Node.js (نسخة 18 فأحدث)
node -v

# 2) ثبّت أداة سطر الأوامر عالمياً
npm install -g @angular/cli

# 3) تحقّق من التثبيت
ng version

# 4) أنشئ مشروعاً جديداً
ng new my-app
#    سيسألك: هل تريد التوجيه؟ نعم
#    وأي صيغة أنماط؟ CSS أو SCSS

# 5) شغّل خادم التطوير
cd my-app
ng serve --open
# يفتح http://localhost:4200
نصيحة

أضف --style=scss و --routing إلى ng new لتتجاوز الأسئلة: ng new my-app --routing --style=scss.

الوسم <app-root> ليس عنصر HTML قياسياً — بل مكوّن Angular. هذه هي الفكرة الأساسية: تخترع عناصرك الخاصة وتملؤها بالمنطق والقالب.

src/main.tsts
import { bootstrapApplication } from '@angular/platform-browser';
import { appConfig } from './app/app.config';
import { AppComponent } from './app/app.component';

bootstrapApplication(AppComponent, appConfig)
  .catch(err => console.error(err));

المكوّن الجذر

app.component.tsts
import { Component } from '@angular/core';

@Component({
  selector: 'app-root',
  standalone: true,
  imports: [],
  templateUrl: './app.component.html',
  styleUrl: './app.component.css'
})
export class AppComponent {
  title = 'تطبيقي الأول';
  lessonsDone = 12;
  lessonsTotal = 20;

  get progress(): number {
    return Math.round((this.lessonsDone / this.lessonsTotal) * 100);
  }
}
app.component.htmlhtml
<main class="app">
  <h1>{{ title }}</h1>
  <p>أكملت {{ lessonsDone }} من {{ lessonsTotal }} درساً ({{ progress }}%)</p>
  <progress [value]="lessonsDone" [max]="lessonsTotal"></progress>
</main>
النتيجة في المتصفح
المزخرف @Component

المزخرف (Decorator) دالة تضيف بيانات وصفية إلى الصنف. @Component تخبر Angular: هذا الصنف مكوّن، اسم وسمه كذا، وقالبه في هذا الملف. بدونه يبقى الصنف مجرّد صنف TypeScript عادي.

المكوّنات المستقلّة (Standalone)

في الإصدارات القديمة كان كل مكوّن يجب تسجيله في «وحدة» NgModule — طبقة تعقيد إضافية أربكت المبتدئين. منذ Angular 17 صارت المكوّنات المستقلّة هي الافتراضية: كل مكوّن يعلن اعتمادياته بنفسه في imports.

ts
@Component({
  selector: 'app-product-list',
  standalone: true,
  imports: [CommonModule, ProductCardComponent],  // ما يحتاجه هذا المكوّن
  templateUrl: './product-list.component.html'
})
export class ProductListComponent { }
نصيحة

إن وجدت شروحاً قديمة تتحدّث عن app.module.ts و declarations فهي لإصدارات سابقة. المسار هنا يتبع الأسلوب المستقلّ الحديث.

اللبنات المعمارية

اللبنةمسؤوليتهامثال
المكوّن (Component)قطعة واجهة: قالب + أنماط + منطق عرضبطاقة منتج، شريط تنقّل
القالب (Template)HTML مع صياغة Angular للربط{{ title }} و *ngIf
الخدمة (Service)منطق قابل لإعادة الاستخدام وجلب البياناتProductService
حقن الاعتماديات (DI)تسليم الخدمات للمكوّنات تلقائياًinject(ProductService)
التوجيه (Directive)يغيّر سلوك عنصر أو مظهره*ngIf, [ngClass]
الأنبوب (Pipe)يحوّل قيمة عند العرض{{ price | currency }}
الموجّه (Router)يربط العناوين بالمكوّنات/products ← ProductList

أوامر CLI التي ستستخدمها يومياً

bash
ng serve                      # تشغيل خادم التطوير
ng generate component header  # توليد مكوّن (اختصار: ng g c header)
ng g c products/product-card  # داخل مجلد فرعي
ng g s services/product       # توليد خدمة
ng g p pipes/truncate         # توليد أنبوب
ng g d directives/highlight   # توليد توجيه
ng build                      # بناء الإنتاج في dist/
ng test                       # تشغيل اختبارات الوحدة
ng update                     # ترقية Angular

أمر ng g c header وحده ينشئ أربعة ملفات، ويسجّل المكوّن، ويتّبع اصطلاحات التسمية. هذه القوة هي سبب اتّساق مشاريع Angular.

مخرجات أمر التوليد

دورة حياة التطبيق

  1. المتصفح يحمّل index.html وفيها <app-root> فارغ.
  2. يُنفَّذ main.ts فيقلع التطبيق بـ bootstrapApplication.
  3. يُنشئ Angular نسخة من AppComponent ويربطها بالوسم.
  4. يُعالَج القالب: تُقيَّم التعابير وتُطبَّق التوجيهات.
  5. يُرسم الناتج داخل <app-root>.
  6. عند تغيّر أي بيانات، يكتشف Angular التغيير ويحدّث الأجزاء المتأثّرة فقط.

تمرين: أول مشروع Angular

أنشئ مشروعاً وعدّل المكوّن الجذر ليعرض بيانات شخصية.

المطلوب:

  • أنشئ مشروعاً باسم my-portfolio مع التوجيه و SCSS.
  • شغّله وتأكّد من ظهوره على المنفذ 4200.
  • في AppComponent عرّف: fullName و job و city و yearsExperience.
  • أضف خاصية محسوبة get startYear() تحسب سنة البداية.
  • في القالب اعرض كل هذه القيم بصياغة الربط {{ }}.
  • ولّد مكوّناً جديداً باسم header بأمر CLI ولاحظ الملفات الأربعة.
  • أضف وسم <app-header> داخل قالب AppComponent (تذكّر إضافته إلى imports).

تلميحات:

  • 💡 لاستخدام مكوّن داخل آخر، أضفه إلى مصفوفة imports في @Component.
  • 💡 get في TypeScript تعرّف خاصية محسوبة تُستدعى بلا أقواس في القالب.
  • 💡 إن ظهر خطأ «is not a known element» فغالباً نسيت imports.
عرض الحل المقترح
app.component.tsts
import { Component } from '@angular/core';
import { HeaderComponent } from './header/header.component';

@Component({
  selector: 'app-root',
  standalone: true,
  imports: [HeaderComponent],
  templateUrl: './app.component.html',
  styleUrl: './app.component.scss'
})
export class AppComponent {
  fullName = 'سارة عبدالله';
  job = 'مطوّرة واجهات أمامية';
  city = 'الرياض';
  yearsExperience = 3;

  get startYear(): number {
    return new Date().getFullYear() - this.yearsExperience;
  }
}
القالب: <app-header></app-header> ثم <h1>{{ fullName }}</h1> و <p>{{ job }} — {{ city }}</p> و <p>بدأت عام {{ startYear }}</p>.

اختبر فهمك

1. ما الفرق الجوهري بين Angular و React؟

الشرح: Angular يوفّر التوجيه و HTTP والنماذج و DI مدمجة؛ React تتركها لاختيارك.

2. ما وظيفة المزخرف @Component؟

الشرح: بدونه يبقى الصنف صنف TypeScript عادياً لا يعرفه Angular.

3. ماذا يعني standalone: true؟

الشرح: الأسلوب الحديث الافتراضي منذ Angular 17؛ يغني عن طبقة الوحدات.

4. ما الأمر الذي يولّد مكوّناً جديداً؟

الشرح: ng generate component واختصاره ng g c ينشئ الملفات الأربعة ويتّبع الاصطلاحات.

5. أين يُرسم تطبيق Angular في الصفحة؟

الشرح: index.html تحوي وسم المكوّن الجذر، وAngular يملؤه عند الإقلاع.
