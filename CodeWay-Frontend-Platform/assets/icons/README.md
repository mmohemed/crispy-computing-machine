# الأيقونات

أيقونات الواجهة مجموعة خطية موحّدة (24×24) مضمّنة في `js/core.js` داخل الكائن `CW.ICONS`،
وتُستدعى عبر `CW.icon("name")`. هذا يضمن عمل الأيقونات دون اتصال بالإنترنت ودون مكتبات خارجية.

لإضافة أيقونة: أضف مسار SVG جديداً إلى `CW.ICONS` باسم مميز.
رموز اللغات والأدوات (Monograms) تُولَّد من حقلَي `mono` و `color` في ملفات البيانات.
