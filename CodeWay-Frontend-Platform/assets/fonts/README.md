# الخطوط

تستخدم المنصة خط **Tajawal** للنصوص و **JetBrains Mono** للكود عبر Google Fonts.
إذا تعذّر تحميل الخط (دون اتصال بالإنترنت) تعرض الصفحات خطوط النظام البديلة المعرفة في
`css/variables.css` (`--font` و `--font-mono`) دون أن ينهار التصميم.

للاستضافة المحلية: ضع ملفات `woff2` هنا وأضف قواعد `@font-face` في `css/global.css`،
ثم احذف وسم `<link>` الخاص بـ Google Fonts من الصفحات.
