# CodeWay — واجهات المنصة التعليمية (Front-End)

> **CodeWay — طريقك نحو احتراف البرمجة**
> مشروع واجهات أمامية لمنصة تعليمية عربية (RTL) لتعلم لغات البرمجة والأدوات والمجالات والمسارات المهنية والذكاء الاصطناعي.

هذه النسخة **واجهات فقط**: لا يوجد Backend أو قاعدة بيانات أو نظام تسجيل دخول حقيقي، ولا يوجد محتوى دروس فعلي.
صفحات الدروس قوالب جاهزة بنصوص توضيحية مثل «سيظهر شرح الدرس هنا».

---

## التشغيل

لا يحتاج المشروع إلى أي تثبيت.

**الطريقة 1 — مباشرة:** افتح الملف `index.html` بالمتصفح.

**الطريقة 2 — Live Server (موصى بها):**
1. افتح المجلد `CodeWay-Frontend-Platform` في Visual Studio Code.
2. ثبّت إضافة **Live Server**.
3. انقر بزر الفأرة الأيمن على `index.html` ← **Open with Live Server**.

**الطريقة 3 — أي خادم محلي:**
```bash
python3 -m http.server 8000
```
ثم افتح `http://localhost:8000`.

> تعمل الصفحات مع `file://` ومع الخادم المحلي. البيانات محمّلة كملفات JavaScript عادية (لا يوجد `fetch`)، لذلك لا تحتاج إلى خادم.
> الخطوط تُحمَّل من Google Fonts، وإن لم يتوفر الإنترنت تُستخدم خطوط النظام دون أن ينهار التصميم.

### كيف تعمل الصفحات؟
كل ملف HTML هيكل خفيف يحمّل ملفات CSS و JavaScript المشتركة، ويحدد نوعه عبر `<body data-page="...">`.
يرسم `app.js` الشريط العلوي والتذييل ثم يستدعي `CW.pages[page]()` الذي يبني المحتوى من ملفات البيانات.
صفحات التفاصيل تُقرأ من معاملات الرابط، مثل:

| الصفحة | مثال على الرابط |
|---|---|
| لغة | `pages/languages/language.html?id=python` |
| دروس وحدة | `pages/languages/lessons.html?id=python&m=2` |
| أداة | `pages/tools/tool.html?id=react&m=1` |
| مجال | `pages/fields/field.html?id=frontend` |
| مسار مهني | `pages/career-paths/path.html?id=data-analyst` |
| مجال ذكاء اصطناعي | `pages/artificial-intelligence/area.html?id=nlp` |
| موضوع علوم حاسوب | `pages/computer-science/topic.html?id=algorithms` |
| مشروع | `pages/projects/project.html?id=todo-list` |
| درس | `pages/lessons/lesson.html?track=lang&id=python&m=1&l=1` |
| اختبار | `pages/quizzes/quiz.html?id=python-basics` |

`track` في قالب الدرس: `lang` | `tool` | `cs` | `ai`.

## تعديل المحتوى والبيانات

كل البيانات في `js/data/`:

| الملف | المحتوى |
|---|---|
| `languages.js` | 16 لغة: الوصف، المستوى، الاستخدامات، المتطلبات، روابط التوثيق، الوحدات (اختيارية) |
| `tools.js` | 6 تصنيفات و50 أداة مع روابط التوثيق الرسمية |
| `fields.js` | 18 مجالاً: المهارات واللغات والأدوات والموضوعات |
| `careers.js` | 30 مساراً مهنياً (تُبنى خارطة كل مسار تلقائياً من بياناته) |
| `ai.js` | 6 مجالات للذكاء الاصطناعي |
| `cs.js` | 12 موضوعاً في علوم الحاسوب |
| `projects.js` | خطة 100 مشروع (25/30/25/20) ونماذج منشورة |
| `assessments.js` | الاختبارات وبنك أسئلة تجريبي والتدريبات |
| `demo-user.js` | المستخدم التجريبي ومستخدمو لوحة الإدارة الوهميون |

- **إضافة لغة/أداة/مشروع:** أضف كائناً جديداً بمعرّف (`id`) فريد، وسيظهر تلقائياً في القوائم والبحث والفلاتر والعلاقات.
- **تخصيص وحدات لغة:** أضف الحقل `modules: [...]` للغة (انظر SQL و R).
- **تخصيص خارطة مسار:** أضف الحقل `stages` للمسار بدلاً من البناء التلقائي.
- **تغيير الهوية البصرية:** عدّل `css/variables.css`.

### الربط مع Backend لاحقاً
- استبدل ملفات `js/data/*.js` بطلبات API تملأ `CW.data` بالهيكل نفسه قبل استدعاء `app.js`.
- محتوى الدرس: املأ المناطق المحددة في `js/pages/lesson.js` (الشرح، الأمثلة، الأخطاء الشائعة، الملخص...).
- محرك التنفيذ: اربط `CW.runJS` أو أضف دالة مماثلة تستدعي خادم تنفيذ لبقية اللغات في `js/code-runner.js`.

## ما يعمل فعلياً في الواجهة

- التنقل بين جميع الصفحات، وقائمة الهاتف، والقوائم المنسدلة، ومسار التنقل.
- البحث الفوري في الرئيسية، ولوحة البحث السريع (`Ctrl+K` أو `/`)، وصفحة الاستكشاف بالفلاتر.
- الفلاتر والترقيم والترتيب في صفحات القوائم مع حفظها في الرابط.
- التبويبات والأكورديون والنوافذ المنبثقة والإشعارات ونسخ الكود.
- قالب الدرس: التنقل بين الدروس والوحدات، وتحديد الدرس كمكتمل (يُحفظ محلياً).
- الاختبارات: الإجابة والتنقل بين الأسئلة وحساب النتيجة ومراجعة الإجابات (أسئلة تجريبية).
- **تشغيل JavaScript فعلياً** في محرر الأكواد وتدريبات JavaScript، داخل Worker معزول بمهلة زمنية.
- متطلبات المشروع القابلة للتعليم، وإعدادات الملف الشخصي (تُحفظ في المتصفح فقط).
- لوحة الإدارة: بحث وفلترة وترقيم وإضافة/تعديل/حذف في الذاكرة فقط.

## ما يحتاج Backend (غير منفذ)

- تسجيل الدخول وإنشاء الحساب وتسجيل الخروج وتغيير كلمة المرور.
- حفظ التقدم والنتائج والإعدادات على الخادم ومزامنتها بين الأجهزة.
- تشغيل لغات غير JavaScript (Python، Java، C++، ...) والتحقق التلقائي من حلولها.
- إرسال نموذج «اتصل بنا» ورفع الصورة الشخصية.
- حفظ تغييرات لوحة الإدارة وصلاحيات المستخدمين.

كل زر يعتمد على هذه الوظائف يعرض رسالة توضيحية بدلاً من ادعاء أنه يعمل.
