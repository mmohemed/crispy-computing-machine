# رتّل — تطبيق القرآن الكريم

تطبيق Flutter لقراءة القرآن الكريم، يعمل بدون إنترنت، مع خطة لربطه بـ Firebase.

## المزايا الحالية (المرحلة 1)
- فهرس السور الـ 114 والأجزاء الـ 30
- قارئ بصفحات المصحف (604 صفحة) بالسحب، بالخط القرآني Amiri Quran
- حفظ آخر موضع قراءة تلقائيًا وبطاقة «تابع القراءة»
- العلامات المرجعية (اضغط على أي آية) ونسخ الآية
- البحث في الآيات مع تجاهل التشكيل
- الوضع الليلي وتغيير حجم خط المصحف

## التشغيل
```bash
cd rattil
flutter pub get
flutter run
```

## البنية
```
lib/
├─ core/        الثيم، التوجيه (go_router)، أدوات النص العربي، التخزين
├─ data/        QuranRepository: الوصول إلى نص القرآن المضمَّن
└─ features/
   ├─ home/       الفهرس: السور، الأجزاء، العلامات
   ├─ reader/     قارئ المصحف وآخر موضع قراءة
   ├─ search/     البحث
   ├─ bookmarks/  العلامات
   └─ settings/   الإعدادات
```
إدارة الحالة بـ Riverpod، والتخزين المحلي بـ shared_preferences.

## الخطة القادمة
- **المرحلة 2:** التلاوة الصوتية (اختيار القارئ، تمييز الآية، التكرار، التشغيل في الخلفية)
- **المرحلة 3:** التفسير الميسّر، ومشاركة الآية كصورة
- **المرحلة 4 (Firebase):** تسجيل الدخول، مزامنة العلامات، مخطط الختمة، **الختمة الجماعية**، التذكير بالورد
- **المرحلة 5:** الإحصائيات، الأيقونة، شاشة البداية
