# تطبيق القرآن الكريم

تطبيق ويب عربي (RTL) لقراءة القرآن الكريم بالرسم العثماني، مع بحث في النص وعلامات مرجعية.
**يعمل بالكامل بدون إنترنت** — النص كله مخزَّن داخل المشروع، ولا يوجد أي طلب شبكة خارجي.

## التشغيل

الأفضل تشغيل خادم محلي (حتى يُحمَّل خط أميري بشكل صحيح):

```bash
cd quran
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

يمكن أيضاً فتح `quran/index.html` مباشرة في المتصفح، لكن بعض المتصفحات تمنع تحميل
الخطوط من مسار `file://` فيُستبدل خط أميري بخط النظام.

## المزايا

| الميزة | التفاصيل |
|---|---|
| 📖 القراءة | ١١٤ سورة، ٦٢٣٦ آية بالرسم العثماني (رواية حفص عن عاصم) بخط أميري |
| 🔍 البحث | بحث في كامل النص بلا حاجة لكتابة التشكيل، مع تمييز موضع المطابقة |
| 🔖 المفضلة | حفظ أي آية والرجوع إليها لاحقاً |
| 📍 موضع القراءة | يُحفظ آخر موضع تلقائياً أثناء التصفّح، وزر «متابعة القراءة» في الصفحة الرئيسية |
| 🗂️ الأجزاء | تنقّل عبر الأجزاء الثلاثين مع بداية ونهاية كل جزء |
| 🎨 المظهر | ثلاث سمات (فاتح، ورقي، داكن)، وتكبير الخط من ٨٠٪ إلى ٢٠٠٪ |
| 📱 الاستجابة | تصميم يعمل على الجوال والحاسب |

كل الإعدادات والعلامات المرجعية تُحفظ في متصفحك (`localStorage`) ولا تُرسل لأي جهة.

## البحث

صندوق البحث يفهم عدة صيغ:

| ما تكتبه | النتيجة |
|---|---|
| `الحمد لله رب العالمين` | كل الآيات التي يرد فيها النص (بلا حاجة للتشكيل) |
| `٢:٢٥٥` أو `2:255` | ينتقل مباشرة إلى آية الكرسي |
| `الكهف 10` | ينتقل إلى سورة الكهف، الآية ١٠ |
| `البق` | يقترح سورة البقرة |

يتعامل البحث مع فروق الرسم العثماني تلقائياً: يتجاهل التشكيل والتطويل، ويوحّد
الهمزات (أ إ آ ٱ) والألف المقصورة والتاء المربوطة، ويطابق الألف الخنجرية سواء كتبتها
ألفاً (`العالمين`) أو حذفتها (`الرحمن`).

## اختصارات لوحة المفاتيح

| المفتاح | الوظيفة |
|---|---|
| `/` | الانتقال إلى صندوق البحث |
| `←` | السورة التالية |
| `→` | السورة السابقة |
| `Esc` | إغلاق لوحة الإعدادات أو شريط الآية |

## البنية

```
quran/
├── index.html              هيكل الصفحة
├── css/styles.css          التنسيقات والسمات الثلاث
├── js/store.js             حفظ الإعدادات والمفضلة وموضع القراءة
├── js/search.js            تطبيع النص العربي، فهرس البحث، تحليل المراجع
├── js/app.js               التوجيه وبناء الشاشات والأحداث
├── data/quran-data.js      نص المصحف كاملاً (١٫٣ م.ب، مولَّد آلياً)
├── fonts/amiri-*.woff2     خط أميري (نسخة عربية مختصرة)
└── tests/run.js            فحوص تعمل بـ Node بلا حزم خارجية
```

## الفحوص

```bash
node quran/tests/run.js
```

تغطي الفحوص سلامة البيانات (عدد السور والآيات، البسملة، جدول الأجزاء)، وقواعد تطبيع
النص العربي، ونتائج البحث ومواضع التمييز، وتحليل المراجع.
