# تطبيق القرآن الكريم

تطبيق ويب عربي (RTL) لقراءة القرآن الكريم بالرسم العثماني، مع بحث في النص وعلامات مرجعية.
**يعمل بالكامل بدون إنترنت** — النص كله مخزَّن داخل المشروع، ولا يوجد أي طلب شبكة خارجي.

## أين التطبيق وكيف أحصل عليه؟

الملفات كلها في مجلد `quran/` داخل المستودع، على فرع `claude/quran-app-build-kusin4`.

### ١) تحميل نسخة الملف الواحد (الأسهل — للاستعمال والمشاركة)

ملف واحد اسمه **`quran-app.html`** (١٫٦ م.ب) يحتوي كل شيء: النص والخط والتنسيقات والشيفرة.
لا يحتاج خادماً ولا إنترنت ولا تنصيب — يكفي فتحه بأي متصفح.

- رابط التحميل المباشر:
  `https://github.com/mmohemed/crispy-computing-machine/raw/claude/quran-app-build-kusin4/quran/dist/quran-app.html`
- أو من صفحة الملف في GitHub ثم زر **Download**.

هذا الملف مبني آلياً من ملفات المشروع، ويمكن إعادة بنائه في أي وقت:

```bash
node quran/tools/build-single.js
```

### ٢) تحميل المشروع كاملاً

```bash
git clone -b claude/quran-app-build-kusin4 https://github.com/mmohemed/crispy-computing-machine.git
```

أو من صفحة الفرع في GitHub: زر **Code** ← **Download ZIP**.

## التشغيل على الحاسب

**نسخة الملف الواحد:** انقر عليه نقراً مزدوجاً ليفتح في المتصفح. انتهى.

**المشروع كاملاً:** الأفضل تشغيل خادم محلي، لأن المتصفحات تمنع بعض المزايا
(الخطوط، والعمل بدون إنترنت) عند الفتح المباشر من القرص:

```bash
cd quran
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## التثبيت على الجوال

التطبيق **PWA**، أي أنه يُثبَّت على الشاشة الرئيسية ويفتح بأيقونته الخاصة بلا شريط
متصفح، ويعمل بعدها بدون إنترنت. لكن التثبيت يحتاج أن يكون التطبيق منشوراً على رابط
`https` — والطريقة المجانية لذلك هي **GitHub Pages**:

### أ) نشر التطبيق على رابط (مرة واحدة فقط)

1. افتح المستودع في GitHub ← **Settings** ← **Pages**.
2. في **Source** اختر **Deploy from a branch**.
3. اختر الفرع `claude/quran-app-build-kusin4` والمجلد `/ (root)`، ثم **Save**.
4. انتظر دقيقة أو دقيقتين، وسيصبح رابط التطبيق:

   ```
   https://mmohemed.github.io/crispy-computing-machine/quran/
   ```

> إن أردت رابطاً أقصر، ادمج الفرع في الفرع الرئيسي واجعل مجلد `quran` هو الجذر،
> أو انشر مجلد `quran` وحده على [Netlify Drop](https://app.netlify.com/drop) بسحبه وإفلاته.

### ب) التثبيت من الرابط

| النظام | الخطوات |
|---|---|
| **أندرويد (Chrome)** | افتح الرابط ← قائمة ⋮ ← **تثبيت التطبيق** / **إضافة إلى الشاشة الرئيسية** |
| **آيفون (Safari)** | افتح الرابط ← زر المشاركة ⬆️ ← **إضافة إلى الشاشة الرئيسية** |

بعد التثبيت افتح التطبيق مرة واحدة وهو متصل بالإنترنت حتى يُخزّن المصحف كاملاً
(١٫٦ م.ب)، ثم سيعمل بعدها **بدون إنترنت نهائياً**.

> على آيفون يجب استخدام Safari تحديداً للتثبيت؛ متصفحات آيفون الأخرى لا تدعم ذلك.

## كيف أرسله لشخص آخر ليستعمله على جواله؟

| الطريقة | ماذا ترسل | ما الذي يفعله المستلم | تُثبَّت كأيقونة؟ |
|---|---|---|---|
| **١. الرابط** (الأفضل) | رابط GitHub Pages أعلاه | يفتحه ثم يضيفه للشاشة الرئيسية | ✅ نعم |
| **٢. الملف الواحد** | ملف `quran-app.html` عبر واتساب أو تيليجرام أو البريد | يحمّله ويفتحه بمتصفحه | ❌ يفتح كصفحة فقط |
| **٣. رابط الملف** | رابط تحميل `quran-app.html` المباشر | يحمّله ويفتحه | ❌ يفتح كصفحة فقط |

**الخلاصة:** إن أردت تجربة «تطبيق حقيقي» بأيقونة على الشاشة ويعمل دون إنترنت، أرسل
**الرابط**. وإن أردت شيئاً يعمل فوراً بلا أي إعداد ولا حساب ولا نشر، أرسل **الملف**.

> ملاحظة عن واتساب: قد يرفض إرسال ملفات `.html` أحياناً. الحل: اضغط الملف في ملف
> `zip` قبل إرساله، أو استخدم تيليجرام أو البريد الإلكتروني.

## المزايا

| الميزة | التفاصيل |
|---|---|
| 📖 القراءة | ١١٤ سورة، ٦٢٣٦ آية بالرسم العثماني (رواية حفص عن عاصم) بخط أميري |
| 🔍 البحث | بحث في كامل النص بلا حاجة لكتابة التشكيل، مع تمييز موضع المطابقة |
| 🔖 المفضلة | حفظ أي آية والرجوع إليها لاحقاً |
| 📍 موضع القراءة | يُحفظ آخر موضع تلقائياً أثناء التصفّح، وزر «متابعة القراءة» في الصفحة الرئيسية |
| 🗂️ الأجزاء | تنقّل عبر الأجزاء الثلاثين مع بداية ونهاية كل جزء |
| 🎨 المظهر | ثلاث سمات (فاتح، ورقي، داكن)، وتكبير الخط من ٨٠٪ إلى ٢٠٠٪ |
| 📱 الاستجابة | تصميم يعمل على الجوال والحاسب |
| 📲 قابل للتثبيت | تطبيق ويب تقدّمي (PWA): يُثبَّت على الشاشة الرئيسية ويعمل دون اتصال |

كل الإعدادات والعلامات المرجعية تُحفظ في متصفحك (`localStorage`) ولا تُرسل لأي جهة.

## البحث

صندوق البحث يفهم عدة صيغ:

| ما تكتبه | النتيجة |
|---|---|
| `الحمد لله رب العالمين` | كل الآيات التي يرد فيها النص (بلا حاجة للتشكيل) |
| `٢:٢٥٥` أو `2:255` | ينتقل مباشرة إلى آية الكرسي |
| `الكهف 10` | ينتقل إلى سورة الكهف، الآية ١٠ |
| `البق` | يقترح سورة البقرة |

يتعامل البحث مع فروق الرسم العثماني تلقائياً: يتجاهل التشكيل والتطويل، ويوحّد
الهمزات (أ إ آ ٱ) والألف المقصورة والتاء المربوطة، ويطابق الألف الخنجرية سواء كتبتها
ألفاً (`العالمين`) أو حذفتها (`الرحمن`).

## اختصارات لوحة المفاتيح

| المفتاح | الوظيفة |
|---|---|
| `/` | الانتقال إلى صندوق البحث |
| `←` | السورة التالية |
| `→` | السورة السابقة |
| `Esc` | إغلاق لوحة الإعدادات أو شريط الآية |

## البنية

```
quran/
├── index.html                هيكل الصفحة
├── manifest.webmanifest      تعريف التطبيق للتثبيت على الجوال
├── sw.js                     عامل الخدمة: التخزين للعمل بدون إنترنت
├── css/styles.css            التنسيقات والسمات الثلاث
├── js/store.js               حفظ الإعدادات والمفضلة وموضع القراءة
├── js/search.js              تطبيع النص العربي، فهرس البحث، تحليل المراجع
├── js/app.js                 التوجيه وبناء الشاشات والأحداث
├── data/quran-data.js        نص المصحف كاملاً (١٫٣ م.ب، مولَّد آلياً)
├── fonts/amiri-*.woff2       خط أميري (نسخة عربية مختصرة)
├── icons/                    أيقونات التطبيق
├── dist/quran-app.html       نسخة الملف الواحد (مولَّدة آلياً)
├── tools/build-single.js     بناء نسخة الملف الواحد
└── tests/run.js              فحوص تعمل بـ Node بلا حزم خارجية
```

> عند تعديل أي ملف من ملفات التطبيق، غيّر رقم `VERSION` في `sw.js` حتى تصل التحديثات
> لمن ثبّت التطبيق على جواله، وأعد بناء نسخة الملف الواحد.

## الفحوص

```bash
node quran/tests/run.js
```

تغطي الفحوص سلامة البيانات (عدد السور والآيات، البسملة، جدول الأجزاء)، وقواعد تطبيع
النص العربي، ونتائج البحث ومواضع التمييز، وتحليل المراجع.
