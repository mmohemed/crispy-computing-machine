النماذج Forms في Django

تعلم كيفية إنشاء نماذج تفاعلية مع التحقق من صحة البيانات باستخدام Django Forms.

مدة القراءة: 11 دقيقة مستوى: متوسط Forms Validation

ما هي النماذج في Django؟

النماذج (Forms) في Django هي وسيلة لإنشاء نماذج HTML والتعامل مع البيانات المدخلة من المستخدمين. توفر النماذج:

  • إنشاء حقول النموذج: تعريف الحقول مثل النصوص، الأرقام، التواريخ، إلخ.
  • التحقق من صحة البيانات (Validation): التأكد من أن البيانات المدخلة صحيحة.
  • عرض الأخطاء: عرض رسائل خطأ مفيدة للمستخدم.
  • إعادة تعبئة النموذج: إعادة عرض البيانات المدخلة مع الأخطاء.
المفهوم الأساسي: النماذج في Django تعمل كجسر بين المستخدم وقاعدة البيانات، وتوفر طبقة أمان إضافية ضد البيانات الخبيثة.

إنشاء نموذج

هناك طريقتان رئيسيتان لإنشاء النماذج في Django:

1. نموذج عادي (Form)

forms.py
from django import forms

class ContactForm(forms.Form):
    name = forms.CharField(max_length=100, label='الاسم')
    email = forms.EmailField(label='البريد الإلكتروني')
    subject = forms.CharField(max_length=200, label='الموضوع')
    message = forms.CharField(widget=forms.Textarea, label='الرسالة')
    priority = forms.ChoiceField(
        choices=[('low', 'منخفض'), ('medium', 'متوسط'), ('high', 'عالي')],
        label='الأولوية'
    )

2. نموذج مرتبط بالنموذج (ModelForm)

forms.py
from django import forms
from .models import Post

class PostForm(forms.ModelForm):
    class Meta:
        model = Post
        fields = ['title', 'content', 'published']
        labels = {
            'title': 'العنوان',
            'content': 'المحتوى',
            'published': 'منشور'
        }
        widgets = {
            'content': forms.Textarea(attrs={'rows': 5}),
        }
نصيحة: استخدم ModelForm عندما يكون النموذج مرتبطاً بنموذج قاعدة بيانات لتوفير الوقت والجهد.

أنواع الحقول في النماذج

يوفر Django مجموعة واسعة من الحقول للاستخدام في النماذج:

الحقل الوصف المعلمات الشائعة
CharField نص قصير max_length, min_length
EmailField بريد إلكتروني يتم التحقق من صحة البريد تلقائياً
IntegerField رقم صحيح min_value, max_value
FloatField رقم عشري min_value, max_value
BooleanField صحيح/خاطئ required, initial
DateField تاريخ input_formats
ChoiceField اختيار من قائمة choices
FileField رفع ملف allow_empty_file
URLField رابط يتم التحقق من صحة الرابط تلقائياً

التحقق من صحة البيانات (Validation)

يوفر Django عدة طرق للتحقق من صحة البيانات المدخلة:

1. التحقق التلقائي

يتم التحقق تلقائياً بناءً على نوع الحقل (مثل EmailField يتحقق من صحة البريد).

2. دوال التحقق المخصصة

forms.py
from django import forms
from django.core.exceptions import ValidationError

class ContactForm(forms.Form):
    name = forms.CharField(max_length=100)
    email = forms.EmailField()
    age = forms.IntegerField(min_value=18, max_value=120)
    
    # التحقق من حقل واحد
    def clean_name(self):
        name = self.cleaned_data.get('name')
        if len(name) < 3:
            raise ValidationError('الاسم يجب أن يكون 3 أحرف على الأقل')
        return name
    
    # التحقق من عدة حقول معاً
    def clean(self):
        cleaned_data = super().clean()
        email = cleaned_data.get('email')
        age = cleaned_data.get('age')
        
        if age and age < 18:
            raise ValidationError('يجب أن يكون العمر 18 سنة أو أكثر')
        
        return cleaned_data

3. معلمات الحقول

forms.py
class ProductForm(forms.Form):
    name = forms.CharField(
        max_length=100,
        min_length=3,
        required=True,
        error_messages={
            'required': 'الاسم مطلوب',
            'max_length': 'الاسم طويل جداً',
            'min_length': 'الاسم قصير جداً'
        }
    )
    price = forms.DecimalField(
        max_digits=10,
        decimal_places=2,
        min_value=0
    )
تنبيه: لا تثق أبداً بالبيانات المرسلة من العميل. قم دائماً بالتحقق من صحة البيانات على الخادم.

عرض النموذج في القالب

هناك عدة طرق لعرض النموذج في قالب Django:

1. عرض كامل

template.html
<form method="post" action="{% url 'submit' %}">
    {% csrf_token %}
    {{ form.as_p }}
    <button type="submit">إرسال</button>
</form>

2. عرض حقول محددة

template.html
<form method="post">
    {% csrf_token %}
    <div class="form-group">
        <label for="{{ form.name.id_for_label }}">{{ form.name.label }}</label>
        {{ form.name }}
        {% if form.name.errors %}
            <div class="error">{{ form.name.errors }}</div>
        {% endif %}
    </div>
    <!-- حقول أخرى -->
    <button type="submit">إرسال</button>
</form>
ملاحظة: استخدم {% csrf_token %} دائماً في النماذج التي تستخدم POST للحماية من هجمات CSRF.
