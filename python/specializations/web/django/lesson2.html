إعداد بيئة Django

تعلم كيفية تثبيت Django، إنشاء مشروع جديد، واستكشاف هيكل المجلدات لتطوير تطبيقات ويب احترافية.

مدة القراءة: 10 دقائق مستوى: مبتدئ سطر الأوامر بايثون 3.8+

المتطلبات الأساسية

قبل أن تبدأ في تثبيت Django، تأكد من توفر المتطلبات التالية:

  • Python 3.8 أو أحدث: Django يعمل على إصدارات Python 3.8 وما فوق.
  • مدير الحزم pip: يأتي مع Python بشكل افتراضي.
  • محطة طرفية (Terminal): ستحتاج إلى استخدام سطر الأوامر.
  • محول نصي (Code Editor): مثل VS Code، PyCharm، أو Sublime Text.
ملاحظة: يمكنك التحقق من إصدار Python لديك عن طريق كتابة python --version في الطرفية.

تثبيت Django

هناك طريقتان رئيسيتان لتثبيت Django:

الطريقة الأولى: التثبيت العالمي

Terminal
pip install django

هذه الطريقة تقوم بتثبيت Django على مستوى النظام بأكمله.

الطريقة الثانية: البيئة الافتراضية (موصى بها)

استخدام البيئات الافتراضية يعزل مشاريعك ويمنع التعارض بين الإصدارات:

Terminal
# إنشاء بيئة افتراضية
python -m venv myenv

# تفعيل البيئة (Windows)
myenv\Scripts\activate

# تفعيل البيئة (Mac/Linux)
source myenv/bin/activate

# تثبيت Django داخل البيئة
pip install django
نصيحة: استخدم البيئات الافتراضية دائماً لتجنب مشاكل توافق الإصدارات بين المشاريع المختلفة.

التحقق من التثبيت

بعد التثبيت، يمكنك التحقق من أن Django قد تم تثبيته بشكل صحيح عن طريق كتابة:

Terminal
django-admin --version

سيظهر لك رقم الإصدار المثبت (مثلاً: 4.2.7).

تنبيه: إذا ظهر خطأ "command not found"، فهذا يعني أن مسار التثبيت غير مضاف إلى متغيرات البيئة (PATH).

إنشاء مشروع جديد

لإنشاء مشروع Django جديد، استخدم الأمر التالي:

Terminal
django-admin startproject myproject

سيقوم هذا الأمر بإنشاء مجلد جديد باسم myproject يحتوي على هيكل المشروع الأساسي.

هيكل المشروع

هيكل المجلدات
myproject/
├── manage.py          # أداة إدارة المشروع
├── myproject/         # حزمة المشروع الرئيسية
│   ├── __init__.py    # ملف تهيئة
│   ├── settings.py    # إعدادات المشروع
│   ├── urls.py        # تعريف المسارات
│   └── asgi.py        # تكوين ASGI
│   └── wsgi.py        # تكوين WSGI
  • manage.py: أداة سطر الأوامر الرئيسية لإدارة المشروع.
  • settings.py: يحتوي على جميع إعدادات المشروع (قاعدة البيانات، التطبيقات، إلخ).
  • urls.py: ملف توجيه الروابط (URL routing).
  • wsgi.py: ملف لتشغيل التطبيق على خوادم الإنتاج.

تشغيل خادم التطوير

يمكنك تشغيل خادم التطوير المدمج في Django باستخدام الأمر التالي:

Terminal
# الانتقال إلى مجلد المشروع
cd myproject

# تشغيل الخادم
python manage.py runserver

بعد تشغيل الخادم، ستظهر رسالة مشابهة لهذه:

Output
Starting development server at http://127.0.0.1:8000/
Quit the server with CTRL-BREAK.
تهانينا! يمكنك الآن فتح المتصفح والذهاب إلى http://127.0.0.1:8000 لرؤية صفحة الترحيب الخاصة بـ Django!
نصيحة: يمكنك تغيير المنفذ عن طريق إضافة رقم المنفذ في نهاية الأمر: python manage.py runserver 8080

إنشاء تطبيق داخل المشروع

في Django، يُقسم المشروع إلى تطبيقات (Apps) متعددة. لإنشاء تطبيق جديد:

Terminal
python manage.py startapp myapp

هذا الأمر ينشئ مجلد جديد myapp بهيكل التطبيق:

هيكل التطبيق
myapp/
├── __init__.py
├── admin.py          # تكوين لوحة الإدارة
├── apps.py           # إعدادات التطبيق
├── models.py         # نماذج قاعدة البيانات
├── tests.py          # اختبارات التطبيق
├── views.py          # دوال العرض
└── migrations/       # مجلد الترحيلات
    └── __init__.py
تنبيه: لا تنسَ إضافة التطبيق الجديد إلى قائمة INSTALLED_APPS في ملف settings.py!

الأوامر الأساسية في Django

إليك جدول يحتوي على أهم الأوامر التي ستستخدمها بشكل متكرر:

الأمر الوصف
django-admin startproject name إنشاء مشروع جديد
python manage.py runserver تشغيل خادم التطوير
python manage.py startapp name إنشاء تطبيق جديد
python manage.py makemigrations إنشاء ملفات ترحيل لقاعدة البيانات
python manage.py migrate تطبيق الترحيلات على قاعدة البيانات
python manage.py createsuperuser إنشاء مستخدم مدير (Admin)
python manage.py shell فتح الواجهة التفاعلية لـ Django

خلاصة الدرس

  • ✅ تأكد من تثبيت Python 3.8+ و pip.
  • ✅ استخدم البيئات الافتراضية لعزل مشاريعك.
  • ✅ قم بتثبيت Django باستخدام pip install django.
  • ✅ أنشئ مشروعاً جديداً بـ django-admin startproject.
  • ✅ شغّل خادم التطوير بـ python manage.py runserver.
  • ✅ أنشئ تطبيقات جديدة باستخدام python manage.py startapp.
