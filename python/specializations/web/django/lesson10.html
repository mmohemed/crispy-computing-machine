نشر تطبيقات Django

تعلم كيفية نشر تطبيقات Django على منصات السحابة وإعداد البيئة الإنتاجية بشكل احترافي.

مدة القراءة: 12 دقيقة مستوى: متقدم Deployment Production

لماذا نشر تطبيقات Django؟

النشر (Deployment) هو عملية نقل تطبيقك من بيئة التطوير إلى بيئة الإنتاج حيث يمكن للمستخدمين الوصول إليه. تعتبر خطوة النشر من أهم الخطوات في دورة حياة التطبيق.

تتضمن عملية النشر:

  • إعداد البيئة الإنتاجية: تهيئة الخادم وقاعدة البيانات.
  • تثبيت المتطلبات: تثبيت جميع الحزم المطلوبة.
  • إعداد قاعدة البيانات: إنشاء قاعدة البيانات وتطبيق الترحيلات.
  • تكوين الملفات الثابتة: إعداد خدمة الملفات الثابتة والوسائط.
  • إعداد خادم الويب: تكوين Gunicorn أو uWSGI مع Nginx.
  • إعداد المجال: ربط التطبيق باسم المجال.
ملاحظة: بيئة الإنتاج تختلف كثيراً عن بيئة التطوير. تأكد من إعداد كل شيء بشكل صحيح قبل النشر.

متطلبات النشر

قبل نشر تطبيق Django، تأكد من تجهيز المتطلبات التالية:

1. ملف requirements.txt

requirements.txt
# إنشاء ملف المتطلبات
pip freeze > requirements.txt

# مثال على محتوى الملف
Django==4.2.7
djangorestframework==3.14.0
gunicorn==21.2.0
psycopg2-binary==2.9.9
whitenoise==6.5.0

2. إعداد متغيرات البيئة

.env (استخدم python-decouple أو django-environ)
SECRET_KEY=your-secret-key
DEBUG=False
DATABASE_URL=postgresql://user:pass@localhost/dbname
ALLOWED_HOSTS=yourdomain.com,www.yourdomain.com

3. تكوين settings.py للإنتاج

settings.py
import os
from decouple import config

# إعدادات الأمان
SECRET_KEY = config('SECRET_KEY')
DEBUG = config('DEBUG', default=False, cast=bool)
ALLOWED_HOSTS = config('ALLOWED_HOSTS').split(',')

# قاعدة البيانات
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.postgresql',
        'NAME': config('DB_NAME'),
        'USER': config('DB_USER'),
        'PASSWORD': config('DB_PASSWORD'),
        'HOST': config('DB_HOST'),
        'PORT': config('DB_PORT', default='5432'),
    }
}

# الملفات الثابتة
STATIC_ROOT = os.path.join(BASE_DIR, 'staticfiles')
STATICFILES_STORAGE = 'whitenoise.storage.CompressedManifestStaticFilesStorage'

# الوسائط
MEDIA_ROOT = os.path.join(BASE_DIR, 'media')
MEDIA_URL = '/media/'
تنبيه: لا تضع أبداً SECRET_KEY أو كلمات المرور في ملفات الكود. استخدم دائماً متغيرات البيئة.

منصات النشر الشائعة

إليك أشهر المنصات المستخدمة لنشر تطبيقات Django:

Heroku

منصة سحابية سهلة الاستخدام مع دعم ممتاز لـ Django

PythonAnywhere

منصة متخصصة لتطبيقات بايثون مع واجهة سهلة

AWS (EC2)

خدمات أمازون السحابية مع مرونة عالية

DigitalOcean

خوادم سحابية بأسعار معقولة مع دعم Django

مقارنة بين المنصات

المنصة المميزات السعر الصعوبة
Heroku سهل الاستخدام، تكامل مع Git، إضافات متعددة مجاني (محدود) / يبدأ من $5/شهر سهل
PythonAnywhere متخصص لبايثون، واجهة ويب، دعم ممتاز مجاني (محدود) / يبدأ من $5/شهر سهل
AWS EC2 مرونة عالية، تحكم كامل، خدمات متعددة حسب الاستخدام / يبدأ من $8/شهر متوسط-صعب
DigitalOcean بسيط، أسعار مناسبة، دروس تعليمية يبدأ من $4/شهر متوسط

خطوات النشر العامة

إليك الخطوات الأساسية لنشر تطبيق Django:

1. إعداد الخادم

Terminal
# تحديث النظام
sudo apt update && sudo apt upgrade

# تثبيت Python و pip
sudo apt install python3-pip python3-venv

# تثبيت PostgreSQL (اختياري)
sudo apt install postgresql postgresql-contrib

2. إعداد التطبيق

Terminal
# نسخ المشروع إلى الخادم
git clone https://github.com/yourusername/yourproject.git

# إنشاء بيئة افتراضية
python3 -m venv venv
source venv/bin/activate

# تثبيت المتطلبات
pip install -r requirements.txt

# تطبيق الترحيلات
python manage.py migrate

# تجميع الملفات الثابتة
python manage.py collectstatic

3. إعداد خادم الويب (Gunicorn + Nginx)

Terminal
# تثبيت Gunicorn
pip install gunicorn

# اختبار Gunicorn
gunicorn --workers 3 myproject.wsgi:application

# تثبيت Nginx
sudo apt install nginx

# تكوين Nginx
# إنشاء ملف /etc/nginx/sites-available/myproject
نصيحة: استخدم Gunicorn كخادم تطبيقات و Nginx كخادم ويب أمامي لتوزيع الطلبات وإدارة الملفات الثابتة.
