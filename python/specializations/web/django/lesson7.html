واجهة الإدارة Admin

تعلم如何使用 نظام الإدارة المدمج في Django لإدارة المحتوى بسهولة وكفاءة.

مدة القراءة: 10 دقائق مستوى: متوسط Django Admin إدارة المحتوى

ما هي واجهة الإدارة في Django؟

واجهة الإدارة (Admin Interface) هي واحدة من أقوى ميزات Django. توفر واجهة آمنة وسهلة الاستخدام لإدارة محتوى التطبيق دون الحاجة إلى كتابة كود إضافي.

تتيح لك واجهة الإدارة:

  • إدارة النماذج: إضافة، تعديل، وحذف الكائنات في قاعدة البيانات.
  • التحكم في المستخدمين: إدارة المستخدمين والمجموعات والصلاحيات.
  • تخصيص الواجهة: تخصيص شكل ووظائف لوحة الإدارة حسب احتياجاتك.
  • الوصول السريع: الوصول إلى البيانات بسرعة وسهولة.
المفهوم الأساسي: واجهة الإدارة هي أداة إنتاجية تساعدك على إدارة التطبيق بكفاءة، وتوفر طبقة إضافية من الأمان والتحكم.

إعداد واجهة الإدارة

لإعداد واجهة الإدارة في Django، تحتاج إلى:

1. إنشاء مستخدم مدير (Superuser)

Terminal
python manage.py createsuperuser

# سيُطلب منك إدخال:
# - اسم المستخدم
# - البريد الإلكتروني
# - كلمة المرور

2. تسجيل النماذج في admin.py

admin.py
from django.contrib import admin
from .models import Post, Category, Comment

# تسجيل نموذج بسيط
admin.site.register(Post)

# تسجيل نماذج متعددة
admin.site.register([Category, Comment])

3. الوصول إلى واجهة الإدارة

URL
http://127.0.0.1:8000/admin/
نصيحة: استخدم createsuperuser لإنشاء أول مستخدم مدير للوصول إلى لوحة التحكم.

تخصيص واجهة الإدارة

يمكنك تخصيص واجهة الإدارة لجعلها أكثر فعالية وسهولة في الاستخدام:

1. تخصيص عرض النموذج

admin.py
from django.contrib import admin
from .models import Post

class PostAdmin(admin.ModelAdmin):
    # الحقول المعروضة في قائمة النماذج
    list_display = ('title', 'author', 'created_at', 'published')
    
    # الفلاتر الجانبية
    list_filter = ('published', 'author', 'created_at')
    
    # حقل البحث
    search_fields = ('title', 'content')
    
    # ترتيب النتائج
    ordering = ('-created_at',)
    
    # حقول قابلة للتعديل مباشرة من القائمة
    list_editable = ('published',)
    
    # تجميع الحقول في أقسام
    fieldsets = (
        ('معلومات أساسية', {
            'fields': ('title', 'content')
        }),
        ('خيارات النشر', {
            'fields': ('published', 'author')
        }),
        ('التواريخ', {
            'fields': ('created_at', 'updated_at'),
            'classes': ('collapse',)
        }),
    )

admin.site.register(Post, PostAdmin)

2. إضافة إجراءات مخصصة

admin.py
class PostAdmin(admin.ModelAdmin):
    actions = ['make_published', 'make_draft']
    
    def make_published(self, request, queryset):
        queryset.update(published=True)
        self.message_user(request, 'تم نشر المنشورات المحددة.')
    make_published.short_description = 'نشر المنشورات المحددة'
    
    def make_draft(self, request, queryset):
        queryset.update(published=False)
        self.message_user(request, 'تم تحويل المنشورات إلى مسودات.')
    make_draft.short_description = 'تحويل إلى مسودات'
ملاحظة: تخصيص واجهة الإدارة يجعلها أكثر كفاءة و سهولة في الاستخدام، خاصة للمستخدمين غير التقنيين.

خيارات التخصيص المتقدمة

إليك جدول يحتوي على أهم خيارات تخصيص واجهة الإدارة:

الخاصية الوصف مثال
list_display الحقول المعروضة في قائمة النماذج ('title', 'author', 'date')
list_filter فلاتر جانبية لتضييق النتائج ('status', 'category')
search_fields الحقول التي يمكن البحث فيها ('title', 'content')
ordering ترتيب النتائج الافتراضي ('-created_at',)
list_editable حقول قابلة للتعديل مباشرة ('status', 'published')
fieldsets تجميع الحقول في أقسام ('معلومات', {'fields': ('title',)})
actions إجراءات مخصصة على النماذج ['make_published']
readonly_fields حقول للقراءة فقط ('created_at', 'updated_at')
