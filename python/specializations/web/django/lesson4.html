واجهة المستخدم Templates

تعلم كيفية استخدام نظام القوالب في Django لعرض البيانات بشكل احترافي وإنشاء واجهات مستخدم ديناميكية.

مدة القراءة: 11 دقيقة مستوى: مبتدئ HTML + CSS Django Templates

ما هي القوالب (Templates)؟

القوالب (Templates) هي ملفات HTML تحتوي على كود Django الخاص لعرض البيانات الديناميكية. تسمح لك القوالب بفصل منطق التطبيق عن واجهة المستخدم، مما يجعل الكود أكثر نظافة وسهولة في الصيانة.

يستخدم Django نظام القوالب الخاص به (Django Template Language - DTL) والذي يوفر:

  • المتغيرات: لعرض البيانات من الـ View.
  • الوسوم (Tags): للتحكم في المنطق مثل الحلقات والشروط.
  • الفلاتر (Filters): لتنسيق البيانات قبل عرضها.
  • الوراثة (Inheritance): لإعادة استخدام القوالب.
المفهوم الأساسي: القوالب هي الجسر بين البيانات (من الـ View) والمستخدم (من خلال المتصفح).

إعداد القوالب

لإعداد القوالب في Django، تحتاج إلى:

1. إنشاء مجلد templates

هيكل المشروع
myproject/
├── manage.py
├── myproject/
│   ├── settings.py
│   └── ...
└── templates/          # مجلد القوالب الرئيسي
    └── base.html       # القالب الأساسي

2. إعداد مسار القوالب في settings.py

settings.py
import os

TEMPLATES = [
    {
        'BACKEND': 'django.template.backends.django.DjangoTemplates',
        'DIRS': [os.path.join(BASE_DIR, 'templates')],  # مسار القوالب
        'APP_DIRS': True,
        'OPTIONS': {
            'context_processors': [
                'django.template.context_processors.debug',
                'django.template.context_processors.request',
                'django.contrib.auth.context_processors.auth',
                'django.contrib.messages.context_processors.messages',
            ],
        },
    },
]
نصيحة: يمكنك أيضاً إنشاء مجلد templates داخل كل تطبيق لتخزين قوالب خاصة بالتطبيق.

لغة قوالب Django

تتكون لغة قوالب Django من ثلاثة عناصر رئيسية:

1. المتغيرات (Variables)

HTML Template
<h1>{{ post.title }}</h1>
<p>{{ post.content }}</p>
<span>تاريخ النشر: {{ post.created_at|date:"Y-m-d" }}</span>

تعرض المتغيرات بين {{ }}.

2. الوسوم (Tags)

HTML Template
<!-- حلقة for -->
{% for post in posts %}
    <div class="post">
        <h2>{{ post.title }}</h2>
        <p>{{ post.content }}</p>
    </div>
{% empty %}
    <p>لا توجد منشورات!</p>
{% endfor %}

<!-- شرط if -->
{% if user.is_authenticated %}
    <p>مرحباً {{ user.username }}!</p>
{% else %}
    <p>الرجاء تسجيل الدخول</p>
{% endif %}

الوسوم تستخدم بين {% %}.

3. الفلاتر (Filters)

HTML Template
<p>{{ post.content|truncatewords:30 }}</p>
<p>{{ post.created_at|date:"Y-m-d H:i" }}</p>
<p>{{ post.title|upper }}</p>
<p>{{ post.content|linebreaks }}</p>
<p>{{ post.content|safe }}</p>

الفلاتر تستخدم بعد |.

جدول الفلاتر الشائعة

الفلاتر الوصف مثال
date تنسيق التاريخ {{ date|date:"Y-m-d" }}
truncatewords اختصار النص لعدد محدد من الكلمات {{ text|truncatewords:30 }}
upper تحويل النص إلى حروف كبيرة {{ text|upper }}
lower تحويل النص إلى حروف صغيرة {{ text|lower }}
linebreaks تحويل الأسطر الجديدة إلى <br> {{ text|linebreaks }}
safe عرض HTML دون ترميز {{ html|safe }}
default قيمة افتراضية إذا كان المتغير فارغاً {{ value|default:"لا يوجد" }}

وراثة القوالب (Template Inheritance)

تسمح وراثة القوالب بإنشاء قالب أساسي (Base Template) يحتوي على الهيكل العام للموقع، ثم توريثه في قوالب أخرى لإضافة محتوى خاص.

القالب الأساسي (base.html)

templates/base.html
<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
    <meta charset="UTF-8">
    <title>{% block title %}موقعي{% endblock %}</title>
    <link rel="stylesheet" href="{% static 'css/style.css' %}">
</head>
<body>
    <header>
        <h1>مدونتي</h1>
        <nav>
            <a href="/">الرئيسية</a>
            <a href="/about/">عن الموقع</a>
        </nav>
    </header>

    <main>
        {% block content %}
        <!-- المحتوى الرئيسي -->
        {% endblock %}
    </main>

    <footer>
        <p>© 2026 مدونتي</p>
    </footer>
</body>
</html>

وراثة القالب

templates/blog/post_list.html
{% extends 'base.html' %}

{% block title %}قائمة المنشورات - مدونتي{% endblock %}

{% block content %}
    <h2>جميع المنشورات</h2>
    {% for post in posts %}
        <div class="post">
            <h3><a href="{% url 'post_detail' post.id %}">{{ post.title }}</a></h3>
            <p>{{ post.content|truncatewords:30 }}</p>
            <small>{{ post.created_at|date:"Y-m-d" }}</small>
        </div>
    {% empty %}
        <p>لا توجد منشورات بعد.</p>
    {% endfor %}
{% endblock %}
نصيحة: استخدم الوراثة لتجنب تكرار الكود وجعل الصيانة أسهل.

الملفات الثابتة (Static Files)

الملفات الثابتة هي ملفات CSS، JavaScript، والصور التي لا تتغير ديناميكياً. في Django، تتم إدارة هذه الملفات من خلال مجلد static.

هيكل الملفات الثابتة

هيكل المشروع
myproject/
├── manage.py
├── myproject/
│   └── settings.py
├── templates/
└── static/              # مجلد الملفات الثابتة
    ├── css/
    │   └── style.css
    ├── js/
    │   └── main.js
    └── images/
        └── logo.png

استخدام الملفات الثابتة في القالب

HTML Template
{% load static %}

<link rel="stylesheet" href="{% static 'css/style.css' %}">
<script src="{% static 'js/main.js' %}"></script>
<img src="{% static 'images/logo.png' %}" alt="شعار الموقع">
ملاحظة: لا تنسَ إضافة {% load static %} في بداية القالب لاستخدام الملفات الثابتة.

محاكي القوالب التفاعلي

جرب استخدام لغة قوالب Django في هذا المحاكي التفاعلي:

Django Template
<!-- سيتم عرض الكود هنا -->
بيانات السياق (Context)
{
    'posts': [
        {'title': 'أول منشور', 'content': 'محتوى المنشور الأول...'},
        {'title': 'منشور ثاني', 'content': 'محتوى المنشور الثاني...'}
    ]
}

خلاصة الدرس

  • ✅ القوالب هي ملفات HTML تحتوي على كود Django الخاص.
  • ✅ تستخدم المتغيرات ({{ }}) لعرض البيانات.
  • ✅ تستخدم الوسوم ({% %}) للتحكم في المنطق.
  • ✅ تستخدم الفلاتر (|) لتنسيق البيانات.
  • ✅ توفر وراثة القوالب لإعادة استخدام الكود.
  • ✅ استخدم الملفات الثابتة لإدارة CSS و JavaScript والصور.
