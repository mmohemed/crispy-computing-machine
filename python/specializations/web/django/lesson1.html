ما هو Django؟

Django هو إطار عمل عالي المستوى لتطوير تطبيقات الويب باستخدام لغة بايثون. صُمم Django لتسريع عملية التطوير وتشجيع الممارسات النظيفة والآمنة.

تم إنشاء Django في عام 2005 من قبل فريق من المطورين في صحيفة Lawrence Journal-World، وتم إطلاقه كمشروع مفتوح المصدر. منذ ذلك الحين، أصبح واحداً من أكثر أطر العمل استخداماً في العالم.

حقيقة ممتعة: تم تسمية Django على اسم عازف الجيتار الشهير Django Reinhardt، وليس له علاقة مباشرة بتقنية الويب!

بنية MVT

يستخدم Django نمطاً معمارياً خاصاً يسمى MVT، وهو مشتق من نمط MVC الكلاسيكي:

  • Model (النموذج): يمثل البيانات وقاعدة البيانات. يتم تعريف النماذج باستخدام كود بايثون.
  • View (العرض): يحتوي على منطق التطبيق. يتلقى الطلبات ويعيد الاستجابات.
  • Template (القالب): مسؤول عن عرض البيانات للمستخدم (واجهة المستخدم).
ملاحظة: في Django، يُطلق على الـ Controller اسم View، ويُستخدم الـ Template بدلاً من الـ View التقليدي.
مثال توضيحي

# نموذج (Model)
class BlogPost(models.Model):
    title = models.CharField(max_length=200)
    content = models.TextField()
    published_date = models.DateTimeField(auto_now_add=True)

# عرض (View)
def post_list(request):
    posts = BlogPost.objects.all()
    return render(request, 'blog/post_list.html', {'posts': posts})

# قالب (Template) - ملف HTML
# <h1>قائمة المنشورات</h1>
# {% for post in posts %}
#     <h2>{{ post.title }}</h2>
#     <p>{{ post.content }}</p>
# {% endfor %}

لماذا تتعلم Django؟

  • طلب كبير في سوق العمل: الشركات الكبرى مثل Instagram، YouTube، وSpotify تستخدم Django.
  • مجتمع ضخم: يوجد ملايين المطورين حول العالم يساعدون بعضهم البعض.
  • توثيق ممتاز: يوفر Django وثائق شاملة وسهلة الفهم.
  • قابلية التوسع: يمكن لـ Django التعامل مع التطبيقات الصغيرة والكبيرة على حد سواء.
نصيحة: إذا كنت تريد بناء تطبيق ويب كامل بسرعة وأمان، فإن Django هو خيارك الأمثل.

من يستخدم Django؟

تستخدم Django العديد من الشركات والمؤسسات العالمية الشهيرة، بما في ذلك:

  • Instagram - تطبيق مشاركة الصور الشهير.
  • YouTube - منصة الفيديو الأكبر في العالم.
  • Spotify - خدمة البث الموسيقي.
  • Dropbox - خدمة التخزين السحابي.
  • NASA - وكالة الفضاء الأمريكية تستخدم Django لبعض تطبيقاتها.
