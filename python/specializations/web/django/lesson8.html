بناء REST APIs

تعلم كيفية إنشاء واجهات برمجة تطبيقات احترافية باستخدام Django REST Framework.

مدة القراءة: 13 دقيقة مستوى: متقدم REST API DRF

ما هو Django REST Framework؟

Django REST Framework (DRF) هو إطار عمل قوي ومرن لبناء واجهات برمجة التطبيقات (APIs) باستخدام Django. يوفر DRF مجموعة من الأدوات والميزات التي تجعل عملية بناء APIs سهلة وسريعة.

الميزات الرئيسية لـ DRF:

  • المُسلسِلات (Serializers): تحويل النماذج إلى JSON والعكس.
  • ViewSets: مجموعة من الدوال الجاهزة للعمليات CRUD.
  • المصادقة (Authentication): دعم لأنواع متعددة من المصادقة.
  • الصلاحيات (Permissions): التحكم في الوصول إلى الـ API.
  • التوثيق التلقائي: إنشاء وثائق API تلقائياً.
  • واجهة تفاعلية: واجهة Browsable API لتجربة الـ API.
ملاحظة: DRF هو الإطار الأكثر شعبية لبناء APIs في Django، ويستخدم في تطبيقات ضخمة مثل Instagram و YouTube.

تثبيت وتكوين DRF

1. تثبيت DRF

Terminal
pip install djangorestframework

2. إضافة DRF إلى INSTALLED_APPS

settings.py
INSTALLED_APPS = [
    'django.contrib.admin',
    'django.contrib.auth',
    # ... التطبيقات الأخرى
    'rest_framework',
]

3. تكوين DRF (اختياري)

settings.py
REST_FRAMEWORK = {
    'DEFAULT_AUTHENTICATION_CLASSES': [
        'rest_framework.authentication.SessionAuthentication',
        'rest_framework.authentication.TokenAuthentication',
    ],
    'DEFAULT_PERMISSION_CLASSES': [
        'rest_framework.permissions.IsAuthenticatedOrReadOnly',
    ],
    'DEFAULT_PAGINATION_CLASS': 'rest_framework.pagination.PageNumberPagination',
    'PAGE_SIZE': 10,
}
نصيحة: استخدم TokenAuthentication لتأمين APIs الخاصة بك.

المُسلسِلات (Serializers)

المُسلسِلات هي قلب DRF. تقوم بتحويل النماذج المعقدة (مثل queryset) إلى JSON يمكن إرساله عبر الـ API، والعكس.

إنشاء مُسلسِل

serializers.py
from rest_framework import serializers
from .models import Post

class PostSerializer(serializers.ModelSerializer):
    class Meta:
        model = Post
        fields = ['id', 'title', 'content', 'author', 'created_at', 'published']
        read_only_fields = ['id', 'author', 'created_at']

مُسلسِل مخصص

serializers.py
class PostSerializer(serializers.Serializer):
    id = serializers.IntegerField(read_only=True)
    title = serializers.CharField(max_length=200)
    content = serializers.CharField()
    author = serializers.CharField()
    created_at = serializers.DateTimeField(read_only=True)
    
    def create(self, validated_data):
        return Post.objects.create(**validated_data)
    
    def update(self, instance, validated_data):
        instance.title = validated_data.get('title', instance.title)
        instance.content = validated_data.get('content', instance.content)
        instance.save()
        return instance
ملاحظة: ModelSerializer هو الأسهل والأكثر استخداماً لأنه يقوم تلقائياً بإنشاء الحقول بناءً على النموذج.

الـ Views في DRF

يوفر DRF عدة طرق لإنشاء الـ Views:

1. ViewSets (الطريقة الموصى بها)

views.py
from rest_framework import viewsets
from .models import Post
from .serializers import PostSerializer

class PostViewSet(viewsets.ModelViewSet):
    queryset = Post.objects.all()
    serializer_class = PostSerializer
    permission_classes = [IsAuthenticatedOrReadOnly]
    
    def perform_create(self, serializer):
        serializer.save(author=self.request.user)

2. Generic Views

views.py
from rest_framework import generics
from .models import Post
from .serializers import PostSerializer

class PostListCreateView(generics.ListCreateAPIView):
    queryset = Post.objects.all()
    serializer_class = PostSerializer

class PostRetrieveUpdateDestroyView(generics.RetrieveUpdateDestroyAPIView):
    queryset = Post.objects.all()
    serializer_class = PostSerializer

3. تعريف المسارات (URLs)

urls.py
from django.urls import path, include
from rest_framework.routers import DefaultRouter
from .views import PostViewSet

router = DefaultRouter()
router.register(r'posts', PostViewSet)

urlpatterns = [
    path('api/', include(router.urls)),
]

المصادقة والصلاحيات

يوفر DRF نظاماً متكاملاً للمصادقة والصلاحيات:

أنواع المصادقة

النوع الوصف الاستخدام
SessionAuthentication يستخدم جلسات Django العادية المتصفحات
TokenAuthentication يستخدم رمز مميز (Token) تطبيقات الهاتف، SPA
JWT Authentication JSON Web Token الأنظمة الموزعة
BasicAuthentication اسم المستخدم وكلمة المرور التطبيقات القديمة

الصلاحيات المدمجة

views.py
from rest_framework.permissions import (
    AllowAny,
    IsAuthenticated,
    IsAdminUser,
    IsAuthenticatedOrReadOnly,
    DjangoModelPermissions,
)

class PostViewSet(viewsets.ModelViewSet):
    permission_classes = [IsAuthenticatedOrReadOnly]
تنبيه: تأكد من إعداد المصادقة بشكل صحيح لحماية APIs الخاصة بك من الوصول غير المصرح به.

محاكي REST API التفاعلي

جرب إرسال طلبات API باستخدام هذا المحاكي التفاعلي:

GET /api/posts/
✓ 200 OK Response Time: ~120ms
POST /api/posts/
✓ 201 Created Response Time: ~150ms
PUT /api/posts/{id}/
✓ 200 OK Response Time: ~130ms
DELETE /api/posts/{id}/
✓ 204 No Content Response Time: ~100ms

خلاصة الدرس

  • ✅ Django REST Framework هو الإطار الأفضل لبناء APIs في Django.
  • ✅ المُسلسِلات (Serializers) تحول النماذج إلى JSON والعكس.
  • ✅ استخدم ViewSets و ModelViewSet لتقليل الكود المكرر.
  • ✅ هناك عدة أنواع من المصادقة: Token, Session, JWT.
  • ✅ استخدم الصلاحيات للتحكم في الوصول إلى الـ API.
  • ✅ DRF يوفر واجهة Browsable API لاختبار الـ API بسهولة.
