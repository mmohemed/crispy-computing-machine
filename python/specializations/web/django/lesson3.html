النماذج و ORM

تعلم كيفية إنشاء النماذج (Models) والتفاعل مع قاعدة البيانات باستخدام Django ORM باحترافية.

مدة القراءة: 12 دقيقة مستوى: مبتدئ ORM بايثون + SQL

ما هي النماذج في Django؟

النماذج (Models) هي العمود الفقري لتطبيق Django. تمثل النماذج هيكل البيانات وتحدد كيفية تخزين البيانات في قاعدة البيانات. كل نموذج هو عبارة عن كلاس بايثون يرث من django.db.models.Model.

يقوم Django ORM (Object-Relational Mapping) بتحويل النماذج إلى جداول في قاعدة البيانات، ويوفر واجهة برمجية سهلة للتعامل مع البيانات باستخدام كائنات بايثون بدلاً من كتابة استعلامات SQL يدوياً.

المفهوم الأساسي: النموذج = جدول في قاعدة البيانات، وكل حقل في النموذج = عمود في الجدول.

إنشاء نموذج

لإنشاء نموذج في Django، تحتاج إلى إضافة كلاس جديد في ملف models.py داخل التطبيق:

models.py
from django.db import models

class Post(models.Model):
    title = models.CharField(max_length=200)
    content = models.TextField()
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)
    published = models.BooleanField(default=False)

    def __str__(self):
        return self.title

class Category(models.Model):
    name = models.CharField(max_length=100)
    slug = models.SlugField(unique=True)
    description = models.TextField(blank=True)

    def __str__(self):
        return self.name

أنواع الحقول الشائعة

الحقل الوصف مثال
CharField نص قصير (يحتاج إلى max_length) title = models.CharField(max_length=200)
TextField نص طويل content = models.TextField()
IntegerField رقم صحيح age = models.IntegerField()
BooleanField قيمة صحيحة/خاطئة published = models.BooleanField(default=False)
DateTimeField تاريخ ووقت created_at = models.DateTimeField(auto_now_add=True)
ForeignKey علاقة واحد إلى متعدد category = models.ForeignKey(Category, on_delete=models.CASCADE)
SlugField رابط قصير (URL-friendly) slug = models.SlugField(unique=True)

الترحيلات (Migrations)

بعد إنشاء النماذج، تحتاج إلى إنشاء ملفات الترحيل وتطبيقها على قاعدة البيانات. الترحيلات هي طريقة Django لتتبع التغييرات في هيكل قاعدة البيانات.

خطوات الترحيل

Terminal
# إنشاء ملفات الترحيل
python manage.py makemigrations

# تطبيق الترحيلات على قاعدة البيانات
python manage.py migrate
نصيحة: قم دائماً بتنفيذ makemigrations أولاً لإنشاء ملفات الترحيل، ثم migrate لتطبيقها.
ملاحظة: يمكنك عرض استعلامات SQL التي ستنفذها الترحيلات باستخدام الأمر: python manage.py sqlmigrate app_name migration_number

Django ORM - العمليات الأساسية

يوفر Django ORM واجهة قوية للتعامل مع قاعدة البيانات باستخدام كود بايثون. إليك العمليات الأساسية:

إنشاء (Create)

Python Shell
# الطريقة الأولى
post = Post(title="أول منشور", content="محتوى المنشور...")
post.save()

# الطريقة الثانية (المفضلة)
post = Post.objects.create(
    title="منشور جديد",
    content="محتوى المنشور الجديد",
    published=True
)

قراءة (Read)

Python Shell
# الحصول على جميع الكائنات
all_posts = Post.objects.all()

# الحصول على كائن واحد (يرفع استثناء إذا لم يوجد)
post = Post.objects.get(id=1)

# التصفية
published_posts = Post.objects.filter(published=True)

# استثناء الفلاتر
draft_posts = Post.objects.exclude(published=True)

# الترتيب
recent_posts = Post.objects.order_by('-created_at')[:5]

# البحث (يحتوي على)
search_results = Post.objects.filter(title__contains="Django")

تحديث (Update)

Python Shell
# تحديث كائن واحد
post = Post.objects.get(id=1)
post.title = "عنوان جديد"
post.save()

# تحديث مجموعة (دفعة واحدة)
Post.objects.filter(published=False).update(published=True)

حذف (Delete)

Python Shell
# حذف كائن واحد
post = Post.objects.get(id=1)
post.delete()

# حذف مجموعة
Post.objects.filter(published=False).delete()

العلاقات بين النماذج

يدعم Django ثلاثة أنواع رئيسية من العلاقات بين النماذج:

1. واحد إلى متعدد (ForeignKey)

models.py
class Author(models.Model):
    name = models.CharField(max_length=100)

class Book(models.Model):
    title = models.CharField(max_length=200)
    author = models.ForeignKey(Author, on_delete=models.CASCADE, related_name='books')

الوصول العكسي: author.books.all()

2. واحد إلى واحد (OneToOneField)

models.py
class UserProfile(models.Model):
    user = models.OneToOneField(User, on_delete=models.CASCADE)
    bio = models.TextField()
    website = models.URLField(blank=True)

3. متعدد إلى متعدد (ManyToManyField)

models.py
class Post(models.Model):
    title = models.CharField(max_length=200)
    tags = models.ManyToManyField('Tag', related_name='posts')

class Tag(models.Model):
    name = models.CharField(max_length=50)
ملاحظة: on_delete=models.CASCADE يعني أنه عند حذف الكائن المرتبط، سيتم حذف جميع الكائنات المرتبطة به أيضاً.

أفضل الممارسات

  • استخدم __str__: دائماً قم بتعريف __str__ لتسهيل عرض الكائنات.
  • استخدم related_name: في العلاقات لتسهيل الوصول العكسي.
  • استخدم auto_now_add و auto_now: لتتبع تواريخ الإنشاء والتحديث.
  • استخدم indexes: أضف فهارس إلى الحقول التي تبحث عنها كثيراً.
  • استخدم Meta: لترتيب النتائج بشكل افتراضي.
مثال متقدم
class Post(models.Model):
    title = models.CharField(max_length=200, db_index=True)
    content = models.TextField()
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)
    published = models.BooleanField(default=False)

    class Meta:
        ordering = ['-created_at']  # ترتيب افتراضي
        indexes = [
            models.Index(fields=['title', 'created_at']),
        ]

    def __str__(self):
        return self.title

خلاصة الدرس

  • ✅ النماذج تمثل هيكل البيانات في Django.
  • ✅ كل نموذج هو كلاس بايثون يرث من models.Model.
  • ✅ استخدم makemigrations و migrate لتطبيق التغييرات.
  • ✅ ORM يوفر عمليات Create, Read, Update, Delete.
  • ✅ هناك ثلاثة أنواع رئيسية من العلاقات: ForeignKey, OneToOne, ManyToMany.
  • ✅ استخدم أفضل الممارسات لتحسين أداء تطبيقك.
