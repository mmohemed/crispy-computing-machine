نظام المصادقة Authentication

تعلم كيفية تطبيق نظام تسجيل دخول متكامل باستخدام نظام المصادقة المدمج في Django.

مدة القراءة: 12 دقيقة مستوى: متوسط Django Auth أمان

ما هو نظام المصادقة في Django؟

يوفر Django نظام مصادقة متكامل وقوي (Authentication System) يمكن استخدامه مباشرة أو تخصيصه حسب احتياجات التطبيق. يشمل النظام:

  • نموذج المستخدم (User Model): نموذج مدمج لإدارة المستخدمين.
  • المصادقة (Authentication): التحقق من هوية المستخدم.
  • الصلاحيات (Permissions): التحكم في الوصول إلى الموارد.
  • المجموعات (Groups): تنظيم المستخدمين في مجموعات.
  • الجلسات (Sessions): إدارة حالة تسجيل الدخول.
ملاحظة: نظام المصادقة في Django آمن ومتكامل، ويستخدم تقنيات مثل التجزئة (Hashing) لتخزين كلمات المرور بشكل آمن.

نموذج المستخدم (User Model)

يوفر Django نموذج User مدمج يحتوي على الحقول التالية:

الحقل الوصف
username اسم المستخدم (فريد)
password كلمة المرور (مشفرة)
email البريد الإلكتروني
first_name الاسم الأول
last_name الاسم الأخير
is_active هل الحساب نشط؟
is_staff هل لديه صلاحيات الإدارة؟
is_superuser هل هو مدير كامل؟
date_joined تاريخ التسجيل
last_login آخر تسجيل دخول
نصيحة: يمكنك تخصيص نموذج المستخدم عن طريق إنشاء نموذج مخصص يرث من AbstractUser.

دوال المصادقة الأساسية

يوفر Django مجموعة من الدوال الجاهزة للتعامل مع المصادقة:

1. إنشاء مستخدم

views.py
from django.contrib.auth.models import User
from django.contrib.auth import authenticate, login, logout

# إنشاء مستخدم جديد
def register_user(request):
    if request.method == 'POST':
        username = request.POST['username']
        email = request.POST['email']
        password = request.POST['password']
        
        # إنشاء المستخدم
        user = User.objects.create_user(
            username=username,
            email=email,
            password=password
        )
        # تسجيل الدخول تلقائياً
        login(request, user)
        return redirect('home')

2. تسجيل الدخول

views.py
def login_user(request):
    if request.method == 'POST':
        username = request.POST['username']
        password = request.POST['password']
        
        # التحقق من المستخدم
        user = authenticate(request, username=username, password=password)
        
        if user is not None:
            login(request, user)
            return redirect('home')
        else:
            # رسالة خطأ
            return render(request, 'login.html', {'error': 'بيانات غير صحيحة'})

3. تسجيل الخروج

views.py
def logout_user(request):
    logout(request)
    return redirect('home')
تنبيه: استخدم create_user() بدلاً من create() لأنها تقوم بتشفير كلمة المرور تلقائياً.

نماذج المصادقة المدمجة

يوفر Django نماذج جاهزة للمصادقة يمكن استخدامها مباشرة:

نموذج تسجيل الدخول

forms.py
from django.contrib.auth.forms import AuthenticationForm

# استخدام النموذج المدمج
# في views.py
from django.contrib.auth.forms import AuthenticationForm

def login_view(request):
    form = AuthenticationForm()
    return render(request, 'login.html', {'form': form})

نموذج إنشاء مستخدم

forms.py
from django.contrib.auth.forms import UserCreationForm

# استخدام النموذج المدمج
# في views.py
from django.contrib.auth.forms import UserCreationForm

def register_view(request):
    form = UserCreationForm()
    return render(request, 'register.html', {'form': form})
ملاحظة: يمكنك تخصيص هذه النماذج عن طريق وراثتها وإضافة حقول إضافية.

الصلاحيات (Permissions)

نظام الصلاحيات في Django يسمح لك بالتحكم في من يمكنه الوصول إلى ماذا. هناك ثلاثة أنواع رئيسية من الصلاحيات:

  • إضافة (add): يمكن للمستخدم إضافة كائنات جديدة.
  • تغيير (change): يمكن للمستخدم تعديل الكائنات الموجودة.
  • حذف (delete): يمكن للمستخدم حذف الكائنات.

التحقق من الصلاحيات

views.py / templates
# في الـ View
if request.user.has_perm('app.add_post'):
    # يمكنه إضافة منشور
    pass

# في القالب
{% if perms.app.add_post %}
    <a href="{% url 'add_post' %}">إضافة منشور</a>
{% endif %}

إنشاء صلاحيات مخصصة

models.py
class Post(models.Model):
    title = models.CharField(max_length=200)
    content = models.TextField()
    
    class Meta:
        permissions = [
            ('can_publish_post', 'يمكنه نشر المنشورات'),
            ('can_approve_post', 'يمكنه الموافقة على المنشورات'),
        ]
