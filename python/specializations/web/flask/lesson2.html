إعداد بيئة Flask

تعلم كيفية تثبيت Flask وإعداد بيئة التطوير المناسبة لبناء تطبيقات الويب ببايثون.

مدة القراءة: 12 دقيقة مستوى: مبتدئ سطر الأوامر

ما الذي سنتعلمه؟

في هذا الدرس، سنتعلم كيفية إعداد بيئة العمل اللازمة لتطوير تطبيقات Flask. سنغطي كل شيء من تثبيت بايثون إلى إنشاء أول مشروع Flask.

  • ✅ تثبيت بايثون – التأكد من وجود بايثون على جهازك.
  • ✅ إنشاء بيئة افتراضية – لعزل تبعيات المشروع.
  • ✅ تثبيت Flask – باستخدام مدير الحزم pip.
  • ✅ إنشاء هيكل المشروع – تنظيم ملفات التطبيق.
  • ✅ تشغيل أول تطبيق – اختبار التثبيت والتأكد من عمله.

متطلبات النظام

قبل البدء، تأكد من توفر المتطلبات التالية:

المتطلب الوصف
بايثون الإصدار 3.7 أو أحدث
مدير الحزم pip مثبت مع بايثون 3.4+
محطة الأوامر Terminal (Linux/Mac) أو Command Prompt (Windows)
محرر نصوص VS Code أو PyCharm أو أي محرر تفضله
ملاحظة: إذا كنت تستخدم نظام Windows، قد تحتاج إلى تثبيت Windows Terminal أو استخدام Git Bash لتجربة أفضل مع الأوامر.

الخطوة 1: تثبيت بايثون

إذا لم يكن لديك بايثون مثبتاً على جهازك، اتبع هذه الخطوات:

  1. قم بزيارة الموقع الرسمي: python.org
  2. قم بتحميل أحدث إصدار من بايثون (Python 3.x).
  3. قم بتشغيل المثبت وتأكد من تفعيل خيار "Add Python to PATH".
  4. اتبع التعليمات لإكمال التثبيت.
التحقق من التثبيت

# في سطر الأوامر
python --version
# أو
python3 --version

# يجب أن يظهر شيء مشابه
Python 3.11.0
تم التثبيت بنجاح! إذا ظهر رقم الإصدار، فأنت جاهز للخطوة التالية.

الخطوة 2: إنشاء بيئة افتراضية

البيئة الافتراضية (Virtual Environment) هي أداة لعزل تبعيات المشروع. هذا يمنع التعارض بين الإصدارات المختلفة للمكتبات.

إنشاء البيئة

إنشاء بيئة افتراضية

# إنشاء مجلد المشروع
mkdir my_flask_project
cd my_flask_project

# إنشاء البيئة الافتراضية
python -m venv venv
# أو
python3 -m venv venv

تفعيل البيئة

تفعيل البيئة الافتراضية

# على Windows
venv\Scripts\activate

# على Linux / Mac
source venv/bin/activate

# بعد التفعيل، سترى (venv) في بداية سطر الأوامر
تذكير مهم: تأكد من تفعيل البيئة الافتراضية قبل تثبيت أي مكتبة. ستظهر (venv) بجانب اسم المستخدم في المحطة.

الخطوة 3: تثبيت Flask

بعد تفعيل البيئة الافتراضية، يمكنك تثبيت Flask باستخدام pip:

تثبيت Flask

# تثبيت Flask
pip install flask

# للتحقق من التثبيت
pip show flask

# حفظ التبعيات في ملف requirements.txt
pip freeze > requirements.txt
نصيحة: استخدم pip freeze > requirements.txt لحفظ جميع المكتبات المثبتة. هذا مفيد لمشاركة المشروع مع الآخرين.
تم تثبيت Flask! الآن أنت جاهز لإنشاء أول تطبيق.

الخطوة 4: هيكل المشروع

ينظم مشروع Flask عادةً بالطريقة التالية:

هيكل المشروع

my_flask_project/
├── venv/                  # البيئة الافتراضية
├── app.py                 # ملف التطبيق الرئيسي
├── requirements.txt       # قائمة التبعيات
├── templates/             # مجلد القوالب (HTML)
│   └── index.html
├── static/                # الملفات الثابتة (CSS, JS, صور)
│   ├── css/
│   ├── js/
│   └── images/
└── .gitignore             # تجاهل الملفات غير المرغوبة في Git

إنشاء ملف التطبيق الرئيسي

app.py

from flask import Flask

# إنشاء تطبيق Flask
app = Flask(__name__)

# تعريف المسار الرئيسي
@app.route('/')
def home():
    return 'مرحباً في Flask!'

# تشغيل التطبيق
if __name__ == '__main__':
    app.run(debug=True)

الخطوة 5: تشغيل التطبيق

بعد إنشاء ملف app.py، يمكنك تشغيل التطبيق باستخدام الأمر التالي:

تشغيل التطبيق

# تشغيل التطبيق
python app.py

# ستظهر رسالة مشابهة:
# * Running on http://127.0.0.1:5000

افتح متصفحك وانتقل إلى http://127.0.0.1:5000 لترى رسالة الترحيب.

تهانينا! لقد قمت بإعداد بيئة Flask وتشغيل أول تطبيق ويب.

الأوامر الشائعة في Flask

إليك قائمة بالأوامر الأكثر استخداماً في تطوير Flask:

  • python -m venv venv – إنشاء بيئة افتراضية جديدة.
  • venv\Scripts\activate (Windows) / source venv/bin/activate (Linux/Mac) – تفعيل البيئة الافتراضية.
  • pip install flask – تثبيت Flask.
  • pip freeze > requirements.txt – حفظ التبعيات.
  • pip install -r requirements.txt – تثبيت التبعيات من ملف.
  • python app.py – تشغيل التطبيق.
  • deactivate – الخروج من البيئة الافتراضية.
ملاحظة: وضع debug=True في app.run() يعيد تشغيل الخادم تلقائياً عند إجراء تغييرات في الكود.

محاكي الأوامر التفاعلي

جرب تنفيذ أوامر إعداد بيئة Flask في المحاكي التفاعلي أدناه:

$ انتظر تنفيذ الأمر...
تنبيه: هذا المحاكي تفاعلي فقط ويوضح مخرجات الأوامر بشكل تعليمي. لا ينفذ أوامر حقيقية على جهازك.

نصائح لبيئة تطوير احترافية

  • استخدم VS Code مع إضافات Python: توفر إضافات مثل Python و Pylance تجربة تطوير ممتازة.
  • احتفظ بملف .gitignore: أضف venv/ و __pycache__/ و *.pyc إلى الملف.
  • قسّم المشروع إلى مجلدات: استخدم مجلدات منفصلة للنماذج (models) والعروض (views) والقوالب (templates).
  • استخدم متغيرات البيئة: خزّن المعلومات الحساسة (مثل مفاتيح API) في ملف .env.
  • تعلّم استخدام Flask CLI: أوامر مثل flask run و flask shell مفيدة جداً.
نصيحة اليوم: "البيئة الجيدة هي نصف التطوير الجيد. استثمر وقتاً في إعداد بيئة عمل مريحة."
