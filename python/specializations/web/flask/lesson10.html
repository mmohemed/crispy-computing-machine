نشر تطبيقات Flask

تعلم كيفية نشر تطبيقات Flask على منصات السحابة المختلفة مثل Heroku و PythonAnywhere و AWS.

مدة القراءة: 16 دقيقة مستوى: متوسط نشر / استضافة

ما الذي سنتعلمه؟

في هذا الدرس الأخير، سنتعلم كيفية نشر تطبيقات Flask على منصات الاستضافة المختلفة، من التحضير إلى النشر الفعلي.

  • ✅ تحضير التطبيق للنشر – إعداد الكود والمتغيرات البيئية.
  • ✅ اختيار منصة النشر – مقارنة بين المنصات المختلفة.
  • ✅ النشر على Heroku – خطوات نشر التطبيق مجاناً.
  • ✅ النشر على PythonAnywhere – منصة مبسطة لتطبيقات بايثون.
  • ✅ النشر على AWS – استخدام EC2 و Elastic Beanstalk.
  • ✅ أفضل ممارسات النشر – نصائح لتطبيق آمن ومستقر.

تحضير التطبيق للنشر

قبل النشر، تحتاج إلى تحضير التطبيق باتباع هذه الخطوات:

ملف requirements.txt

# إنشاء ملف التبعيات
pip freeze > requirements.txt

# مثال على محتوى الملف
Flask==2.3.3
Flask-SQLAlchemy==3.1.1
Flask-Login==0.6.2
Flask-WTF==1.1.1
gunicorn==21.2.0
python-dotenv==1.0.0
ملف Procfile (لـ Heroku)

web: gunicorn app:app
ملف .env (متغيرات البيئة)

SECRET_KEY=your-secret-key-here
DATABASE_URL=postgresql://user:pass@localhost/db
FLASK_ENV=production
استخدام متغيرات البيئة في الكود

import os
from dotenv import load_dotenv

load_dotenv()

class Config:
    SECRET_KEY = os.environ.get('SECRET_KEY') or 'default-key'
    SQLALCHEMY_DATABASE_URI = os.environ.get('DATABASE_URL') or 'sqlite:///site.db'
    FLASK_ENV = os.environ.get('FLASK_ENV') or 'development'
تنبيه: لا تضع أبداً المفاتيح السرية وكلمات المرور في الكود. استخدم متغيرات البيئة دائماً.

مقارنة منصات النشر

هناك العديد من المنصات لنشر تطبيقات Flask. إليك مقارنة بين أشهرها:

المنصة المميزات السعر المناسب لـ
Heroku سهل الاستخدام، تكامل مع Git، إضافات متعددة مجاني (مع قيود) / مدفوع المشاريع الصغيرة والمتوسطة
PythonAnywhere مخصص لبايثون، واجهة ويب سهلة، دعم Flask مجاني (مع قيود) / مدفوع المبتدئين والمشاريع البسيطة
AWS مرونة عالية، خيارات متعددة (EC2, EB, Lambda) مدفوع (حسب الاستخدام) المشاريع الكبيرة والمؤسسات
DigitalOcean خوادم App Platform، Droplets، سهولة الاستخدام مدفوع (بأسعار معقولة) المطورين والشركات الناشئة
Fly.io نشر سريع، دعم Docker، خوادم عالمية مجاني (مع قيود) / مدفوع المشاريع الحديثة
Render سهل الاستخدام، دعم Git، شبكة CDN مجاني (مع قيود) / مدفوع المشاريع الصغيرة والمتوسطة

النشر على Heroku

Heroku هو منصة سحابية سهلة الاستخدام لنشر تطبيقات الويب. اتبع هذه الخطوات:

خطوات النشر على Heroku

# 1. تثبيت Heroku CLI
# قم بتحميله من الموقع الرسمي

# 2. تسجيل الدخول
heroku login

# 3. إنشاء تطبيق جديد
heroku create my-flask-app

# 4. إضافة قاعدة بيانات (PostgreSQL)
heroku addons:create heroku-postgresql:hobby-dev

# 5. تعيين متغيرات البيئة
heroku config:set SECRET_KEY=your-secret-key
heroku config:set FLASK_ENV=production

# 6. النشر
git push heroku main

# 7. فتح التطبيق
heroku open

# 8. عرض السجلات
heroku logs --tail
نصيحة: Heroku يتطلب وجود ملف Procfile و requirements.txt في جذر المشروع.

PythonAnywhere هو منصة مبسطة لنشر تطبيقات بايثون، مثالية للمبتدئين.

خطوات النشر على PythonAnywhere

# 2. رفع الملفات عبر FTP أو باستخدام Git

# 5. إعداد WSGI

النشر على AWS

AWS (Amazon Web Services) يوفر خيارات متعددة لنشر تطبيقات Flask.

النشر باستخدام Elastic Beanstalk

Elastic Beanstalk

# 1. تثبيت EB CLI
pip install awsebcli

# 2. تهيئة التطبيق
eb init -p python-3.10 my-flask-app

# 3. إنشاء البيئة
eb create my-flask-env

# 4. تعيين متغيرات البيئة
eb setenv SECRET_KEY=your-key DATABASE_URL=postgresql://...

# 5. النشر
eb deploy

# 6. فتح التطبيق
eb open

النشر باستخدام EC2

EC2 - الخطوات الأساسية

# 1. إنشاء مثيل EC2 (Ubuntu)

# 2. الاتصال بالمثيل

# 3. تثبيت المتطلبات

# 4. نسخ المشروع

cd my-flask-app
python3 -m venv venv
source venv/bin/activate

أفضل ممارسات النشر

  • استخدم متغيرات البيئة: لا تخزن المفاتيح السرية في الكود. استخدم متغيرات البيئة دائماً.
  • قاعدة بيانات منفصلة: استخدم قاعدة بيانات منفصلة للإنتاج (PostgreSQL, MySQL) بدلاً من SQLite.
  • خادم ويب احترافي: استخدم Gunicorn أو uWSGI مع Nginx كخادم وكيل عكسي.
  • HTTPS: قم بتفعيل SSL/TLS لتشفير الاتصالات (استخدم Let's Encrypt).
  • مراقبة الأخطاء: استخدم أدوات مثل Sentry أو Rollbar لتتبع الأخطاء في الإنتاج.
  • نسخ احتياطية: قم بعمل نسخ احتياطية لقاعدة البيانات بشكل دوري.
  • التحديثات: حافظ على تحديث المكتبات وإصدار بايثون.
