ما هو Flask-WTF؟

Flask-WTF هو امتداد (Extension) لـ Flask يدمج مكتبة WTForms مع Flask. يوفر طريقة سهلة لإنشاء نماذج ويب، والتحقق من صحة البيانات، وحماية النماذج من هجمات CSRF.

حماية CSRF

حماية مدمجة ضد هجمات التزوير عبر المواقع

التحقق من الصحة

مدقق مدمج للتحقق من صحة البيانات المدخلة

مرونة عالية

يدعم جميع أنواع الحقول والمدققات المخصصة

سهل الاستخدام

بناء نماذج احترافية بأسطر قليلة من الكود

ملاحظة: Flask-WTF هي مكتبة رسمية موصى بها من قبل مجتمع Flask لبناء النماذج.

إنشاء نموذج

لإنشاء نموذج في Flask-WTF، نحدد كلاس يرث من FlaskForm ونعرف الحقول المطلوبة.

مثال: نموذج تسجيل دخول

forms.py

from flask_wtf import FlaskForm
from wtforms import StringField, PasswordField, SubmitField
from wtforms.validators import DataRequired, Email, Length

class LoginForm(FlaskForm):
    # حقل البريد الإلكتروني
    email = StringField('البريد الإلكتروني', 
        validators=[DataRequired(), Email()])
    
    # حقل كلمة المرور
    password = PasswordField('كلمة المرور', 
        validators=[DataRequired(), Length(min=6)])
    
    # زر الإرسال
    submit = SubmitField('تسجيل الدخول')

مثال: نموذج تسجيل مستخدم

forms.py - نموذج متقدم

from flask_wtf import FlaskForm
from wtforms import StringField, PasswordField, TextAreaField, SelectField, BooleanField, SubmitField
from wtforms.validators import DataRequired, Email, Length, EqualTo, Optional

class RegisterForm(FlaskForm):
    username = StringField('اسم المستخدم', 
        validators=[DataRequired(), Length(min=3, max=50)])
    
    email = StringField('البريد الإلكتروني', 
        validators=[DataRequired(), Email()])
    
    password = PasswordField('كلمة المرور', 
        validators=[DataRequired(), Length(min=6)])
    
    confirm_password = PasswordField('تأكيد كلمة المرور', 
        validators=[DataRequired(), EqualTo('password')])
    
    bio = TextAreaField('السيرة الذاتية', 
        validators=[Optional(), Length(max=500)])
    
    gender = SelectField('الجنس', 
        choices=[('male', 'ذكر'), ('female', 'أنثى')])
    
    agree_terms = BooleanField('أوافق على الشروط', 
        validators=[DataRequired()])
    
    submit = SubmitField('إنشاء حساب')
المدققات الشائعة:
  • DataRequired() – الحقل مطلوب
  • Email() – يجب أن يكون بريداً إلكترونياً صحيحاً
  • Length(min, max) – تحديد طول النص
  • EqualTo() – يساوي حقل آخر
  • Optional() – الحقل اختياري
  • NumberRange(min, max) – نطاق رقمي

أنواع الحقول في WTForms

توفر WTForms مجموعة واسعة من أنواع الحقول لتغطية جميع احتياجاتك:

الحقل الوصف مثال
StringField نص قصير (سطر واحد) StringField('الاسم')
TextAreaField نص طويل (متعدد الأسطر) TextAreaField('الوصف')
PasswordField كلمة مرور (مخفية) PasswordField('كلمة المرور')
EmailField بريد إلكتروني EmailField('البريد')
IntegerField رقم صحيح IntegerField('العمر')
FloatField رقم عشري FloatField('السعر')
BooleanField خانة اختيار (Checkbox) BooleanField('موافق')
SelectField قائمة منسدلة SelectField('الدولة', choices=[])
RadioField أزرار اختيار RadioField('الجنس', choices=[])
FileField رفع ملفات FileField('الصورة')
DateField تاريخ DateField('تاريخ الميلاد')
DateTimeField تاريخ ووقت DateTimeField('تاريخ النشر')
HiddenField حقل مخفي HiddenField('id')
SubmitField زر الإرسال SubmitField('إرسال')

عرض النموذج في القالب

لاستخدام النموذج في القالب، نمرره إلى render_template() ونستخدمه في HTML.

كود التطبيق

app.py

from flask import Flask, render_template, redirect, url_for, flash
from forms import LoginForm

app = Flask(__name__)
app.config['SECRET_KEY'] = 'your-secret-key-here'

@app.route('/login', methods=['GET', 'POST'])
def login():
    form = LoginForm()
    
    if form.validate_on_submit():
        # معالجة البيانات
        email = form.email.data
        password = form.password.data
        flash('تم تسجيل الدخول بنجاح!', 'success')
        return redirect(url_for('home'))
    
    return render_template('login.html', form=form)

قالب النموذج

templates/login.html

{% extends "base.html" %}

{% block content %}
<h1>تسجيل الدخول</h1>

<form method="POST" action="">
    {{ form.hidden_tag() }}
    
    <div class="form-group">
        {{ form.email.label }}
        {{ form.email(class="form-control") }}
        {% for error in form.email.errors %}
            <span class="error">{{ error }}</span>
        {% endfor %}
    </div>
    
    <div class="form-group">
        {{ form.password.label }}
        {{ form.password(class="form-control") }}
        {% for error in form.password.errors %}
            <span class="error">{{ error }}</span>
        {% endfor %}
    </div>
    
    {{ form.submit(class="btn btn-primary") }}
</form>
{% endblock %}
ملاحظة: form.hidden_tag() يضيف تلقائياً حقل CSRF المخفي لحماية النموذج.

حماية CSRF

CSRF (Cross-Site Request Forgery) هو هجوم يخدع المستخدم لإرسال طلب غير مقصود. يوفر Flask-WTF حماية مدمجة ضد هذا الهجوم.

إعداد المفتاح السري

إعداد SECRET_KEY

# في app.py
app.config['SECRET_KEY'] = 'your-secret-key-here'

# أفضل ممارسة: استخدم متغيرات البيئة
import os
app.config['SECRET_KEY'] = os.environ.get('SECRET_KEY') or 'fallback-key'

تفعيل الحماية

تفعيل CSRF

from flask_wtf.csrf import CSRFProtect

# تهيئة الحماية
csrf = CSRFProtect(app)

# أو باستخدام FlaskForm مباشرة
# كل نموذج يرث من FlaskForm يحصل على حماية CSRF تلقائياً
تنبيه: تأكد من تعيين SECRET_KEY في التطبيق. بدونها، لن تعمل حماية CSRF.

  • استخدم مدققات مخصصة: يمكنك إنشاء دوال تحقق مخصصة لحالات خاصة.
