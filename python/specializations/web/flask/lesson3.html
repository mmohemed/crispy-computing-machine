نظام التوجيه (Routing)

التوجيه هو آلية ربط عناوين URL بالدوال التي تعالج الطلبات. عند زيارة المستخدم لمسار معين، يقوم Flask بتنفيذ الدالة المرتبطة بهذا المسار وإعادة النتيجة للمتصفح.

المسارات الثابتة

مسارات ثابتة

from flask import Flask

app = Flask(__name__)

@app.route('/')
def home():
    return 'الصفحة الرئيسية'

@app.route('/about')
def about():
    return 'صفحة عن الموقع'

@app.route('/contact')
def contact():
    return 'صفحة الاتصال'

المسارات الديناميكية

تسمح المسارات الديناميكية بتمرير متغيرات في عنوان URL.

مسارات ديناميكية

# مسار ديناميكي باسم المستخدم
@app.route('/user/<name>')
def user_profile(name):
    return f'مرحباً {name}!'

# مسار مع رقم (مع محول int)
@app.route('/post/<int:post_id>')
def show_post(post_id):
    return f'رقم المنشور: {post_id}'

# مسار مع مسار (مع محول path)
@app.route('/path/<path:subpath>')
def show_subpath(subpath):
    return f'المسار الفرعي: {subpath}'
محولات المسارات:
  • string – النص الافتراضي (يقبل أي نص)
  • int – يقبل الأرقام الصحيحة فقط
  • float – يقبل الأرقام العشرية
  • path – يقبل مساراً كاملاً (بما في ذلك `/`)
  • uuid – يقبل معرفات UUID

مقارنة محولات المسارات

المحول الوصف مثال
string أي نص (الافتراضي) /user/<name>
int أرقام صحيحة فقط /post/<int:id>
float أرقام عشرية /price/<float:value>
path مسار كامل (مع `/`) /files/<path:filepath>
uuid معرفات UUID /item/<uuid:uid>

القوالب (Templates) و Jinja2

يستخدم Flask محرك القوالب Jinja2 لعرض HTML ديناميكياً. القوالب تسمح بفصل المنطق عن واجهة المستخدم.

هيكل مجلد القوالب

هيكل المشروع

my_flask_project/
├── app.py
├── templates/
│   ├── base.html       # القالب الأساسي
│   ├── index.html      # صفحة رئيسية
│   └── user.html       # صفحة المستخدم
└── static/
    ├── css/
    │   └── style.css
    └── js/
        └── script.js

إنشاء قالب أساسي (base.html)

templates/base.html

<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>{% block title %}Flask App{% endblock %}</title>
    <link rel="stylesheet" href="{{ url_for('static', filename='css/style.css') }}">
</head>
<body>
    <nav>
        <a href="/">الرئيسية</a>
        <a href="/about">عن الموقع</a>
    </nav>
    
    <main>
        {% block content %}{% endblock %}
    </main>
    
    <footer>
        © 2026 Flask App
    </footer>
</body>
</html>

إنشاء صفحة باستخدام القالب

templates/index.html

{% extends "base.html" %}

{% block title %}الرئيسية - Flask App{% endblock %}

{% block content %}
    <h1>مرحباً في Flask!</h1>
    <p>هذا هو أول قالب Flask باستخدام Jinja2.</p>
    
    {% if user %}
        <p>مرحباً {{ user }}!</p>
    {% else %}
        <p>مرحباً زائرنا الكريم!</p>
    {% endif %}
    
    <ul>
        {% for item in items %}
            <li>{{ item }}</li>
        {% endfor %}
    </ul>
{% endblock %}
ملاحظة: تستخدم Jinja2 علامات {{ }} لعرض المتغيرات، و {% %} للتحكم في التدفق (if، for، extends، إلخ).

تمرير البيانات إلى القوالب

يمكنك تمرير البيانات من دوال العرض إلى القوالب باستخدام معامل render_template().

app.py - تمرير البيانات

from flask import Flask, render_template

app = Flask(__name__)

@app.route('/')
def home():
    user = 'أحمد'
    items = ['التعلم', 'الإبداع', 'التميز']
    return render_template('index.html', user=user, items=items)

@app.route('/user/<name>')
def user_profile(name):
    # تمرير البيانات كقاموس
    data = {
        'username': name,
        'age': 25,
        'city': 'القاهرة'
    }
    return render_template('user.html', **data)

@app.route('/about')
def about():
    # تمرير بيانات بسيطة
    return render_template('about.html', title='عن الموقع')
نصيحة: يمكنك تمرير أي عدد من المتغيرات إلى القالب. استخدم القواميس لتنظيم البيانات المعقدة.

استخدام البيانات في القالب

templates/user.html

<h1>ملف المستخدم</h1>
<p>الاسم: {{ username }}</p>
<p>العمر: {{ age }} سنة</p>
<p>المدينة: {{ city }}</p>

{# تعليق في Jinja2 - لن يظهر في الصفحة #}

{% if age >= 18 %}
    <p style="color: green;">✅ مستخدم بالغ</p>
{% else %}
    <p style="color: orange;">⚠️ مستخدم قاصر</p>
{% endif %}

استخدام الملفات الثابتة في القالب

templates/base.html

<!-- ربط ملف CSS -->
<link rel="stylesheet" href="{{ url_for('static', filename='css/style.css') }}">

<!-- إضافة صورة -->
<img src="{{ url_for('static', filename='images/logo.png') }}" alt="Logo">

<!-- إضافة JavaScript -->
<script src="{{ url_for('static', filename='js/script.js') }}"></script>
تذكير: استخدم دالة url_for('static', filename='...') لإنشاء روابط الملفات الثابتة. هذه الدالة تضمن عمل الروابط بشكل صحيح في جميع المسارات.

دوال Flask المفيدة للقوالب

توفر Flask دوالاً مساعدة يمكن استخدامها في القوالب:

  • url_for() – إنشاء روابط ديناميكية للمسارات.
  • get_flashed_messages() – عرض رسائل مؤقتة (فلاش).
  • session – التعامل مع جلسات المستخدم.
  • request – الوصول إلى بيانات الطلب.
أمثلة على url_for()

<!-- رابط إلى الصفحة الرئيسية -->
<a href="{{ url_for('home') }}">الرئيسية</a>

<!-- رابط مع متغيرات -->
<a href="{{ url_for('user_profile', name='أحمد') }}">ملف أحمد</a>

<!-- رابط إلى ملف ثابت -->
<link rel="stylesheet" href="{{ url_for('static', filename='css/style.css') }}">

مثال تفاعلي: استكشف التوجيه والقوالب

جرب إنشاء مسارات مختلفة وشاهد كيف تعمل مع محرك القوالب:

/ /about /user/<name>
المسارات المعرفة ووظائفها ستظهر هنا...
تذكير: هذا المثال تفاعلي فقط ويحاكي نظام التوجيه في Flask. في التطبيقات الحقيقية، تُعرّف المسارات في كود بايثون.

نصائح للتوجيه والقوالب

  • استخدم المسارات الديناميكية بحكمة: استخدم محولات المسارات لتقييد نوع البيانات المسموح بها.
  • نظّم القوالب باستخدام الوراثة: أنشئ قالباً أساسياً (base.html) ووسّعه في الصفحات الفرعية.
  • استخدم url_for() بدلاً من الروابط الثابتة: هذا يجعل الكود أكثر قابلية للصيانة.
  • استفد من مرشحات Jinja2: مثل | upper، | lower، | length، | default.
  • قسّم القوالب إلى أجزاء قابلة لإعادة الاستخدام: استخدم {% include %} لإضافة أجزاء مثل شريط التنقل والتذييل.
نصيحة اليوم: "القوالب الجيدة تجعل التطبيق سهل الصيانة وجميل المظهر. استثمر وقتاً في تصميم قوالب احترافية."
