معالجة الأخطاء والتصحيح

تعلم كيفية التعامل مع الأخطاء في Flask، تقنيات التصحيح المتقدمة، وتسجيل الأحداث لتحسين استقرار التطبيق.

مدة القراءة: 14 دقيقة مستوى: متوسط Debugging

ما الذي سنتعلمه؟

في هذا الدرس، سنتعلم كيفية التعامل مع الأخطاء في تطبيقات Flask، وتقنيات التصحيح الفعالة، وتسجيل الأحداث.

  • ✅ أنواع الأخطاء – فهم الأخطاء الشائعة في Flask.
  • ✅ معالجة الأخطاء – استخدام try/except وإنشاء صفحات خطأ مخصصة.
  • ✅ وضع التصحيح – استخدام debug mode وأدوات التصحيح.
  • ✅ تسجيل الأحداث (Logging) – تسجيل الأخطاء والأنشطة.
  • ✅ تصحيح الأخطاء – تقنيات وحيل لتصحيح الأخطاء بسرعة.
  • ✅ أفضل الممارسات – نصائح لتطبيقات أكثر استقراراً.

أنواع الأخطاء في Flask

هناك عدة أنواع من الأخطاء التي قد تواجهها في تطبيقات Flask:

الكود النوع الوصف مثال
400 Bad Request طلب غير صحيح (بيانات مفقودة) نموذج بدون حقول مطلوبة
401 Unauthorized غير مصرح (يحتاج مصادقة) محاولة وصول بدون تسجيل دخول
403 Forbidden ممنوع (لا توجد صلاحية) محاولة وصول صفحة مدير
404 Not Found المورد غير موجود مسار غير موجود في التطبيق
405 Method Not Allowed طريقة غير مسموحة POST على مسار GET فقط
500 Internal Server Error خطأ في الخادم خطأ في قاعدة البيانات
503 Service Unavailable الخدمة غير متاحة خادم قاعدة البيانات متوقف
ملاحظة: فهم رموز الحالة يساعدك في تشخيص المشكلات بسرعة وتقديم رسائل خطأ مفيدة للمستخدمين.

معالجة الأخطاء الأساسية

استخدم try/except للتعامل مع الأخطاء المتوقعة ومنع انهيار التطبيق.

معالجة الأخطاء

from flask import Flask, render_template, flash, redirect, url_for

app = Flask(__name__)

@app.route('/user/<int:user_id>')
def get_user(user_id):
    try:
        # محاولة جلب المستخدم من قاعدة البيانات
        user = User.query.get(user_id)
        if not user:
            # رفع استثناء مخصص
            raise ValueError('المستخدم غير موجود')
        return render_template('user.html', user=user)
    except ValueError as e:
        flash(str(e), 'danger')
        return redirect(url_for('home'))
    except Exception as e:
        # تسجيل الخطأ غير المتوقع
        app.logger.error(f'خطأ غير متوقع: {e}')
        flash('حدث خطأ غير متوقع. الرجاء المحاولة لاحقاً.', 'danger')
        return redirect(url_for('home'))

معالجة أخطاء قاعدة البيانات

معالجة أخطاء قاعدة البيانات

from sqlalchemy.exc import SQLAlchemyError

@app.route('/create-post', methods=['POST'])
def create_post():
    try:
        post = Post(title=request.form['title'], content=request.form['content'])
        db.session.add(post)
        db.session.commit()
        flash('تم إنشاء المنشور بنجاح', 'success')
        return redirect(url_for('home'))
    except SQLAlchemyError as e:
        db.session.rollback()
        app.logger.error(f'خطأ في قاعدة البيانات: {e}')
        flash('حدث خطأ في قاعدة البيانات. الرجاء المحاولة لاحقاً.', 'danger')
        return redirect(url_for('home'))
    except Exception as e:
        app.logger.error(f'خطأ غير متوقع: {e}')
        flash('حدث خطأ غير متوقع.', 'danger')
        return redirect(url_for('home'))

صفحات الخطأ المخصصة

قم بإنشاء صفحات خطأ مخصصة لتجربة مستخدم أفضل.

صفحات الخطأ المخصصة

from flask import render_template

# صفحة 404 - غير موجود
@app.errorhandler(404)
def page_not_found(e):
    return render_template('404.html'), 404

# صفحة 500 - خطأ في الخادم
@app.errorhandler(500)
def internal_server_error(e):
    app.logger.error(f'خطأ 500: {e}')
    return render_template('500.html'), 500

# صفحة 403 - ممنوع
@app.errorhandler(403)
def forbidden(e):
    return render_template('403.html'), 403

# صفحة 405 - طريقة غير مسموحة
@app.errorhandler(405)
def method_not_allowed(e):
    return render_template('405.html'), 405

# معالج الأخطاء العام
@app.errorhandler(Exception)
def handle_exception(e):
    app.logger.error(f'خطأ غير متوقع: {e}')
    return render_template('error.html', error=str(e)), 500
نصيحة: قوالب الخطأ المخصصة تجعل التطبيق يبدو أكثر احترافية وتحسن تجربة المستخدم.

وضع التصحيح (Debug Mode)

وضع التصحيح مفيد جداً أثناء التطوير. يوفر إعادة تشغيل تلقائي وعرض تفصيلي للأخطاء.

تفعيل وضع التصحيح

# الطريقة الأولى: في app.run()
if __name__ == '__main__':
    app.run(debug=True)

# الطريقة الثانية: باستخدام متغيرات البيئة
# Linux/Mac:
# export FLASK_DEBUG=1
# Windows:
# set FLASK_DEBUG=1
# ثم:
# flask run

# الطريقة الثالثة: في الإعدادات
app.config['DEBUG'] = True
app.config['ENV'] = 'development'

مميزات وضع التصحيح

  • إعادة تشغيل تلقائي: عند تغيير الكود، يعاد تشغيل الخادم تلقائياً.
  • مصحح الأخطاء التفاعلي: صفحة خطأ تفاعلية مع إمكانية تنفيذ كود.
  • عرض التفاصيل: يعرض تتبع المكدس (Stack Trace) كاملاً.
  • تسجيل إضافي: يسجل المزيد من المعلومات للمساعدة في التصحيح.
تحذير: لا تستخدم وضع التصحيح في الإنتاج أبداً! يعرض معلومات حساسة ويمكن أن يشكل ثغرة أمنية.

تسجيل الأحداث (Logging)

التسجيل مهم لتتبع الأخطاء والأنشطة في التطبيق. يساعد في تشخيص المشكلات في الإنتاج.

إعداد التسجيل

import logging
from logging.handlers import RotatingFileHandler
import os

# إعداد مجلد السجلات
if not os.path.exists('logs'):
    os.mkdir('logs')

# تكوين معالج الملفات
file_handler = RotatingFileHandler('logs/app.log', maxBytes=10240, backupCount=10)
file_handler.setFormatter(logging.Formatter(
    '%(asctime)s %(levelname)s: %(message)s [in %(pathname)s:%(lineno)d]'
))
file_handler.setLevel(logging.INFO)

# إضافة المعالج إلى التطبيق
app.logger.addHandler(file_handler)
app.logger.setLevel(logging.INFO)

# استخدام التسجيل
@app.route('/')
def home():
    app.logger.info('تم زيارة الصفحة الرئيسية')
    return render_template('home.html')

@app.route('/api/data')
def get_data():
    try:
        data = fetch_data()
        app.logger.debug(f'تم جلب البيانات: {len(data)} عنصر')
        return jsonify(data)
    except Exception as e:
        app.logger.error(f'خطأ في جلب البيانات: {e}')
        return jsonify({'error': 'حدث خطأ'}), 500

مستويات التسجيل

  • DEBUG – معلومات تفصيلية للتصحيح.
  • INFO – معلومات عامة عن سير العمل.
  • WARNING – تحذيرات، مشكلات محتملة.
  • ERROR – أخطاء تؤثر على الوظائف.
  • CRITICAL – أخطاء خطيرة تتطلب تدخل فوري.
نصيحة: استخدم مستويات التسجيل المناسبة لكل نوع من الأحداث. لا تسجل معلومات حساسة مثل كلمات المرور.

محاكي الأخطاء التفاعلي

جرب محاكاة أنواع مختلفة من الأخطاء وشاهد كيف يتم عرضها:

اختر نوع الخطأ واضغط "محاكاة الخطأ" لرؤية العرض...
تنبيه: هذا المحاكي يوضح كيف تبدو الأخطاء في Flask. الأخطاء الحقيقية قد تظهر بشكل مختلف حسب الإعدادات.

نصائح لتصحيح الأخطاء بفعالية

  • اقرأ تتبع المكدس: السطر الأول قد يكون الأهم. ابدأ بفهم مصدر الخطأ.
  • استخدم نقاط التوقف: في VS Code أو PyCharm، أضف نقاط توقف وتتبع تنفيذ الكود.
  • قسّم المشكلة: عزل الجزء الذي يسبب المشكلة قبل محاولة حلها.
  • استخدم وضع التصحيح: يساعد في رؤية التفاصيل أثناء التنفيذ.
  • سجل كل شيء: استخدم التسجيل لتتبع الأخطاء والأنشطة في الإنتاج.
  • اختبر الحل: تأكد من أن الحل يعمل ولا يسبب مشاكل جديدة.
