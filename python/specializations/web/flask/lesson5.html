قواعد البيانات SQLAlchemy

تعلم كيفية التعامل مع قواعد البيانات باستخدام SQLAlchemy ORM، وإنشاء النماذج، وإجراء عمليات CRUD.

مدة القراءة: 16 دقيقة مستوى: متوسط SQLite / PostgreSQL

ما الذي سنتعلمه؟

في هذا الدرس، سنتعلم كيفية التعامل مع قواعد البيانات في Flask باستخدام SQLAlchemy، وهو ORM (Object-Relational Mapping) قوي يسهل التعامل مع قواعد البيانات.

  • ✅ ما هو SQLAlchemy – مقدمة عن ORM ومميزاته.
  • ✅ تثبيت Flask-SQLAlchemy – إضافة المكتبة إلى المشروع.
  • ✅ إنشاء النماذج – تعريف جداول قاعدة البيانات.
  • ✅ عمليات CRUD – إنشاء، قراءة، تحديث، حذف البيانات.
  • ✅ العلاقات بين الجداول – One-to-Many, Many-to-Many.
  • ✅ الترحيل (Migrations) – تحديث هيكل قاعدة البيانات.

ما هو SQLAlchemy؟

SQLAlchemy هو مكتبة بايثون قوية للتعامل مع قواعد البيانات. يوفر ORM (Object-Relational Mapping) يسمح لك بالتعامل مع قاعدة البيانات باستخدام كائنات بايثون بدلاً من كتابة استعلامات SQL مباشرة.

ORM قوي

تعامل مع قاعدة البيانات باستخدام كائنات بايثون

دعم متعدد

يدعم SQLite, PostgreSQL, MySQL, Oracle

أمان

حماية مدمجة ضد SQL Injection

مرونة عالية

يمكنك كتابة استعلامات SQL معقدة عند الحاجة

ملاحظة: Flask-SQLAlchemy هو امتداد لـ Flask يضيف دعم SQLAlchemy مع تكامل سهل مع التطبيق.

تثبيت Flask-SQLAlchemy

لتثبيت Flask-SQLAlchemy ومشغل قاعدة البيانات، استخدم الأوامر التالية:

تثبيت المكتبات

# تثبيت Flask-SQLAlchemy
pip install flask-sqlalchemy

# لتثبيت مشغل PostgreSQL (اختياري)
pip install psycopg2-binary

# لتثبيت مشغل MySQL (اختياري)
pip install pymysql

# حفظ التبعيات
pip freeze > requirements.txt
تم التثبيت! الآن أصبحت جاهزاً لإنشاء النماذج.

تكوين قاعدة البيانات

لإعداد قاعدة البيانات في تطبيق Flask، نحتاج إلى تكوين URI الخاص بقاعدة البيانات.

app.py - تكوين قاعدة البيانات

from flask import Flask
from flask_sqlalchemy import SQLAlchemy
import os

app = Flask(__name__)

# تكوين قاعدة البيانات
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///site.db'
app.config['SQLALCHEMY_TRACK_MODIFICATIONS'] = False

# إنشاء كائن قاعدة البيانات
db = SQLAlchemy(app)

# تعريف النموذج
class User(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(50), unique=True, nullable=False)
    email = db.Column(db.String(120), unique=True, nullable=False)
    password = db.Column(db.String(60), nullable=False)

    def __repr__(self):
        return f"User('{self.username}', '{self.email}')"

# إنشاء قاعدة البيانات
with app.app_context():
    db.create_all()
أنواع URI لقواعد البيانات:
  • SQLite: sqlite:///site.db
  • PostgreSQL: postgresql://user:pass@localhost/db
  • MySQL: mysql://user:pass@localhost/db

أنواع الأعمدة في SQLAlchemy

توفر SQLAlchemy مجموعة واسعة من أنواع الأعمدة لتناسب جميع احتياجاتك:

النوع الوصف مثال
Integer رقم صحيح db.Integer
String نص قصير (سلسلة) db.String(100)
Text نص طويل db.Text
Boolean قيمة منطقية db.Boolean
DateTime تاريخ ووقت db.DateTime
Float رقم عشري db.Float
JSON بيانات JSON db.JSON

إنشاء النماذج (Models)

النماذج هي كلاسات بايثون تمثل جداول قاعدة البيانات. يتم تعريفها عن طريق وراثة db.Model.

models.py - نماذج متقدمة

from flask_sqlalchemy import SQLAlchemy
from datetime import datetime

db = SQLAlchemy()

# نموذج المستخدم
class User(db.Model):
    __tablename__ = 'users'
    
    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(50), unique=True, nullable=False)
    email = db.Column(db.String(120), unique=True, nullable=False)
    password = db.Column(db.String(60), nullable=False)
    created_at = db.Column(db.DateTime, default=datetime.utcnow)
    is_active = db.Column(db.Boolean, default=True)
    
    # العلاقة مع المنشورات (One-to-Many)
    posts = db.relationship('Post', backref='author', lazy=True)
    
    def __repr__(self):
        return f"User('{self.username}')"

# نموذج المنشور
class Post(db.Model):
    __tablename__ = 'posts'
    
    id = db.Column(db.Integer, primary_key=True)
    title = db.Column(db.String(100), nullable=False)
    content = db.Column(db.Text, nullable=False)
    published = db.Column(db.Boolean, default=False)
    created_at = db.Column(db.DateTime, default=datetime.utcnow)
    updated_at = db.Column(db.DateTime, default=datetime.utcnow, onupdate=datetime.utcnow)
    
    # المفتاح الخارجي
    user_id = db.Column(db.Integer, db.ForeignKey('users.id'), nullable=False)
    
    def __repr__(self):
        return f"Post('{self.title}')"

# نموذج الفئة (Many-to-Many مع المنشورات)
class Category(db.Model):
    __tablename__ = 'categories'
    
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(50), unique=True, nullable=False)
    
    # العلاقة Many-to-Many
    posts = db.relationship('Post', secondary='post_categories', backref='categories')
تذكير: db.create_all() يجب أن يُستدعى داخل سياق التطبيق باستخدام app.app_context().

العلاقات بين الجداول

تدعم SQLAlchemy جميع أنواع العلاقات بين الجداول:

نوع العلاقة الوصف مثال
One-to-One كل سجل مرتبط بسجل واحد في جدول آخر User ↔ Profile
One-to-Many سجل واحد مرتبط بعدة سجلات User → Posts
Many-to-One عدة سجلات مرتبطة بسجل واحد Posts → User
Many-to-Many عدة سجلات مرتبطة بعدة سجلات Posts ↔ Categories
جدول وسيط (Many-to-Many)

# جدول وسيط للعلاقة Many-to-Many
post_categories = db.Table('post_categories',
    db.Column('post_id', db.Integer, db.ForeignKey('posts.id'), primary_key=True),
    db.Column('category_id', db.Integer, db.ForeignKey('categories.id'), primary_key=True)
)

class Post(db.Model):
    # ... الحقول السابقة ...
    categories = db.relationship('Category', secondary=post_categories, backref='posts')

عمليات CRUD الأساسية

CRUD هي اختصار لـ Create, Read, Update, Delete. هذه هي العمليات الأساسية التي نجريها على قاعدة البيانات.

1. إنشاء (Create)

إضافة بيانات

# إنشاء مستخدم جديد
new_user = User(
    username='ahmed',
    email='ahmed@example.com',
    password='hashed_password'
)

# إضافة إلى الجلسة
db.session.add(new_user)

# إنشاء منشور جديد
new_post = Post(
    title='أول منشور',
    content='محتوى المنشور...',
    user_id=new_user.id
)
db.session.add(new_post)

# حفظ التغييرات في قاعدة البيانات
db.session.commit()

2. قراءة (Read)

استعلامات القراءة

# جلب جميع المستخدمين
users = User.query.all()

# جلب مستخدم حسب المعرف
user = User.query.get(1)

# جلب مستخدم حسب البريد الإلكتروني
user = User.query.filter_by(email='ahmed@example.com').first()

# جلب المستخدمين النشطين مع الترتيب
active_users = User.query.filter_by(is_active=True).order_by(User.username).all()

# جلب المنشورات التي تحتوي على كلمة معينة
posts = Post.query.filter(Post.content.contains('Django')).all()

# استخدام LIKE
users = User.query.filter(User.username.like('%med%')).all()

# جلب مع العلاقات
user = User.query.get(1)
posts = user.posts  # جميع منشورات المستخدم

3. تحديث (Update)

تحديث البيانات

# جلب المستخدم
user = User.query.get(1)

# تحديث الحقول
user.username = 'ahmed_updated'
user.email = 'new_email@example.com'

# حفظ التغييرات
db.session.commit()

# تحديث متعدد
User.query.filter_by(is_active=False).update({'is_active': True})
db.session.commit()

4. حذف (Delete)

حذف البيانات

# جلب المستخدم
user = User.query.get(1)

# حذف المستخدم
db.session.delete(user)

# حذف جميع المنشورات غير المنشورة
Post.query.filter_by(published=False).delete()

# حفظ التغييرات
db.session.commit()
ملاحظة: جميع عمليات CRUD تتطلب db.session.commit() لحفظ التغييرات.

الترحيل (Migrations) باستخدام Flask-Migrate

Flask-Migrate هو امتداد لإدارة تغييرات هيكل قاعدة البيانات باستخدام Alembic.

تثبيت وتكوين Flask-Migrate

# تثبيت Flask-Migrate
pip install flask-migrate
إعداد Flask-Migrate

from flask import Flask
from flask_sqlalchemy import SQLAlchemy
from flask_migrate import Migrate

app = Flask(__name__)
app.config['SQLALCHEMY_DATABASE_URI'] = 'sqlite:///site.db'
db = SQLAlchemy(app)

# تهيئة الترحيل
migrate = Migrate(app, db)

# الأوامر في المحطة:
# flask db init        # تهيئة مجلد الترحيل
# flask db migrate -m "رسالة"  # إنشاء ملف ترحيل
# flask db upgrade     # تطبيق التغييرات على قاعدة البيانات
# flask db downgrade   # التراجع عن آخر تغيير
تنبيه: تأكد من استخدام flask db migrate قبل flask db upgrade لتجنب فقدان البيانات.

محاكي قاعدة البيانات التفاعلي

جرب إدارة المستخدمين في قاعدة بيانات محاكاة باستخدام عمليات CRUD:

# اسم المستخدم البريد الإلكتروني تاريخ الإضافة إجراء
إجمالي المستخدمين: 0
آخر إضافة: لا يوجد
تنبيه: هذا المحاكي تفاعلي فقط ويحاكي عمليات قاعدة البيانات. لا يتم حفظ البيانات بشكل دائم.

نصائح لقواعد البيانات الاحترافية

  • استخدم الفهارس (Indexes): أضف index=True للحقول التي تستخدمها في البحث لتحسين الأداء.
  • تعامل مع الأخطاء: استخدم try/except عند التعامل مع قاعدة البيانات للتعامل مع الأخطاء بشكل مناسب.
  • استخدم العلاقات بحكمة: اختر النوع المناسب من العلاقات (One-to-Many, Many-to-Many) حسب احتياجاتك.
  • قم بالترحيل بانتظام: استخدم Flask-Migrate لإدارة تغييرات هيكل قاعدة البيانات.
  • استخدم Session بحذر: تأكد من إغلاق الجلسات بعد الاستخدام لتجنب تسرب الموارد.
نصيحة اليوم: "قاعدة البيانات الجيدة هي أساس التطبيق الناجح. خطط لهيكل البيانات بعناية."
